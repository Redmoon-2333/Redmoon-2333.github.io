# rl-practice 复现指南

本指南对应强化学习实践系列（12 篇）的代码与实验口径。压缩包内是**源码、测试与实验编排脚本**，不含 `runs/` 原始日志与 checkpoint；它能从头重跑流程，但**不能直接离线重算文章中已发布的数字与图表**——那些数字来自本地 `runs/`，随包附上的数据摘要记录了对应结果。

## 1. 环境

- Python 3.12（Windows；Linux/macOS 同样可用，只需替换解释器路径）
- 依赖：`torch`（2.10，CPU 即可）、`numpy`、`gymnasium`、`matplotlib`、`seaborn`、`pytest`

```bash
pip install torch numpy gymnasium matplotlib seaborn pytest
```

本系列全部实验在 CPU 上完成，单次运行的量级见下表。

## 2. 目录结构

```
rl-practice/
├── rlpractice/
│   ├── common/        # 注册表、运行日志、评估协议、统计
│   ├── envs/          # 悬崖网格（终止式变体）
│   ├── algos/single/  # qlearning / sarsa / dqn / reinforce / a2c / ppo
│   ├── algos/marl/    # 走廊、谜题、导航三环境 + iql/vdn/qmix/coma/maddpg/iddpg/commnet
│   ├── train.py       # 统一训练入口
│   └── figures/       # 纯读取绘图与数据摘要
├── tests/             # 单元测试（边界、目标、单调性、消融隔离、策略回归…）
├── scripts/           # 实验编排、复评、汇总
├── （随包不提供）runs/         # 原始日志（manifest/episodes/evals/checkpoint），仅本地保留
└── （随包不提供）figures_out/  # 图表输出，由本地 runs/ 生成
```

## 3. 三条命令

```bash
python -m pytest tests -q                       # 单元测试
python -m rlpractice.train --algo qlearning --env cliff --seed 0 --budget 100000
python -m rlpractice.figures                    # 只读 runs/ 生成全部图表
```

- `--env` 可选：`cliff`、`cartpole`、`corridor`、`riddle`、`nav2d`；
- `--budget` 是环境步（MARL 为联合步）硬上限；
- `--set key=value` 覆盖任意算法超参，例如 `--set lr=0.001 --set rollout=32`。

完整实验矩阵（15 个配置 × 5 个种子 = 75 次运行）用 `scripts/run_formal.py` 编排，
支持断点续跑、线程限制与失败留痕。

## 4. 数据口径

- 训练种子 0–4；验证 20 局（种子 10000+，每 10% 预算一次）；最终测试 100 局（种子 20000+）。
- 第 3–5 章的 CartPole 数字为**一次性复评**（配置冻结后在从未用于调参的 30000–30099 种子上
  重新评估，见 `scripts/final_eval.py` 与各 run 的 `final_eval.csv`）。该命令需要本地已有的训练
  checkpoint，源码包本身不含 checkpoint，因此解压后无法直接重算这批复评数字。
- 每次运行写入 `runs/<env>/<algo>/seed<k>_<时间戳>/`：
  - `manifest.json`：配置、依赖版本、源码 SHA256、状态与用时；
  - `episodes.csv`：逐回合 return / 长度 / 累计环境步；
  - `evals.csv`：逐局评估原始记录（含策略模式与评估种子）；
  - `checkpoints/`：最终策略。
- 误差带为跨训练种子的样本标准差（SD），不是 SEM 或置信区间。

## 5. 三类结果的定位

- 悬崖与 CartPole：单智能体基础机制的可复现对照；
- 走廊 / 谜题 / 导航：**三个自定义小环境上的六个教学机制演示**，
  不是对原论文的性能复现，也不与文献数字并排比较。

## 6. 与源实现的关系

多智能体部分移植自课题项目的教学代码，修正了已确认问题：QMIX 输出被迫非负、COMA 的
critic 目标误用 $\mathbb{E}[\mathrm{onehot}]$ 且随机评估未使用显式随机数流、MADDPG/IDDPG
的 critic 目标形状广播错误与 actor 冻结时序错误、通信消融同时砍掉深度、环境终止与截断未分离、
绘图写死结论。每次修正都有对应回归测试锚定（见 `tests/test_policy_regressions.py`）。
旧 COMA 与 MADDPG/IDDPG 正式运行产生于修复之前，其算法对照结论已撤回；源码修复并通过冒烟测试
不等于历史结果恢复有效，重新得出结论需要按同协议重训。
