## 0. 模型结构与任务（一分钟版）

**数据流**（单头自注意力，只有位置 2 的输出接 loss）：

```
词 id → 查词嵌入表 E（固定不训） → X (3×8)
      → Q = X·W_Q   K = X·W_K   V = X·W_V    ← 同一个 X 的三种投影（可学习）
      → S = QKᵀ/√8 → A = softmax(S)          ← 注意力权重，每行和为 1
      → O = A·V → 取末位 h = O[2]             ← 位置 2 的'信息包'
      → logits = W_OUT·h + b → softmax → P(词) → loss = -log P(正确词)
```

**任务**：输入 `[<pad>, 主语, 很]`，预测属性词。

| 输入 | 应预测 |
| --- | --- |
| <pad> 小猫 很 | **困** |
| <pad> 垫子 很 | **软** |
| <pad> 月亮 很 | **亮** |

**为什么这个任务需要注意力**：位置 2（"很"）自己不携带任何主语信息，想预测对属性，它的注意力必须**越过"很"、回头盯住位置 1 的主语**——这正是训练结束后我们能从权重里读出的"视角"。

```
logits[小猫] = h·W_OUT[1]: -0.33·-0.25 + +0.15·+0.24 + -0.00·-0.14 + -0.20·-0.12 + +0.22·+0.20 + -0.17·+0.07 + -0.35·-0.19 + -0.31·-0.04 = +0.2516
8 个 logits: [-0.027  +0.000  -0.387  -0.366  -0.585  -0.475  -0.138  -0.481]
逐个取指数  : [+0.974  +1.000  +0.679  +0.693  +0.557  +0.622  +0.871  +0.618]   求和 = 6.014
P(困) = 0.622 / 6.014 = 0.1034
loss  = -ln(P) = 2.2688
```

> 概念解析：logits 是"每个候选词的得分"，softmax 把得分变概率；交叉熵 loss = -log(正确词概率)——概率越接近 1，loss 越接近 0。训练的全部目标就是**把正确词的概率推高**。

## 3. 第 1 次反向传播：梯度从哪来

### 3.1 梯度源头：dlogits = p − onehot(正确词)

```
p       = [+0.162  +0.166  +0.113  +0.115  +0.093  +0.103  +0.145  +0.103]
dlogits = [+0.170  +0.157  +0.112  +0.111  +0.098  -0.221  -0.198  -0.230]
```

> 概念解析：交叉熵+softmax 的梯度有个极简形式——**正确词概率被拽高的力度 = (1−p)，错误词被压低的力度 = 各自的 p**。概率错得越离谱，推力越大。

### 3.2 W_OUT[困,0] 的梯度 = 三个样本贡献相加

```
样本1(应预测困): dlogits[5]=-0.897 × h[0]=-0.330 → +0.2956
样本2(应预测软): dlogits[6]=-0.864 × h[0]=+0.017 → -0.0150
样本3(应预测亮): dlogits[7]=-0.889 × h[0]=+0.134 → -0.1191
相加 = 总梯度 +0.1615
```

> 概念解析：这就是 micrograd 里"梯度是所有路径贡献之和，必须 += 累加"的再现——batch 里每个样本都往同一个参数上贡献一份梯度。

### 3.3 更新公式实算

```
W_OUT[困,0] = +0.2058 - 0.5 × +0.1047 = +0.1535
```

### 3.4 数值梯度抽查（验证手推反向没推错）

```
W_Q[0,0]: 手推 = -0.000153   数值差分 = -0.000204   误差 = 5.09e-05
```

> 概念解析：把参数手动挪动 ±ε 各算一次 loss，(loss₊−loss₋)/2ε 就是数值导数。两者一致 → 手推的反向传播是对的。micrograd 里"对照数值导数"的同款操作。

## 5. 训练完成：最终权重在说什么（反向理解）

### 5.1 注意力分布：训练前 vs 训练后（位置 2 的行）

| 样本 | 训练前（pad / 主语 / 很） | 训练后（pad / 主语 / 很） |
| --- | --- | --- |
| <pad>小猫很 → 困 | 0.335 / 0.344 / 0.321 | **0.660 / 0.268 / 0.072** |
| <pad>垫子很 → 软 | 0.364 / 0.288 / 0.348 | **0.044 / 0.952 / 0.005** |
| <pad>月亮很 → 亮 | 0.331 / 0.352 / 0.317 | **0.007 / 0.992 / 0.001** |

> 读法：训练前三个位置接近均摊（≈1/3）；训练后位置 2 的注意力**几乎全部压在主语上**（位置 1），"<pad>"和"很"被压到接近 0。

> **诚实的发现**：三个样本没有走同一条路——样本 2/3 学到了"回头盯主语"（0.95、0.99 压在主语上）；样本 1 却把 0.66 的注意力放在了 <pad> 上。这不是 bug：对样本 1 来说，"关注常量 <pad> + 输出层记住这种组合"同样能把 P(困) 推到 0.999——**梯度下降只保证 loss 下降，不保证选中的是最优雅的路径**（真实模型里的"捷径学习"现象）。样本 2/3 的模式才是我们想要的"属性查询"视角。

### 5.2 打分的变化：Q·K 学会了"认主语"

| 样本 | s(2→pad) 前→后 | s(2→主语) 前→后 | s(2→很) 前→后 |
| --- | --- | --- | --- |
| 样本1 | -0.0272 → +0.0000 | +0.0000 → **-0.8998** | -0.0701 → -2.2188 |
| 样本2 | +0.0000 → -3.0820 | -0.2337 → **+0.0000** | -0.0428 → -5.3008 |
| 样本3 | -0.0637 → -4.9108 | +0.0000 → **+0.0000** | -0.1065 → -7.1296 |

> 解读：主语方向的打分被显著放大（或 pad/很 方向被打压）——这就是 W_Q、W_K 训练后学到的东西：**位置 2 的 Query 与主语的 Key 在投影空间里方向对齐**。注意力权重的变化只是这个打分变化经过 softmax 的结果。

> 样本 1 是例外：它的 s(2→pad) 反而升到相对最高——对应 5.1 里它走的"<pad> 捷径"。读表时把样本 2/3 当作"属性查询头"的标准形态即可。

### 5.3 输出层：3×3 "主语 → 属性"对齐矩阵

h（位置 2 的信息包，几乎 = 主语内容）与 W_OUT 里三行属性向量的点积：

| 信息包来自 | ×W_OUT[困] | ×W_OUT[软] | ×W_OUT[亮] | 应选 |
| --- | --- | --- | --- | --- |
| 小猫 的内容 | +7.061 | +1.142 | -5.739 | **困** |
| 垫子 的内容 | -0.761 | +8.926 | +0.540 | **软** |
| 月亮 的内容 | -11.965 | +3.852 | +11.084 | **亮** |

> 解读：对角线（小猫→困、垫子→软、月亮→亮）显著高于非对角线 —— W_OUT 学会了**把"主语内容"翻译成"正确属性"**。模型答对的机制就在这张表里。

### 5.4 这个头学到的"视角"（一句话）

> **"属性查询头"：要猜一个词的属性，越过无信息的连接词，回头盯住它的主语，再把主语身份翻译成对应属性。** 这正是 Day2 笔记里"多头 = 每个头学一种关系视角"的最小可运行证据——真实 Transformer 里成百上千个头，各自学到的关系（指代/语法/共现…）都可以用本文同款方法读出来。

## 6. 概念 FAQ（聊天里问过的问题存档）

**Q1：K 是由 V 推出来的，还是训练出来的？**

都不是。K 和 V 是同一个词的输入向量 x 分别乘以 W^K、W^V 得到的——**同源、独立、互不推出**。训练学出的是 W 矩阵的参数；推理时每个词的 K、V 由它自己的 x 即时算出。

**Q2：生成"垫子"那一刻，Q 是谁？**

是当前已生成序列末位（"在"）的 Query——**垫子还没出生，不可能提供 Q**。流程："在"的 Q 取货 → 预测出垫子 → 垫子拼回输入 → 下一步垫子才有自己的 Q。垫子是输出，不是输入。

**Q3：训练和推理有什么区别？**

训练用 teacher forcing：完整答案一次喂入，掩码保证每个位置只看过去，并行算出所有位置的预测。推理没有答案，只能逐词生成，一步一轮回。

**Q4：为什么初始注意力是均匀的？**

初始 W 是随机小数 → Q·K 分数差距很小 → softmax 接近均匀（≈1/3）。训练让"该看的方向"打分变大，softmax 逐渐变尖。INIT_SCALE 调大，初始分布就会变尖。
