强化学习入门的学习笔记与阶段总结：Day1 从奖励与回报讲到 Q-learning、SARSA 和悬崖行走；Day2 拆解 DQN 的一次更新；Day3 通过两条路线理解 Actor–Critic；Day4 从整局 REINFORCE 连接 baseline、Critic 和 GAE；Day5 接通 PPO 的采样、更新与冻结评估；Day6 进入多智能体合作训练、反事实评分与通信；Day7 从 VDN 到 QMIX，接通价值分解、联合回放与完整合作训练；Day8 用连续动作实验拆解 MADDPG 风格的集中式 Critic、局部 Actor 与软同步；Day9 用消失提示任务理解循环 Actor、本回合 hidden、完整序列重建与时间梯度；Day11 通过 COMA 训练，把团队奖励接到候选动作 Q、个体反事实优势、多步回报和分散评估。《Day8前的一个小总结》集中辨明合作、通信、价值评价与实验结果之间的关系。
