第一题的七个右端依次是 $2T(n/2)+n^4$、$T(7n/10)+n$、$16T(n/4)+n^2$、$7T(n/3)+n^2$、$7T(n/2)+n^2$、$2T(n/4)+\sqrt n$、$T(n-2)+n^2$。其余五题可以先自己挑只有一个元素、全负、重复值或刚好不能到达的输入，检查写下的算法有没有真正满足返回要求。

## 一、递推式：比较每层总代价

对 $T(n)=aT(n/b)+n^p$，规模按比例缩小时，第 $i$ 层代价为 $n^p(a/b^p)^i$，深度为 $\Theta(\log n)$。层代价递减、持平、递增，分别对应根部占主导、各层同阶、底层占主导。

|小题|紧确界|推导要点|
|---|---|---|
|1|$\Theta(n^4)$|每层是上一层的 $2/2^4=1/8$，求和同根部同阶|
|2|$\Theta(n)$|只有一条递归链，工作量为 $n+0.7n+0.7^2n+\cdots$|
|3|$\Theta(n^2\log n)$|比例 $16/4^2=1$，每层 $n^2$|
|4|$\Theta(n^2)$|比例 $7/9<1$，构成收敛几何级数|
|5|$\Theta(n^{\log_2 7})$|比例 $7/4>1$，底层叶数与 $7^{\log_2 n}$ 同阶|
|6|$\Theta(\sqrt n\log n)$|两个子问题各贡献上一层一半的根号项，每层仍是 $\sqrt n$|
|7|$\Theta(n^3)$|每次减 2，展开为 $n^2+(n-2)^2+\cdots$。项数是 $\Theta(n)$，且前约 $n/4$ 项每项至少 $(n/2)^2$|

答第七小题时，上界“至多 $n$ 项，每项至多 $n^2$”还不够。最后一行给出的那段大项同时给出三次下界，这才能写紧确界。

## 二、分两堆：倒序子集和与方案恢复

设总和 $S$，较小一堆的和为 $b$，差值为 $S-2b$。所以要在 $C=\lfloor S/2\rfloor$ 以内找最大的可达和。用 `reachable[t]` 表示用已处理的数能否得到 $t$，初始只有 0 可达。每个元素只能进一堆一次，所以容量必须倒序扫描。若顺序扫描，仅有一个 3 时，本轮刚得到的 3 就可能再次被用来凑 6。

~~~python
def split_piles(values):
    cap = sum(values) // 2
    parent = [None] * (cap + 1)
    parent[0] = (-1, -1)
    for i, x in enumerate(values):
        for t in range(cap, x - 1, -1):
            if parent[t] is None and parent[t - x] is not None:
                parent[t] = (i, t - x)
    t = max(i for i, p in enumerate(parent) if p is not None)
    chosen = set()
    while t:
        i, t = parent[t]
        chosen.add(i)
    return ([x for i, x in enumerate(values) if i in chosen],
            [x for i, x in enumerate(values) if i not in chosen])
~~~

例如 1、6、11、5 总和 23，容量为 11。处理完 1、6 时可达 0、1、6、7，再看到 11，第一次到达 11 的记录指向 0。于是两堆可取 11 和 (1,6,5)，差为 1。依据“取不取当前元素”归纳，所有且仅有可行的子集和会被标记。记录首次到达的下标可以处理重复值，父指针不会被后来一轮覆盖。时间 $O(nS)$，工作表 $O(S)$，输出及下标集合另占 $O(n)$。这是关于数值总和的伪多项式算法。

## 三、最大子数组：必须以当前位置结尾

输入非空时，记 $E_i$ 为必须以第 $i$ 项结尾的最大连续和，则 $E_i=\max(A_i,E_{i-1}+A_i)$。取第一项表示从这里重新开始，取第二项表示沿用上一段左端点。每个非空连续段都有唯一右端点，比较各 $E_i$ 就不会漏掉全局最优。记住更新全局纪录时的两个端点，否则最后一次重启就会覆盖答案的位置。

~~~python
def max_slice(a):
    ending = best = a[0]
    start = left = right = 0
    for i in range(1, len(a)):
        if ending < 0:
            ending, start = a[i], i
        else:
            ending += a[i]
        if ending > best:
            best, left, right = ending, start, i
    return best, a[left:right + 1]
~~~

对 −2、3、−1、4、−6，各位置的结尾最优和依次为 −2、3、2、6、0，全局答案是和为 6 的连续段 3、−1、4。全负输入 −5、−2 要返回 −2，初值若取 0 会错误地选出空段。扫描时间 $O(n)$，额外状态 $O(1)$，复制答案切片另用与输出长度相当的空间。

## 四、跳跃游戏：证明可达位置形成前缀

维护 `far` 表示由已经扫描的可达位置能覆盖的最右下标。题面允许跳**至多**给定步数，所以从 $i$ 能覆盖连续区间 $[i,i+A_i]$，与当前可达前缀相接时没有空洞。遇到 $i>far$ 可以立即返回假。在判定位置可达之前，不能用它的跳力更新边界。

~~~python
def reaches_last(a):
    far = 0
    for i, steps in enumerate(a):
        if i > far:
            return False
        far = max(far, i + steps)
        if far >= len(a) - 1:
            return True
    return False
~~~

对 3、2、1、0、4，扫描前四项后边界一直是 3，最后的 4 看得见却用不到。对 2、3、1、1、4，扫描下标 1 时就覆盖末尾。有一个元素时起点就是终点。时间 $O(n)$，额外空间 $O(1)$。

## 五、最长上升子序列：同长度只留最小末尾

二次解法枚举前驱 $j<i$ 且 $a_j<a_i$。原卷要求 $O(n\log n)$，需换状态。让 `tails[k]` 表示已读前缀内，长度为 $k+1$ 的严格上升子序列能有的最小末尾。固定长度时，更小的末尾能接上原末尾所能接的一切后继，因此留下它不会损失未来的最优长度。各长度的最小末尾严格递增，可用二分查找第一个大于等于 $x$ 的位置。

~~~python
from bisect import bisect_left

def lis_length(a):
    tails = []
    for x in a:
        j = bisect_left(tails, x)
        if j == len(tails):
            tails.append(x)
        else:
            tails[j] = x
    return len(tails)
~~~

|读入值|2|6|8|3|4|5|1|
|---|---|---|---|---|---|---|---|
|当前最小末尾表|2|2,6|2,6,8|2,3,8|2,3,4|2,3,4,5|1,3,4,5|

为什么算出来的长度可实现？若插在位置 $j>0$，前一格末尾严格小于 $x$，能接成长度 $j+1$ 的真实子序列。为什么不漏掉更长的？后一个长度若能由 $x$ 新建，则一定已有同长度前驱的末尾严格小于 $x$，二分位置就会更靠右。例子答案为 4，具体方案可取 2、3、4、5。末尾表里的 1 最后才出现，直接打印整张表会拼出不存在的序列。对 2、2、2，每次替换第一格，严格上升长度为 1。共 $n$ 次二分，时间 $O(n\log n)$，空间 $O(n)$。

## 六、最长回文子序列：两端决定依赖

令 $L(i,j)$ 表示 $A_i$ 至 $A_j$ 内的最长回文子序列长度。空区间为 0，单点为 1。若两端相同，把它们包在内部最优解外面即可。任意回文解去掉成对的首尾后都位于内部，因而原解至多比内部最优解多 2。若两端不同，必须舍弃至少一端，取两种舍法的最大值。填写顺序可以按区间长度递增，也可以让左端点递减、右端点递增。

~~~python
def palindrome_length(a):
    n = len(a)
    if n == 0:
        return 0
    d = [[0] * n for _ in range(n)]
    for i in range(n - 1, -1, -1):
        d[i][i] = 1
        for j in range(i + 1, n):
            if a[i] == a[j]:
                d[i][j] = 2 + d[i + 1][j - 1]
            else:
                d[i][j] = max(d[i + 1][j], d[i][j - 1])
    return d[0][-1]
~~~

以序列 1、2、3、1 为例。长度 1 的答案都是 1，长度 2 的三个区间都是 1，长度 3 的两个区间也都是 1。最外层两个 1 相同，用中间的 2 或 3 作中心即可得 3。全相同的四个元素得 4，全不同得 1。二维表有 $O(n^2)$ 个状态，每格只看相邻三个格子，故时间和空间均为 $O(n^2)$。题目只求长度时可以压缩到一行，覆盖前需暂存上一行左上角的值。
