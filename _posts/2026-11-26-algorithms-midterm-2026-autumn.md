## 第一题　活动选择（20 分）

### 题目

有 $n\ge1$ 个活动，第 $i$ 个的开始时间和结束时间分别为 $s_i$ 和 $f_i$，且 $s_i<f_i$。活动占用半开区间 $[s_i,f_i)$，一个活动的结束时间等于另一个活动的开始时间时，两者相容。目标是选出尽可能多的互不冲突的活动。

每轮从尚未选择且与所有已选活动均不冲突的活动中，选**开始时间最晚**的一个。开始时间相同可以任选。

1. 描述实现该规则的完整贪心算法，可使用伪代码。（8 分）
2. 证明该算法总能得到活动数最多的可行方案。（12 分）

### 解答

**（1）实现。** 按开始时间降序处理。已选活动从右往左接上，`boundary` 是已选序列最左侧活动的开始时间。之后扫描到的活动都在这一边界或更早开始，能加入当且仅当它在边界时刻前结束或刚好在边界结束。选中后把边界改为它的开始时间。

```python
def select_activities(intervals):
    indexed = sorted(enumerate(intervals, start=1),
                     key=lambda item: item[1][0], reverse=True)
    boundary = float("inf")
    chosen = []
    for index, (start, finish) in indexed:
        if finish <= boundary:
            chosen.append(index)
            boundary = start
    return chosen[::-1]
```

例如 $[0,2),[1,4),[2,3),[3,5)$，扫描时依次选 $[3,5),[2,3),[0,2)$，返回时按时间正序排列。排序耗时 $O(n\log n)$，扫描耗时 $O(n)$。这版实现保留活动原编号，额外空间为 $O(n)$。

**（2）交换证明。** 考虑任意一轮的剩余候选集。令 $g$ 是其中开始最晚的活动，任选一个最优方案，并记该方案中开始最晚的活动为 $a$。如果最优方案已经选了 $g$，它便满足本轮贪心选择。否则，把 $a$ 换成 $g$。原方案中其余活动的结束时间均不晚于 $s_a$，又有 $s_a\le s_g$，所以换入 $g$ 后仍相容，活动数相同。

因此存在包含 $g$ 的最优方案。固定 $g$ 后，候选只剩满足 $f_i\le s_g$ 的活动。由开始时间的排序和正时长，其他候选没有可能排到 $g$ 之后。不满足条件的活动也无法在未来更早的边界下加入。若这个子问题能选得更多，接上 $g$ 就能改进当前最优解，矛盾。空候选集返回空方案，按剩余候选规模归纳即可。证明只用到 $s_a\le s_g$，所以开始时间并列时任选都成立。

## 第二题　最优二进制前缀码（20 分）

### 题目

设有 $n\ge2$ 个字符 $x_1,\ldots,x_n$，字符 $x_i$ 的权重为 $w_i>0$，其二进制码字长度为 $\ell_i$。构造一组二进制前缀码，使加权码长 $L=\sum_{i=1}^n w_i\ell_i$ 最小。八个字符的权重如下。

| 字符 | a | b | c | d | e | f | g | h |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 权重 | 1 | 1 | 2 | 3 | 5 | 8 | 13 | 21 |

1. 给出这八个字符的一组最优二进制前缀码，可以用编码表或标明 0、1 分支的编码树表示。（8 分）
2. 推广至任意 $n\ge2$，第 $i$ 个字符的权重为 $F_i$，其中 $F_1=F_2=1$，且 $F_i=F_{i-1}+F_{i-2}$（$i\ge3$）。给出一组最优编码的一般形式，并说明理由。（12 分）

### 解答

**（1）八字符。** Huffman 算法每轮合并权重最小的两个节点，合并后把父节点放回候选集合。本题依次发生以下合并。

| 轮次 | 合并对象的权重 | 父节点权重 |
| ---: | --- | ---: |
| 1 | $1+1$ | 2 |
| 2 | $2+2$ | 4 |
| 3 | $3+4$ | 7 |
| 4 | $5+7$ | 12 |
| 5 | $8+12$ | 20 |
| 6 | $13+20$ | 33 |
| 7 | $21+33$ | 54 |

第一次合并令 `a` 走 1、`b` 走 0。之后每次令新并入的字符走 0，已有子树走 1。自根向下读边即得到下表。

| 字符 | 权重 | 码字 | 码长 |
| --- | ---: | --- | ---: |
| a | 1 | `1111111` | 7 |
| b | 1 | `1111110` | 7 |
| c | 2 | `111110` | 6 |
| d | 3 | `11110` | 5 |
| e | 5 | `1110` | 4 |
| f | 8 | `110` | 3 |
| g | 13 | `10` | 2 |
| h | 21 | `0` | 1 |

按表计算得 $L=7+7+12+15+20+24+26+21=132$。每次合并给两子树中的所有叶子增加一层，所以也可用父节点权重之和 $2+4+7+12+20+33+54=132$ 复核。

**（2）一般形式。** 记 $1^r$ 为连续 $r$ 个 `1`，$1^0$ 为空串。沿用上述边标记，可取

$$
\operatorname{code}(x_1)=1^{n-1},\qquad
\operatorname{code}(x_i)=1^{n-i}0\quad(2\le i\le n).
$$

所以 $\ell_1=\ell_2=n-1$，从 $i=2$ 起有 $\ell_i=n-i+1$。例如 $n=2$ 时是 `1` 和 `0`。每个以 `0` 结尾的码与任何更长的码，在这个 `0` 所在位置分别走两条不同的边，故码字彼此不为前缀。

**为什么会形成这棵树。** 记已经合并的前 $k$ 个字符的总权重为 $T_k$。由 Fibonacci 递推可归纳得到 $T_k=\sum_{i=1}^kF_i=F_{k+2}-1$。合并 $F_1,F_2$ 后得到 $T_2=2$。若已形成 $T_k$，剩余字符的最小权重为 $F_{k+1}$。当 $F_{k+2}$ 也还在时，有

$$
F_{k+1}\le T_k=F_{k+1}+(F_k-1)<F_{k+2}.
$$

这里的左侧不等式用到 $F_k\ge1$，右侧用到 $T_k=F_{k+2}-1$。因此最小的两个节点正是 $F_{k+1}$ 与 $T_k$。若只剩两个节点，直接合并。逐轮得到 $T_{k+1}$，最终最初的兄弟 $x_1,x_2$ 都在深度 $n-1$，后来并入的 $x_i$ 在深度 $n-i+1$。

**为什么每轮合并都最优。** 对应前缀码的二叉树以字符作为叶子。权重为正的最优树可以取满二叉树，即每个内部节点有两个孩子。否则可收缩单孩子节点，使其下的码变短。最深处有一对同深度的兄弟叶，将两个最小权重放到这对叶子，只需交换叶标签。小权重移到更深处、大权重移到更浅处，加权码长不会增加。将这对兄弟收缩成一个权重为两者之和的叶子，原加权码长恰好等于收缩树的加权码长加上这两个权重。若收缩后有更优树，展开便能改进原解。归纳可知，反复合并两个最小权重的做法最优。

一般 Huffman 用最小堆建树，需 $O(n\log n)$ 时间和 $O(n)$ 额外空间。已知权重为这组 Fibonacci 数时，直接按合并次序构造树只需线性次合并，显式写出全部码字需要 $\Theta(n^2)$ 个字符。

## 第三题　分割等和子集（15 分）

### 题目

正整数数组 $A$ 含 $n\ge1$ 个元素。判断能否把全部元素分成和相等的两组。每个元素必须且只能归入一组，数值相同但位置不同的元素视为不同元素。令 $S=A_1+\cdots+A_n$。设计一个 $O(nS)$ 时间的动态规划算法，输出“可以”或“不可以”。

1. 定义状态并给出边界条件。（4 分）
2. 给出状态转移、计算顺序及完整伪代码。（5 分）
3. 简要论证正确性。（3 分）
4. 分析时间和空间复杂度。（3 分）

### 解答

**（1）状态和边界。** $S$ 为奇数时直接返回“不可以”。若 $S$ 为偶数，令 $T=S/2$。找到一组位置，使对应元素和为 $T$，其余位置的元素和自然也是 $T$。令 $D[i,t]$ 表示前 $i$ 个位置中能否选出和为 $t$ 的子集，其中 $0\le t\le T$。$D[0,0]=\text{true}$，$D[0,t]=\text{false}$（$t>0$）。

**（2）转移和顺序。** 不取第 $i$ 个元素时看上一行同一列。取时须有 $t\ge A_i$，再看上一行的 $t-A_i$ 列。按 $i$ 递增逐行计算，每行内部可按 $t$ 递增。

$$
D[i,t]=D[i-1,t]\ \lor\ \bigl(t\ge A_i\ \land\ D[i-1,t-A_i]\bigr).
$$

```python
def partition_equal(a):
    total = sum(a)
    if total % 2:
        return "不可以"
    target = total // 2
    dp = [[False] * (target + 1) for _ in range(len(a) + 1)]
    dp[0][0] = True
    for i, value in enumerate(a, start=1):
        for t in range(target + 1):
            dp[i][t] = dp[i - 1][t] or (
                t >= value and dp[i - 1][t - value]
            )
    return "可以" if dp[len(a)][target] else "不可以"
```

**（3）正确性。** 空前缀只能凑出 0，初值成立。任何取自前 $i$ 个位置且和为 $t$ 的方案，按是否包含位置 $i$ 恰好落到两种转移之一。反过来，来自上一行的可行方案，原样使用或加上位置 $i$，都构成当前行的可行方案。按前缀长度归纳，最终 $D[n,T]$ 准确判断能否凑出一半，同时补集给出第二组。

**（4）复杂度。** 每个状态 $O(1)$，时间和二维表空间都是 $O(nT)=O(nS)$。压到一维时，每个元素都要从 $T$ 降序更新到该元素的值，空间为 $O(S)$。以 $[2,3,3]$ 为例，目标为 4，正确结果是“不可以”。若一维表升序更新，第一轮可能先用 2 使 `dp[2]` 为真，又用刚得到的 `dp[2]` 推出 `dp[4]`，相当于重复用了同一位置。

## 第四题　最大正方形（15 分）

### 题目

给定 $m\times n$ 的 0–1 矩阵 $A$，其中 $m,n\ge1$。求全由 1 组成的最大正方形子矩阵的面积。子矩阵由连续的行和连续的列构成，边与原矩阵的行、列方向平行，面积等于其中元素的个数。矩阵中没有 1 时返回 0。

$$
A=\begin{bmatrix}
0&1&1&0\\
1&1&1&1\\
0&1&0&1
\end{bmatrix}.
$$

上面的输入输出 4。第 1 至 2 行、第 2 至 3 列组成的全 1 正方形边长为 2，面积为 4。

设计一个 $O(mn)$ 时间的动态规划算法。

1. 定义状态并给出边界条件。（4 分）
2. 给出状态转移、计算顺序及完整伪代码。（5 分）
3. 简要论证正确性。（3 分）
4. 分析时间和空间复杂度。（3 分）

### 解答

**（1）状态和边界。** 用 $D[i,j]$ 表示**右下角恰为** $(i,j)$ 的最大全 1 正方形的**边长**，行列从 1 编号。加一行第 0 行、一列第 0 列，边长统一设为 0。

**（2）转移和顺序。** 行从上到下、列从左到右。当前格是 0 时状态为 0，是 1 时看上、左和左上三个状态，取最小值加 1。

$$
D[i,j]=
\begin{cases}
0,& A_{ij}=0,\\
1+\min\{D[i-1,j],D[i,j-1],D[i-1,j-1]\},& A_{ij}=1.
\end{cases}
$$

```python
def maximal_square(a):
    m, n = len(a), len(a[0])
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    best = 0
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if a[i - 1][j - 1] == 1:
                dp[i][j] = 1 + min(dp[i - 1][j], dp[i][j - 1],
                                   dp[i - 1][j - 1])
                best = max(best, dp[i][j])
    return best * best
```

**（3）正确性。** 若当前位置是 1，记三个邻居状态的最小值为 $k$。任意以当前位置为右下角、边长为 $d>1$ 的全 1 正方形中，三个邻居各自都有一个边长为 $d-1$ 的全 1 子正方形。因此 $d\le k+1$。

反过来，左上的边长 $k$ 正方形提供待构造正方形的左上块。上方的边长 $k$ 正方形提供最右列的前 $k$ 个格，左方的边长 $k$ 正方形提供最底行的前 $k$ 个格。补上当前位置的 1 就得到边长 $k+1$ 的全 1 正方形。$k=0$ 时该格自己构成边长 1 的正方形。逐格取最大边长再平方，就得到题目要求的面积。

原题矩阵算出的状态表为

$$
D=\begin{bmatrix}
0&1&1&0\\
1&1&2&1\\
0&1&0&1
\end{bmatrix}.
$$

**（4）复杂度。** 每格计算一次，时间为 $O(mn)$，二维表的额外空间为 $O(mn)$。滚动更新时，保留上一行的左上值、上一行的当前列以及当前行已更新的前一列，空间可降为 $O(n)$。

## 第五题　最长回文子序列（15 分）

### 题目

给定长度为 $n\ge1$ 的字符串 $s$，求其最长回文子序列的长度。子序列可以删除零个或多个字符，保留字符的相对顺序。回文序列从左往右和从右往左读相同。只返回长度。设计一个 $O(n^2)$ 时间的动态规划算法。

1. 定义状态并给出边界条件。（4 分）
2. 给出状态转移、计算顺序及完整伪代码。（5 分）
3. 简要论证正确性。（3 分）
4. 分析时间和空间复杂度。（3 分）

### 解答

**（1）状态和边界。** $D[i,j]$ 为闭区间 $s[i..j]$ 内最长回文子序列的长度，下标从 0 开始。单字符 $D[i,i]=1$，空区间 $D[i,j]=0$（$i>j$）。

**（2）转移和顺序。** 两端相等时可将最优内部回文包在两端之间。两端不等时至少跳过一个端点。每项依赖更短区间，按长度从 2 增加到 $n$。

$$
D[i,j]=
\begin{cases}
2+D[i+1,j-1],& s_i=s_j,\\
\max\{D[i+1,j],D[i,j-1]\},& s_i\ne s_j.
\end{cases}
$$

```python
def longest_palindromic_subsequence(s):
    n = len(s)
    dp = [[0] * n for _ in range(n)]
    for i in range(n):
        dp[i][i] = 1
    for length in range(2, n + 1):
        for i in range(n - length + 1):
            j = i + length - 1
            if s[i] == s[j]:
                dp[i][j] = 2 + dp[i + 1][j - 1]
            else:
                dp[i][j] = max(dp[i + 1][j], dp[i][j - 1])
    return dp[0][n - 1]
```

**（3）正确性。** 两端不等时，同时选两端会使回文首尾不同，故最优解来自两个去掉一端的区间之一，两边的最优长度都可实现。两端相等时，给内部最优回文加上两个端点，可以得到 $2+D[i+1,j-1]$。为了证明这是上界，考虑任一长度至少为 2 的回文子序列。若它包含原区间的任一端点，删去该回文自己的首尾，余下的回文位于内部区间，长度比原来少 2。若两个原端点都没用，整个回文已经在内部区间。长度为 0 或 1 的候选也不超过构造值。于是转移的上下界一致。按区间长度归纳得到全串的答案。

例如 `bbbab` 的两端均为 `b`，中间 `bba` 的最优长度为 2，所以全串答案为 4，可选出 `bbbb`。相邻两字符相等时，对应的空区间初值为 0，直接得到 2。

**（4）复杂度。** 有 $n(n+1)/2$ 个非空区间，每个状态耗时 $O(1)$，时间与额外空间均为 $O(n^2)$。只求长度时，可改为从右向左更新左端点，滚动保存一行并暂存覆盖前的斜对角值，把空间降到 $O(n)$。

## 第六题　救生艇（15 分）

### 题目

有 $n\ge1$ 个人，第 $i$ 人的体重是正整数 $w_i$。救生艇数量不限，每艘最多载两人，乘客体重之和不得超过 $C$。每个人的体重都不超过 $C$，且必须且只能乘坐一艘船。求运送全部人所需的最少船数。设计一个 $O(n\log n)$ 时间的贪心算法。

1. 说明贪心策略并给出完整伪代码。（6 分）
2. 证明能得到最少船数。（6 分）
3. 分析时间和空间复杂度。（3 分）

### 解答

**（1）贪心策略。** 排序后用两指针指向剩余乘客的两端。每轮给最重的人安排一艘船。若最轻的人是另一名乘客且二人可以同船，就配对。否则最重的人独乘。整轮结束时从剩余集合中移除已经上船的人。

```python
def min_rescue_boats(weights, capacity):
    weights = sorted(weights)
    left, right = 0, len(weights) - 1
    boats = 0
    while left <= right:
        if left < right and weights[left] + weights[right] <= capacity:
            left += 1
        right -= 1
        boats += 1
    return boats
```

例如体重为 $[1,2,3,4]$、载重为 5，先配 $4+1$，再配 $3+2$，两艘即可。等号对应刚好满载，允许配对。`left == right` 时只剩一人，给其安排一艘。

**（2）交换证明。** 设当前最重和最轻的人分别为 $H,L$，对应体重为 $h,l$。只剩一人时答案为一艘。其余情况分两类。

- 若 $h+l>C$，任意其他人的体重都至少为 $l$，所以所有可行方案都须给 $H$ 单独一艘。
- 若 $h+l\le C$，从一个最少船数方案出发。若 $H,L$ 已同船，可以直接保留。若两人各自单乘，合并为一艘还能减少船数，因此最优方案中不会出现这一情况。若恰有一人单乘，将 $H,L$ 配在一起，让原来的另一位同船者单乘，仍用两艘。若原先是 $H$ 和 $X$ 同船、$L$ 和 $Y$ 同船，则改成 $H,L$ 一艘、$X,Y$ 一艘。因 $w_Y\le h$ 且 $X$ 原本能与 $H$ 同船，故 $w_X+w_Y\le w_X+h\le C$，交换可行且船数不变。

因此每轮的安排都能出现在某个最优方案中。移除这一艘船上的人后，若其余人有更省船的安排，就能改进原最优方案。对剩余人数归纳，双指针算法总能用最少船数。

**（3）复杂度。** 排序耗时 $O(n\log n)$，双指针总共移动 $O(n)$ 次。上面的 `sorted` 生成新数组，额外空间为 $O(n)$。若允许改写输入并改用原地堆排序，额外空间可为 $O(1)$。
