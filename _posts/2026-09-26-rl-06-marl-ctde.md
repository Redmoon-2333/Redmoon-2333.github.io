> 前五章的每一条更新式都默认同一件事：环境的转移与奖励是固定的，随训练改变的只有我自己的策略。这一章把前提拆掉——当环境里还有另一个正在学习的智能体时，我面对的还是原来那个 MDP 吗？如果不，单智能体时代得出的结论哪些还成立，哪些必须重写？本章用三个自定义小环境把困难拆开，用一个最小算法（IQL）演示最直接的处理方式及其失效方式，最后给出 CTDE 这一范式的定位。

## 一 · 单智能体的结论在什么时候失效

单智能体章节里有三条隐含结论，进入多智能体后逐条要重估：

**第一，「存在唯一最优策略」失效。** 走廊里智能体 0 的最优走法取决于智能体 1 是否去踩开关 B；开关谜题里智能体 1 的最优走法完全取决于智能体 0 把答案告诉它的方式。策略的好坏不再由环境单独定义，而是由「对手/队友的策略 + 环境」共同定义，最优性变成相对量，博弈论里用均衡而不是最优解来承接这个概念。

**第二，「收敛保证」失效。** 表格 Q-learning 的收敛论证建立在固定的转移核 $P(s'|s,a)$ 与奖励 $R(s,a)$ 之上：马尔可夫决策过程本身不随时间变化，Q 值回归的目标才稳定。多智能体里，队友每次参数更新都在改写我眼中的 $P_i$ 与 $R_i$——我观察到的「环境」在训练过程中持续漂移。注意这只说明**标准 MDP 收敛证明不再适用**，不等于算法一定发散（见易错点三）。

**第三，「训练分布 = 评估分布」失效。** 单智能体里测试环境与训练环境是同一个固定环境；多智能体里，测试时与我配对的策略正是训练出来的那一个。成绩属于配对 $(\pi_0, \pi_1)$，不属于单个 $\pi_i$：换一个 partner，或 partner 的策略挪动一步，同一套参数的分数都可能重排。

三类困难由此展开，下表是本章的骨架：

| 困难 | 具体含义 | 本章用哪个环境说明 |
|---|---|---|
| 非平稳性 | 队友策略变化使我的最优策略随之变化，回归目标持续漂移 | 走廊协作（完全可观察） |
| 信用分配 | 团队回报只有一个，无法直接判断是哪个智能体的功劳 | 走廊协作（共享奖励） |
| 部分可观测与联合动作 | 各自只见局部观测、信息不对称；动作空间随智能体数指数增长 | 谜题（信息不对称）、2D 导航（连续控制） |

## 二 · 三个自定义环境：把三类困难各自隔离出来

三个环境共用统一接口（`reset` / `step` 返回 `terminated`、`truncated`、`info`），观测与终止语义如下表：

| 环境 | 规则要点 | 观测维度 | 终止 / 截断 |
|---|---|---|---|
| 走廊协作 `CorridorEnv` | 9 格，开关 A=2、门=4、开关 B=6、目标=0；两开关被**同时踩住 2 步**门永久打开；门开后任一 agent 到 0 格得 +10；每步 −0.1、撞车 −0.2、10% 打滑；40 步上限 | 5 维：`[自身格子/8, 门开, 自己在开关上, 自身编号, 队友格子/8]`，动作 3（原地/左/右） | `terminated`=送达成功；`truncated`=40 步超时（未送达，可 bootstrap） |
| 开关谜题 `RiddleEnv` | 9 格、第 3 格是墙；正确答案每局随机为 4 或 6，**只有智能体 0 看得到**；智能体 1 从 5 出发去踩 | 3 维：`[自身格子/8, 自身编号, 答案特征]`，智能体 0 见 0.0/1.0，智能体 1 恒 0.5（未知） | `terminated`=踩对（+10）**或踩错（−5）**；`truncated`=25 步未作答（可 bootstrap） |
| 2D 导航 `Nav2D` | 场地 $[-1,1]^2$，连续动作（裁剪到 $[-1,1]$ 的力）；奖励 $=-\sum_{\text{地标}}\min_i \text{距离}$，碰撞额外 −1，再除以 10；两质点分工覆盖两块地标 | 8 维：自身位置/速度 + 两个地标相对位置，**看不到队友** | 无真实终止，25 步一律 `truncated`（可 bootstrap）；`success` 只在结算时判定：每块地标 0.5 内各有一个不同 agent |

三处口径必须说清：

- **`terminated` 是任务本身结束**——走廊里是成功送达，谜题里是答对或答错，两者都属于「真实终止」，Bellman 目标不再外推；**`truncated` 是人为的回合步数上限**（40/25/25 步），过程本身没有结局，价值估计照常 bootstrap。谜题里「答错」是 terminated 而不是截断：失败是任务的结局，不是时间用完了。
- 走廊的 `info.fell` 指超时未送达，谜题的 `fell` 指智能体 1 踩错开关，导航的 `fell` 指本回合发生过碰撞——同一个字段名在三个环境里语义不同，引用时必须带环境名。
- **完全可观察不等于没有困难**：走廊里每个 agent 都看得见队友格子，观测是充分的，非平稳与信用分配照样存在；困难的来源是「有学习者」，不全是「看不见」。

## 三 · IQL：把队友当成环境

最直接的处理方式是**假装队友是环境的一部分**，即独立 Q 学习（Independent Q-Learning, IQL）：每个智能体维护自己的 $Q_i$，各自回放、各自 bootstrap，团队标量奖励 $r$ 直接广播给每个人。

对联合转移 $(o, a, r, o', d)$，智能体 $i$ 的目标与损失为：

$$y_i = r + \gamma (1-d)\max_{a_i'} Q_i(o_i', a_i';\theta_i^-)$$

$$L(\theta_i) = \mathbb{E}\big[\operatorname{Huber}\big(Q_i(o_i,a_i;\theta_i) - y_i\big)\big]$$

其中 $d=1$ 仅当 `terminated`，截断时 $d=0$ 照常外推；$\theta_i^-$ 是每个智能体各自的目标网络，$\max$ 只在**自己的**动作维上取——目标里既没有队友的动作，也没有联合价值。本实现里三个方法共用同一套个体 Q 网络（`obs → 64 → 64 → n_actions`）与同一份联合回放 `JointReplay`，差别只在损失怎么组合：IQL 把 $r$ 与 $d$ 广播到每个智能体、逐个算 Huber；VDN 则把预测值求和去对联合目标。换言之，**IQL 与 VDN 的分野在「梯度流到谁身上」**，这正是第 7 章同预算对照的接口。

IQL 的失败模式有三种，前两种是一体两面：

1. **训练时互相适应**：两组参数同时更新，我的回归目标 $y_i$ 依赖的「下一状态分布」由对方当前策略生成，而对方策略此刻也在改。数据分布持续漂移，Q 值对着一个移动靶回归，单智能体里的收敛论证在这里断掉。
2. **评估时策略耦合**：测试成绩衡量的是这一对策略的配合，而不是任一智能体的独立能力。训练时双方互相迁就出来的默契，换一个 partner 就消失；反过来，训练早期学到的「等对方」类约定一旦被对方后期改写，前期积累的价值估计也作废。
3. **信用分配未被处理**：走廊里 +10 是团队回报，IQL 把它整份记在每个智能体自己账上——一个人踩对了开关，另一个人也拿到同样的 $y_i$ 信号。奖励是共享的，归因却没有发生，这只解决了「有信号」，没解决「信号归谁」。

## 四 · 实测：走廊上的 IQL 基线

协议（全部按系列统一口径）：预算 **100,000 联合步**（一个联合步 = 两个智能体同时各走一步，只计 1 次环境步；局数是另一口径，不与预算混用），训练种子 **0–4 共 5 个**；$\gamma=0.95$，$\varepsilon$ 从 0.5 线性衰减到 0.05、覆盖前 60% 预算；每 10,000 联合步做一次验证，**验证 20 局**（种子 10000+）；训练结束做**最终测试 100 局**（种子 20000+），**贪心策略**逐局记录。误差带口径为跨训练种子的样本 SD。

走廊组已跑完 5 个训练种子（0–4），实测结果如下：

- 测试成功率（100 局 × 5 种子）：100.0%
- 测试平均回报 ± 跨种子 SD：9.547 ± 0.000
- 截断率 / 平均局长：0.0%、4.5
- 验证成功率首次 → 末次（5 种子均值）：100% → 100%

![走廊上四种方法的验证成功率曲线：IQL 作为独立学习基线，与 VDN／QMIX／COMA 同预算对照（每点 20 局贪心评估，5 种子；阴影为跨种子 SD；IQL 与 VDN 曲线完全重合且全程 100%，红色被蓝色覆盖）](/assets/img/rl-practice/06_corridor_curves.png)

这些数字为第 7 章提供同环境基线。IQL、VDN、QMIX 共用个体 Q 网络、联合回放接口及环境步预算，但 QMIX 多了混合网络和全局状态输入，不能把差异视为单一变量的纯因果效应。COMA 使用 actor–critic 与 on-policy 轨迹，不共享这套 Q 网络和回放训练结构；其旧结果已因实现缺陷撤回。

## 五 · CTDE：训练时集中，执行时分散

**CTDE（Centralized Training with Decentralized Execution，集中训练、分散执行）**允许训练阶段使用集中信息，如全局状态、联合动作或联合经验；执行阶段则只使用各智能体实际可获得的信息。独立学习也可能在特定任务上收敛，但单智能体的平稳性保证不能直接搬用。集中训练仍消耗计算、通信与数据资源，只是不要求部署时继续提供所有集中信息。

![CTDE：训练时集中信息、执行时分散决策](/assets/img/rl-practice/faro_ch06_ctde.png)

CTDE 是信息约束范式，不是某一种 critic 架构。集中信息可进入 critic、混合网络或训练目标；具体如何使用取决于算法。策略执行所依赖的观测、历史和通信必须在部署时可获得，不能训练时偷偷多看一份执行期不存在的输入。示意图中的 critic 与回放是一类实现，并非所有 CTDE 算法的必备组件。

第 7–10 章分别讨论价值分解、反事实基线、连续控制和通信。各章要单独说明网络结构、信息来源、数据复用和预算；它们不是跨环境、等容量的统一算法排名。

## 六 · 易错点

**一、把「多 agent 对话」当成 MARL。** 多个 LLM 互相发消息、分工完成一个任务，是编排（orchestration）：没有参数更新、没有奖励信号、没有从交互中学习的过程，不属于多智能体强化学习。判断标准只有一条——**有没有策略在训练中被奖励信号改写**，与参与者是模型还是智能体无关。

**二、共享奖励 ≠ 已解决信用分配。** 共享奖励只保证「人人有信号」；信号里多少来自自己、多少来自队友，在 IQL 里是糊的。信用分配要回答的是反事实问题：如果只有我的动作变了，团队回报会变多少——这需要显式机制（值分解、反事实基线），不会因为奖励相同就自动完成。

**三、非平稳 ≠ 理论上一定不收敛。** 非平稳破坏的是「固定 MDP + 充分探索 + 递减步长 ⇒ 收敛到唯一 $Q^*$」这条标准论证的前提；某些结构（如势博弈、具备收缩性的环境、特定自博弈设定）下独立学习仍有收敛结论。正确的表述是「单智能体的收敛保证不再自动成立，需要逐案重新论证」，而不是「多智能体一定发散」。

**四、玩具环境结论的边界。** 本章三个环境都是 2 个智能体、共享奖励、小状态空间的教学环境，作用是**机制演示**：让非平稳、信息不对称、连续控制各自有一个可跑通的最小载体。它们不构成对论文方法的复现，也不能外推到大规模、异质、竞争或部分可观测的连续场景；跨环境的数字不排名，表格法与神经网络的表示差异也必须写明。

**五、两处易混口径。**「把每个 agent 的 Q 加起来 = 团队 Q」常被算在 QMIX 名下——**加和是 VDN，QMIX 是单调混合**（对每个 $Q_i$ 单调不减，不是求和），第 7 章展开；另有一个同样缩写为 IQL 的离线 RL 方法（*Implicit Q-Learning*），与本章的 Independent Q-Learning 同名不同物，引用时必须带上下文。

## 代码实现

对应复现包 `rlpractice/algos/marl/value.py`：

```python
qs = agent_qs(q_nets, ob)                             # (B, n, A)
q_taken = qs.gather(2, ac.unsqueeze(-1)).squeeze(-1)  # (B, n)

with th.no_grad():
    qns = agent_qs(tgt_nets, nob)                     # (B, n, A)
    q_next = qns.max(2).values                        # 各自独立 max，把队友当环境

# iql 与 vdn 的差别在“谁的梯度到谁”：iql 对每个 agent 分别算 TD，
# vdn 让梯度流过联合和（这里两者目标数值一致，损失形式不同）。
per_target = td_target(rew, don, gamma, q_next, mode="per_agent")
loss = th.nn.functional.smooth_l1_loss(q_taken, per_target)

opt.zero_grad()
loss.backward()
th.nn.utils.clip_grad_norm_(params, 10.0)
opt.step()
if env_steps % int(cfg["target_sync"]) == 0:          # 硬同步 target 网络
    for t, s in zip(tgt_nets, q_nets):
        soft_update(t, s, 1.0)
```

`td_target(..., mode="per_agent")` 把共享的团队奖励 $r$ 与 `don` 广播给每个智能体，各自算 $r+\gamma(1-d)\max_{a'}Q_i'(s',a')$；`don` 只在 terminated 时置 1，truncated 照常外推（第二节口径）。`qns.max(2)` 让每人只用自己网络的下一动作价值——队友被当成环境的一部分，这就是第三节所说训练非平稳问题在实现里的形态。
