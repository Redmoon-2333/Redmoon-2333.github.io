> （前言）前面几章的动作空间都是离散的：悬崖环境每步从 4 个方向里选一个，改进策略只需对 4 个 $Q$ 值直接取最大。第 9 章换成连续动作——Nav2D 里每个 agent 每步输出一个二维力向量——要回答两个问题：动作从离散变成连续之后，价值学习难在哪里；「训练时看全局、执行时看局部」在连续控制里到底解决了什么。

## 一 · 问题：从 4 个离散选择到连续力向量

离散动作下，$Q(s,a)$ 是一张可枚举的表：悬崖环境只有 4 个动作，学习就是给每个状态下的 4 个格子填数，改进策略只需 $\max_{a} Q(s,a)$，这个最大值可以老老实实逐个算出来。动作换成连续向量后，两件事同时失效。

第一，动作空间不可枚举。Nav2D 的动作是 $[-1,1]^2$ 里的一个点，理论上无穷多个；$Q(s,\cdot)$ 从「几个数」变成「关于 $a$ 的一个函数」，$\max_a Q(s,a)$ 从查表变成一次优化，DQN 那种「对每个动作各算一个 Q 再取最大」的写法没有对应物。可行的替代是把「输出动作」这件事交给一个网络：给定 $s$，由参数 $\theta$ 的函数 $\mu_\theta(s)$ 直接吐出动作，再用 critic 的梯度告诉它往哪个方向拧。

第二，多智能体让每个 agent 面对的环境不再稳定。$i$ 号 agent 学 $Q_i$ 时，回报由所有人的联合动作决定，而别人的策略也在同时更新——对 $i$ 而言，马尔可夫决策过程的转移和奖励分布一直在漂。第 6 章给出的应对框架是 CTDE（centralized training with decentralized execution）：**训练时**让 critic 看到所有 agent 的观测与动作，把「别人的策略在变」这件事作为信息显式喂给价值函数；**执行时**每个 actor 只用自己那 8 维局部观测，因为部署阶段拿不到队友信息。这里要立刻澄清一个高频误读：本章 MADDPG 架构中「看全局」的是 critic，actor 从训练到执行始终只吃局部观测——不是「训练时策略也看全局」。

无论动作离散还是连续，队友动作都可能直接影响奖励和价值。集中式 critic 对联合动作显式建模，能缓解把队友策略变化压入局部噪声的问题，但不保证目标平稳或训练收敛。它仍需面对函数逼近、分布漂移和数据覆盖不足。执行时本章 actor 只使用本地 8 维观测。

本章比较 MADDPG 的联合观测/动作 critic 与 IDDPG 的局部 critic。两组使用相同的 actor 结构、训练预算和主要超参数，但 critic 输入维度不同，相应首层参数量也不同；这是集中信息机制的对照，并非严格等容量的单变量实验。

## 二 · 连续动作下的策略梯度：确定性策略与 tanh 输出

随机策略输出的是动作分布 $\pi_\theta(a\mid s)$，确定性策略直接输出动作本身：$a=\mu_\theta(s)$。确定性策略梯度（DPG）的直觉可以写成一行：

$$\nabla_\theta J(\theta)=\mathbb{E}_{s}\Big[\nabla_\theta \mu_\theta(s)\,\nabla_a Q_w(s,a)\big|_{a=\mu_\theta(s)}\Big]$$

读法是链式法则穿过 critic：$\nabla_a Q$ 是「在当前状态下，动作往哪个方向挪能涨分」的斜率，$\nabla_\theta \mu_\theta$ 把这个斜率翻译回参数空间。和随机策略梯度相比，它不需要在动作上求和或采样期望（期望只对状态取），梯度更干净；代价是策略不再有随机性，探索必须另外解决（见第四节）。

动作边界怎么保证？本实现的 actor 输出层是 Tanh，$a=\tanh(f_\theta(o))\in(-1,1)$，边界由网络结构给出，不需要把越界动作惩罚进奖励。Tanh 饱和区梯度趋近 0，动作贴边时学习会变慢——这是硬边界换来的代价。更关键的一点：Tanh 输出仍可能与环境实际执行的动作不一致（噪声、裁剪都在其后），回放里存的必须是真正被执行的那个动作，第五节的修正②就在这里。

本环境中每个 agent 的动作维度是 2（二维力），actor 输入是 8 维局部观测。核对手段很直接：拿一批观测做一次前向，检查输出是否全部落在 $(-1,1)$；再把输出加噪声后对比裁剪前后的数值，确认入库的就是环境收到的那一份（见修正②）。

```python
def actor_forward(nets, o):                      # 每个 agent 一个 actor
    return th.stack([net(o[:, i]) for i, net in enumerate(nets)], dim=1)
# mlp(...) 的 out_act=Tanh：动作落在 (-1,1)，边界由结构给出
```

## 三 · 结构对照：MADDPG（CTDE）与 IDDPG（各看各的）

每个 agent 各有一个 actor $\mu_{\theta_i}(o_i)$，互不共享参数；差别全在 critic 的输入上：

| 项目 | MADDPG（`mode=ctde`） | IDDPG（`mode=indep`） |
|---|---|---|
| critic $i$ 输入 | 拼接 2 个观测 + 2 个动作（$2\times8+2\times2=20$ 维） | 只用自己那份 $o_i,a_i$（$8+2=10$ 维） |
| critic 数量 | 每 agent 一个，各判自己的回报 | 同左 |
| actor 输入 | 仅本地 8 维观测 | 同左 |
| 执行期信息 | 仅本地观测 | 仅本地观测 |

Nav2D 是共享奖励：两个 agent 收到同一个标量 $r$，回放按 agent 维度存联合观测 $(2,8)$ 与联合动作 $(2,2)$，每条转移只带一个 $r$ 和一个 $d$。共享奖励不改变「各判各的 $Q_i$」这一结构——同一份 $r$ 被两个 critic 分别回归，差别仍只在输入。为控制其他训练条件，两个模式共用同一套超参（$\gamma=0.95$、$\tau=0.01$、actor/critic 学习率均为 $10^{-3}$、批次 64、回放容量 20000），否则对照里就混进了第二个变量。

两类网络的更新流程相同，一个训练步里依次做三件事：

1. **critic 更新**。对批次里每个 agent $i$ 算目标 $y_i=r+\gamma(1-d)\,Q'_i(x'_i,\,a')$，其中 $a'$ 由各 agent 的 target actor 对下一观测生成，$Q'_i$ 是 $i$ 自己的 target critic（CTDE 下 $x'$ 是拼接的全局输入，独立模式下只拼自己）。critic 损失用 smooth L1 回归到 $y_i$。
2. **actor 更新**。损失是 $\max$ 的连续版：$\mathcal{L}_i=-\mathbb{E}[Q_i(x,\mu_\theta(o))]$——让 critic 给自己打的分变高。更新第 $i$ 个 actor 时把其余 actor 和全部 critic 参数冻结，梯度只落到该 actor 上。
3. **软更新**。target actor 与 target critic 各按 $\tau$ 追随在线网络。

## 四 · 训练循环：replay、软更新 τ、探索与评估

**回放**是 off-policy 的基础：固定容量 20000 的转移池存 $(o,a,r,o',d)$，攒够 1000 步后每步抽 64 条样本更新。Nav2D 没有真实终止（terminated 恒为 `False`），25 步到点属于 truncated，价值仍要 bootstrap，所以入库的 $d$ 恒为 0，$y=r+\gamma Q'$。把人为上限当成终止、把 $(1-d)$ 乘成 0，会系统性压低价值估计。

**目标网络与软更新**是两个东西，容易混：目标网络是那份「用它算 $y$ 的、结构相同的慢拷贝」，解决自举的追逐问题；软更新是它跟上在线网络的**规则**——每次更新后走一小步 $\theta'\leftarrow(1-\tau)\theta'+\tau\theta$，本实现 $\tau=0.01$；与之相对的 hard update 是每 $N$ 步整份覆盖。$\tau$ 既不是折扣也不是学习率，它是「目标网络的追随速度」。

**探索噪声与评估贪心**必须分开。确定性策略本身不带探索，训练时用 $a=\mu(o)+0.1\,\mathcal{N}(0,I)$ 再裁剪到 $[-1,1]$，靠外加高斯噪声覆盖动作空间；评估与最终测试走 `greedy` 分支，直接取 $\mu(o)$，不加噪声。评估用独立环境实例和显式种子：训练中每 6250 步在 20 局验证集（种子 10000 起）上看一次，收尾在 100 局测试集（种子 20000 起）上出数。训练回报含噪声、含探索代价，和验证/测试的贪心回报不是同一条曲线，不能直接对比。

回放里的动作来自旧策略（还带着噪声），而 actor 更新算的是当前策略在同一批观测下会输出的动作——这是 off-policy 的典型形态：critic 学「数据里那些动作」的价值，actor 优化「我现在想输出的动作」的价值，中间靠 critic 的泛化衔接。前 1000 步只收集不更新（warmup），避免用近乎随机的早期数据去拟合一个尚未成形的 critic。

## 五 · 本项目的三处修正

早期版本相对源实现做过以下三处修正，但它们不足以证明整条管线正确。本次又发现并修复两个独立缺陷：critic 输出 `[B,1]` 与奖励 `[B]` 广播成 `[B,B]` 的目标；actor 冻结标志在前向之后切换，导致第二个 actor 没有梯度。现统一标量 Q 为 `[B]`，断言预测与目标形状一致，并在每个 actor 前向前切换冻结状态。回归测试覆盖两种 critic 模式、批大小 1/4 和两个 actor 都发生参数变化。

**① 每个 critic 用「自己的」target critic 算 $y_i$。** 源版把两个 target critic 的输出平均进同一个 $y$，再拿它训练各自 critic——独立基线的更新目标里因此混进了另一个 agent 的价值判断，等于给 IDDPG 塞了集中式信息，两组结果不再只差「critic 输入」这一个变量，对照失效。本版 $y_i$ 只用 $Q'_i$，$i$ 从 1 到 2 各算各的。

**② 动作先 clip 到 $[-1,1]$ 再执行与入库。** 环境内部执行时会裁剪，源版却把裁剪前的动作写进回放：数据里记的 $a$ 与实际物理不一致，critic 学到的 $Q(s,a)$ 对应一个从未发生过的动作，且噪声越大偏差越大。本版在 `act()` 里先 `np.clip(a, -1, 1)` 再交给环境、再入池，保证「记录的动作 = 执行的动作」。

**③ actor 更新时冻结 critic 参数。** `backward()` 会计算梯度，只有 optimizer 的 `step()` 才改变其管理的参数。actor-only optimizer 不会自动更新 critic；冻结 critic 主要避免无用梯度计算与累积，同时保留 critic 对动作的导数。每个 actor 的 `requires_grad` 必须在该次前向之前设置，再执行前向、反传与更新，最后恢复。

## 六 · 环境口径：Nav2D

- **场地与动力学**：$[-1,1]^2$ 平面，2 个 agent、2 块地标，位置与地标都均匀采样（两地标间距不小于 0.4）；速度按 $v\leftarrow 0.9v+a\cdot 0.1$ 更新，位置越界裁剪到边界内。
- **动作**：连续力，二维，取值 $[-1,1]$（执行前裁剪）。
- **奖励**：$r=\big(-\sum_{\text{地标}}\min_i\|p_i-l\|-\mathbb{1}[\text{碰撞}]\big)\big/10$——每块地标到最近 agent 的距离之和取负，两 agent 距离小于 0.2 记一次碰撞扣 1，整体除以 10。
- **观测**：8 维 = 自身位置 2 + 自身速度 2 + 两个地标的相对位置 $2\times2$，**看不到队友**。
- **终止口径**：无真实终止，第 25 步一律 truncated；success 只在结算时判定——每块地标 0.5 半径内各有一个**不同**的 agent（两种配对都算成功）。评估记录里，nav2d 的碰撞计入 `fell`，对应碰撞率。

奖励除以 10 后，单步奖励常在 0.1 量级，回报的绝对数值只在本环境内有意义。

## 七 · 重训后的实测结果

原协议为每算法 5 个训练种子、每种子 62,500 联合步；验证每次 20 局（种子 10000 起），测试每种子 100 局（种子 20000 起）。历史 MADDPG/IDDPG 运行受第五节两处实现错误影响：critic 目标形状广播错误，actor 冻结/解冻又发生在 forward 之后，10 个旧检查点里第二个 actor 与初始化逐元素相同。那批数字已撤回——它们的测试成功率只有 4.0% 与 2.8%。

修正后按同一协议重训 5 个种子（`implementation_revision=policy-audit-v2`；单种子墙钟 MADDPG 370 ± 3 秒、IDDPG 343 ± 17 秒）。最终贪心测试每种子 100 局（种子 20000 起）：

| 方法 | 测试回报（跨种子 mean ± 样本 SD） | 测试成功率 | 逐种子回报 |
|---|---|---|---|
| MADDPG（集中式 critic） | −1.086 ± 0.301 | 93.6% ± 4.9% | −0.591、−1.016、−1.273、−1.219、−1.332 |
| IDDPG（各看各的） | −1.229 ± 0.379 | 90.6% ± 8.1% | −0.633、−1.288、−1.241、−1.292、−1.689 |

修复前后差距极大：同样的预算与协议，成功率从 4.0%／2.8% 升到 93.6%／90.6%。这说明那两处缺陷不是细节——第二个 actor 从不更新，等于只有一名智能体在学习，任务几乎必然失败；也说明「数字难看」有时确实是实现问题，而不是算法本身不行。

**不要过度解读方法差异。** MADDPG 的均值与成功率都略优于 IDDPG，但两者跨种子 SD 区间大幅重叠（回报 −1.086 ± 0.301 对 −1.229 ± 0.379），$n=5$ 且未做显著性检验，不能据此说集中式 critic 更好。本章的机制问题是「全局信息进入 critic 改变了什么」，这需要受控消融与更多种子来回答，而不是这组对照的排序。

## 八 · 易错点

1. **把确定性策略当成「没有探索」。** 确定性策略不自带随机性，探索靠训练期外加噪声；噪声只在训练加，评估走贪心。反过来说，评估用贪心也不代表训练过程没有探索。
2. **把目标网络与软更新混为一谈。** 目标网络是「用来自举算 $y$ 的慢拷贝」这一**结构**；软更新是 $\theta'\leftarrow(1-\tau)\theta'+\tau\theta$ 这一**同步规则**；$\tau$ 是追随速度。三者各有其物，不是同一件事的两种叫法。
3. **跨环境比回报。** Nav2D 奖励除以 10、25 步截断，与悬崖、CartPole 的奖励尺度完全不同，回报数值只在同环境、同协议内可比；不同表示（表格 vs 网络）的差异也要写明。
4. **把 CTDE 说成「训练也看全局」。** 本章 MADDPG 架构里，全局信息进入 critic；其他 CTDE 方法也可让 mixer 或集中训练目标使用全局信息。actor 自始至终只用局部观测，执行期更不存在任何全局信息。若 actor 训练时喂了全局观测，部署时就对不上了。
5. **把 25 步截断当终止。** truncated 属于人为上限，仍要 bootstrap；当成 terminated 会让 $y$ 丢掉 $\gamma Q'$ 项。
