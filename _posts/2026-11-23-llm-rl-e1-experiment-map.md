同样写着「80%」，它可以是 Qwen 答对 80 道题，也可以是小型策略在 100 局中赢了 80 局。前者测答题，后者测行动。读一张实验表，先找到这个百分数的分子、分母和产生方式。

## 1. 每种材料能回答什么

| 材料类型 | 实际发生了什么 | 能回答什么 |
|---|---|---|
| 数值与缓存复算 | 读取作者或本地已有数据，重新计算 | 公式、统计或已有输出是否一致 |
| 冻结 LLM 推理 | 模型做裁判、抽取、求解、生成程序 | 当前模型在指定输入和预算下表现如何 |
| 小策略训练 | 表格 Q 学习或小神经网络参数更新 | 控制环境中的学习机制与条件差异 |
| 原生环境测量 | 运行公开环境的原始模拟器 | 分叉是否准确、目标信号是否可测 |
| 候选协议 | 约定运行方法和统计规则 | 实验要区分哪些解释、什么结果支持继续 |

用选桥任务试着区分这些材料。把以前记录的成功数 `80` 除以局数 `100`，是**复算**。让权重固定的 Qwen 为 100 份报告选桥，是**推理评价**。让 Qwen 生成奖励程序，再用程序反馈更新 MAPPO 的 Actor 和 Critic，是**小策略训练**。写出「下次要测两种报告」且确定成功标准，则是一份**候选协议**。实际系列中，E2 的 CREDO 属于复算，E8 的压缩先导属于小策略训练。

例如 E10 的「原生 RWARE」是直接运行公开的仓储模拟器，让策略移动货架。E10 记录的是模拟动作与回报。

## 2. 每次比较都保留最直接的竞争者

若主张“LLM 反馈能指导训练”，保留原始团队奖励、随机反馈和手写进度规则。若主张“聪明地选题升级更省资源”，保留随机升级、长度规则和全交大模型。若主张“新反事实工具更省”，保留同样缓存下的旧工具。

假设各组选桥 100 局：普通 MAPPO 成功 60 局，加入 Qwen 反馈后成功 80 局。手写规则给「报齐两座桥」加分，也成功 80 局。这个纸上比较显示加分有效，而用规则就能达到同一成绩。要测语言反馈的额外价值，可以安排手写规则很难列全的报告类型，再比较两种方法。

## 3. 种子、题目和重复调用怎样计数

在 LCA 小实验中，3 个训练种子各评价 20 个初始状态，得到 60 个评价情形。计算训练之间的不确定性时，以 3 次训练为单位。

同一批 400 道数学题先用于路由，再用于拆解和能力预测。同一道题可以比较多种方法，题目总数仍是 400。同一日志的「给金标答案」与「不给金标答案」也能组成一对。

假设改奖励前，三个种子分别答对 `12/20`、`14/20`、`10/20`，改后分别答对 `15/20`、`14/20`、`14/20`。种子是控制随机初始化和采样的编号。先做三次配对相减，得到 `+15`、`0`、`+20` 个百分点，再平均为 `+11.67` 个百分点。这里的训练重复数为 3，每个数都来自同一模型对 20 个初始状态的评价。

随机种子让比较可重复，不会自动让样本独立。重复单位要跟实验问题一致。

准确率从 80% 到 85% 是提高 5 个百分点。置信区间描述指定抽样与估计方法下的不确定性。配对分析先在同一种子或同一道题内求差，再汇总。用 bootstrap 估计时，反复重抽的单位是这些配对差。

## 4. 结果与成本一起看

| 成本 | 本系列如何解释 |
|---|---|
| 环境动作 | 实际推进环境多少次；分叉也计入 |
| LLM 调用 | 包括初答、复核、额外采样和失败重试 |
| token | 分别统计输入和输出，以及本地和远程的读写量 |
| 策略训练 | 每奖励候选的种子、步数、评估预算 |
| 人工信息 | 金标选候选、真实成员、完整历史等特权条件 |

多跑一个联盟需要调用模型。恢复完整历史需要更长的输入和一次前向计算。分别记账才能看出花费集中在哪里。

## 5. 实验之间的继承关系

| 材料链 | 贯穿的问题 | 正文位置 |
|---|---|---|
| CREDO、裁判换序、语言反馈、独立复核 | 评分有没有依据、估计稳不稳 | E2 |
| LCA→奖励迁移→强规则；生成奖励→程序修正；观测混叠 | 奖励怎样影响实际学习 | E3 |
| 搜索、离线路由、复核价值、路由与能力预测 | 有限预算花在哪里 | E4 |
| 故障改派→语言分类→结构化抽取→求解与执行 | 语言怎样接上约束系统 | E5 |
| 日志归因→局部找步→回看；联盟→少量联盟；删除修复 | 责任标签与行动收益 | E6 |
| 协议泛化、证据交接、自然候选、共享模拟、MASBench 分叉 | 消息何时有用、怎样量 | E7 |
| 压缩任务源码→四种更新→160 次比较 | 内容选择与读取的联合学习 | E8、E9 |
| TeamTR 表格诊断→原生 RWARE 预试 | 旧轨迹偏差在当前预算下能否测到 | E10 |
| C02、C01 改、C03 | 下一组实验如何区分机制 | E11 |

归档中复现、扩展和持续探索共 42 个盘点单元，包括独立复核与待运行协议；压缩先导另列。这个数字描述材料覆盖，独立实验数应按各篇实际重复单位理解。
