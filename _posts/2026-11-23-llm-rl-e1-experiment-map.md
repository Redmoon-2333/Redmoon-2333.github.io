这套实践系列记录前期探索中已经留下的代码、回答和结果，以及由它们引出的下一组问题。当前正在比较研究切口，尚未选定一套完成验证的最终算法。

从[论文 P1](/2026/11/23/llm-rl-p1-learning-object/)开始读，可以先理解“谁在学习”；本篇提供实验地图。后续每篇先说明问题和比较，再解释代码与读数。

## 1. 四种材料，四种可回答的问题

| 材料类型 | 实际发生了什么 | 能回答什么 |
|---|---|---|
| 数值与缓存复算 | 读取作者或本地已有数据，重新计算 | 公式、统计或已有输出是否一致 |
| 冻结 LLM 推理 | 模型做裁判、抽取、求解、生成程序 | 当前模型在指定输入和预算下表现如何 |
| 小策略训练 | 表格 Q 学习或小神经网络参数更新 | 控制环境中的学习机制与条件差异 |
| 原生环境测量 / 候选协议 | 前者运行真实模拟器接口，后者定义待比较方案 | 分叉是否准确、信号是否可测，或下一步准备检验什么 |

例如，LLM 生成奖励程序，小 Q 表根据程序学习，更新的是小策略。CREDO 表格精确复算，没有训练 Qwen。压缩先导训练了小网络，也没有进行大模型微调。

原生环境指公开环境的原始模拟机制；它与真实机器人实机是另一层关系。

## 2. 每次比较都保留最直接的竞争者

若主张“LLM 反馈能指导训练”，保留原始团队奖励、随机反馈和手写进度规则。若主张“聪明地选题升级更省资源”，保留随机升级、长度规则和全交大模型。若主张“新反事实工具更省”，保留同样缓存下的旧工具。

这些比较分别排除不同解释。只胜过无反馈，不能判断是否需要 LLM；只胜过完全重跑，不能判断收益是否其实来自缓存。

## 3. 种子、题目和重复调用怎样计数

在 LCA 小实验中，3 个训练种子各评价 20 个初始状态，得到 60 个评价情形。真正独立训练的是 3 次；不能把 60 局当成 60 次独立训练计算置信区间。

同一批 400 道数学题先用于路由，再用于拆解和能力预测，能够形成配对分析；不能把它们相加成 1,200 道新题。同一日志的“给金标答案/不给金标答案”两个条件，也共享日志来源。

随机种子让比较可重复，不会自动让样本独立。重复单位要跟实验问题一致。

准确率从 80% 到 85% 是提高 5 个百分点。置信区间表示指定抽样与估计方法下的效应不确定性范围；配对区间先在同一种子或同一道题内求差，再汇总。bootstrap 通过重复重抽这些独立单位估计不确定性，不能把共享训练的评价局任意拆成独立样本。

## 4. 结果与成本一起看

| 成本 | 本系列如何解释 |
|---|---|
| 环境动作 | 实际推进环境多少次；分叉也计入 |
| LLM 调用 | 包括初答、复核、额外采样和失败重试 |
| token | 区分输入/输出、本地/远程，不能直接当真实延迟 |
| 策略训练 | 每奖励候选的种子、步数、评估预算 |
| 人工信息 | 金标选候选、真实成员、完整历史等特权条件 |

“多跑一个联盟”可能增加一次模型调用；“恢复历史不增加环境步”仍增加前向开销。标注这些成本，才能判断一种信号是否值得获取。

## 5. 实验之间的继承关系

| 材料链 | 贯穿的问题 | 正文位置 |
|---|---|---|
| CREDO、裁判换序、语言反馈、独立复核 | 评分有没有依据、估计稳不稳 | E2 |
| LCA→奖励迁移→强规则；生成奖励→程序修正；观测混叠 | 奖励怎样影响实际学习 | E3 |
| 搜索、离线路由、复核价值、路由与能力预测 | 有限预算花在哪里 | E4 |
| 故障改派→语言分类→结构化抽取→求解与执行 | 语言怎样接上约束系统 | E5 |
| 日志归因→局部找步→回看；联盟→少量联盟；删除修复 | 责任标签与行动收益 | E6 |
| 协议泛化、证据交接、自然候选、共享模拟、MASBench 分叉 | 消息何时有用、怎样量 | E7 |
| 压缩任务源码→四种更新→160 次比较 | 内容选择与读取的联合学习 | E8、E9 |
| TeamTR 表格诊断→原生 RWARE 预试 | 旧轨迹偏差在当前预算下能否测到 | E10 |
| C02、C01 改、C03 | 下一组实验如何区分机制 | E11 |

归档中复现、扩展和持续探索共 42 个盘点单元，包括独立复核与待运行协议；压缩先导另列。这个数字描述材料覆盖，独立实验数应按各篇实际重复单位理解。
