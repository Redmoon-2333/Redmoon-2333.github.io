上一章用 Bellman 方程说明了“价值应该自洽”，但没有回答一个更动手的问题：写代码时，TD 目标里的下一个状态价值到底取什么？Q-learning 说取 $\max_a Q(s',a)$，SARSA 说取 $Q(s',a')$——$a'$ 是实际会走的那个动作。两个函数加起来不到十行，训练出的策略却截然不同。本章用同一个悬崖网格、同一套预算跑完两算法，把这个分叉讲清楚。

## 1. 核心问题：想象最优，还是面对现实

TD 更新的通用形式是 $Q(s,a) \leftarrow Q(s,a) + \alpha[\text{target} - Q(s,a)]$，分歧全部发生在 target 的后半段：

- **Q-learning**：$\text{target} = r + \gamma \max_{a'} Q(s',a')$。它假设“从 $s'$ 开始，之后一切都按最优来”，完全不管当前行为策略实际上会怎么走。这是一种**想象中的最优**。
- **SARSA**：$\text{target} = r + \gamma Q(s',a')$，其中 $a'$ 是行为策略在 $s'$ 真正采样出来的动作。它评估的是“**按我现在这套走法继续走**，值多少”。这是**面对现实**。

差异会通过自举向前传播：更新后的 $Q(s,a)$ 会进入前驱状态的后续 target。Q-learning 用最大动作值构造最优性备份；SARSA 用行为策略采到的动作值，因而会把后续探索造成的风险计入目标。这是目标策略的区别，不等于 Q-learning 必然系统性高估、SARSA 必然系统性低估；带噪估计经过 $\max$ 引起的过估计是另一个问题。两者的初始化、学习率、探索率相同，本章比较的是这两种 target。

Q-learning 的备份用 $\max$，不对行为策略的下一动作取平均，因此是 **off-policy**；SARSA 用行为策略采出的 $a\prime$ 更新，因而是 **on-policy**。Q-learning 指向最优动作价值 $Q^*$，SARSA 控制则在评估与改进当前 $\varepsilon$-greedy 策略之间迭代。有限预算、固定学习率下，两者的估计都不能直接视为已经收敛。

行为策略 $\mu$ 产生数据，目标策略 $\pi$ 决定备份所评估的后续行为。表格 Q-learning 的标准收敛结论需要状态–动作对得到充分访问、学习率满足随机逼近条件，并满足折扣或适当的回合终止条件；不是任意 $\mu$ 都能学到 $Q^*$。它可利用其他策略产生的有效环境转移，但数据覆盖仍然重要。SARSA 的目标策略与行为策略一致。训练时固定 $\varepsilon>0$，测试时改成 $\varepsilon=0$，确实换了执行策略，但这不意味着从 $Q^\pi$ 贪心改进本身有错。

终止时两者都不 bootstrap（`target = r`），这与第 1 章的 terminated/truncated 口径一致，见第 8 节。

## 2. 代码里的两个更新函数

实现位于复现包 `rlpractice/algos/single/tabular.py`，逐行对照：

```python
def qlearning_update(Q, s, a, r, s2, terminated, alpha, gamma):
    target = r if terminated else r + gamma * np.max(Q[s2])
    Q[s, a] += alpha * (target - Q[s, a])

def sarsa_update(Q, s, a, r, s2, a2, terminated, alpha, gamma):
    target = r if terminated else r + gamma * Q[s2, a2]
    Q[s, a] += alpha * (target - Q[s, a])
```

唯一的区别是 `np.max(Q[s2])` 与 `Q[s2, a2]`。主循环里的结构差异也要注意：Q-learning 更新后才重新选动作；SARSA 必须**先在 $s'$ 采出 $a'$，再做更新**，因此多一个参数。

最终评估也写在同一份实现里：greedy 模式用 `np.argmax` 直接取最大动作，stochastic 模式复用训练时的 `epsilon_greedy`（$\varepsilon=0.1$），并且整个评估过程**共享同一个随机数生成器**——若每步重播种，采样序列会出现周期性模式，同一策略的评估结果会随实现细节漂移。

## 3. ε-greedy 与平局约定

行为策略统一是 $\varepsilon$-greedy（$\varepsilon=0.1$）：以 0.1 概率均匀随机选 4 个动作之一，否则取 $Q$ 值最大的动作。平局由 `np.argmax` 固定解决——**返回第一个最大值的索引，因此全零初始化时固定返回动作 0（全零只是特例：只要动作 0 属于最大值集合就返回 0）**，与源教学代码一致。这条约定在表格初始化为全 0 的早期训练中影响很大：不加处理的话，智能体初始会固定向某个方向走；固定到动作 0 至少让初始行为可复现、可解释。读别人的 RL 代码时，`np.argmax` 的平局行为是最容易被忽略、又最能解释“为什么我这版跑出来不一样”的细节之一。

还要分清两个阶段的随机性：**训练阶段**用 $\varepsilon$-greedy 采数据并更新 $Q$；**评估阶段**由协议决定，greedy 模式取纯 $\arg\max$（$\varepsilon=0$），stochastic 模式仍按 $\varepsilon=0.1$ 采样。同一个 $Q$ 表、两种读法，第 5、6 节的全部差异都建立在这条区分上。

## 4. 手算对照：一次 Q-learning 与一次 SARSA 更新

设当前状态 $s$、动作 $a$，走到 $s'$ 得到 $r=-1$，未终止；$\gamma=1$，$\alpha=0.5$；当前 $Q(s,a)=0$，$s'$ 处四个动作的 $Q$ 行为 $[-2,\,-3,\,-2,\,-4]$，而实际采样出的 $a'=1$。

**Q-learning：**

$$\text{target} = -1 + \max_{a'} Q(s',a') = -1 + (-2) = -3$$

$$Q(s,a) \leftarrow 0 + 0.5 \times (-3 - 0) = -1.5$$

**SARSA（$a'=1$）：**

$$\text{target} = -1 + Q(s',1) = -1 + (-3) = -4$$

$$Q(s,a) \leftarrow 0 + 0.5 \times (-4 - 0) = -2.0$$

同一条转移、同一张 $Q$ 表，Q-learning 取 $s\prime$ 处最大的估计，SARSA 取实际采到的动作估计，所以本例得到 $-1.5>-2.0$。这个大小关系来自备份规则，不能据此判断哪一个偏离了其目标价值，也不能把 SARSA 一概称作“悲观估计”。

若取 $\alpha=1$，两个更新值分别为 $-3$ 和 $-4$。后续访问前驱状态时，这些值还会参与备份，差异因而可能向前传播；传播方式取决于后续动作、转移和折扣，并不是“乐观或悲观沿链相乘”。

## 5. 实测：同一个悬崖，两种性格

实验口径：5 个训练种子（0–4），每种子 100,000 环境步预算，$\alpha=0.5$、$\gamma=1.0$、$\varepsilon=0.1$、单局上限 100 步；训练中每 10,000 环境步做一次 20 局贪心验证（种子从 10000 起），只用于观察学习过程；最终测试用保留测试种子（20000 起）每种子 100 局、共 5 种子，greedy 与 stochastic 两套模式**分别落盘**。下表全部为最终测试数字，均值 ± 跨种子 SD。

在没有探索噪声时，贴崖走的 7 步路线回报最高。表中 Q-learning 的贪心策略走出了这条路线；SARSA 的平均局长更长且存在截断。局长均值混合了成功、失败和截断回合，不能把 20 步量级的均值直接当成一条已证最优的绕行路线。

| 算法 | 模式 | return ± SD | 成功率 | 掉崖率 | 截断率 | 局长 |
|---|---|---|---|---|---|---|
| Q-learning | greedy | 0.760 ± 0.000 | 100.0% | 0.0% | 0.0% | 7.0 |
| Q-learning | stochastic | 0.448 ± 0.000 | 85.0% | **15.0%** | 0.0% | 7.3 |
| SARSA | greedy | −0.320 ± 2.057 | 80.0% | 0.0% | **20.0%** | 28.8 |
| SARSA | stochastic | −0.026 ± 1.113 | 85.6% | 9.0% | 5.4% | 20.7 |

SARSA 的 target 会计入后续 $\varepsilon$-greedy 探索带来的风险，因而可能偏向离崖更远的路线。$\varepsilon=0.1$ 表示每步以 10% 概率进入随机选动作分支，不是 10% 掉崖率：若四个动作均匀采样、其中一个会掉崖且贪心动作安全，则该状态单步掉崖概率是 $0.1/4=2.5\%$；整局风险还取决于沿途状态与访问次数。本次 stochastic 测试中，SARSA 的掉崖率为 9.0%，低于 Q-learning 的 15.0%，但平均回报也更低。Q-learning 的最大值备份不计后续探索动作的风险，贪心测试走出 7 步路线、掉崖率为 0%；加回探索后，掉崖率升至 15.0%。

## 6. SARSA 的贪心截断能说明什么

本次 SARSA 贪心评估掉崖率为 0%，但截断率为 **20.0%**，成功率 80%，return 为 −0.320 ± 2.057，局长 28.8；验证成功率也从首次 100% 退到末次 80%。这些数字说明部分最终贪心策略未能在 100 步内到达目标，不能归因为 on-policy 的必然缺陷。对精确 $Q^\pi$，在策略改进定理的适用条件下，贪心改进不会降低价值；这里使用的是有限预算、固定学习率训练出的估计表，尚有估计误差及未收敛的可能。Q-learning 本次五种子的贪心测试 SD 为 0.000，也不表示它在一般情形下不会成环。

加回探索后，SARSA 的 return 为 −0.026、成功率 85.6%、截断率 5.4%。这是另一个执行策略的实测表现；随机动作可能帮助离开某些滞留状态，但仅凭汇总指标不能确定具体机制。

一种待检查的机制是确定性动作选择造成滞留或循环。`np.argmax` 返回第一个最大值的索引，不是一律返回动作 0；只有动作 0 也属于最大值集合时才会选它。要确认本例原因，需要逐种子查看最终 $Q$ 表、沿轨迹记录动作及平局位置，并区分估值误差、循环和单纯路径过长。掉崖率为 0 或早期验证曾成功，都不足以排除最终策略没有学好的可能。

## 7. 同局数 ≠ 同预算

两算法都是**每种子 100,000 环境步，5 个种子合计 500,000 步**。Q-learning 的 **67,979 回合**与 SARSA 的 **40,757 回合**是五种子训练回合数之和，不是单个 100,000 步运行的回合数。按总步数除以总回合数，训练平均局长约为 7.36 与 12.27 步；不能用最终贪心测试的 7.0 与 28.8 步来解释训练回合总数。固定环境步预算时，回合数受训练过程中的局长影响，因此曲线应按环境步对齐。总回合数之比也不能推出某个中间回合检查点恰好多用了多少交互。

## 8. 本变体与 Sutton 标准 CliffWalking 的差异

Sutton & Barto 的标准 CliffWalking 是回合任务：掉崖扣分并回到起点，**掉崖不终止，到达目标才终止**。本变体（`rlpractice/envs/cliff.py`）改为**掉崖和到达目标都 terminated**，两者都不 bootstrap。100 步上限作为采样保护记为 truncated，并保留 bootstrap；这不要求把任务称为持续任务。

差异不只是记分方式。掉崖即终止意味着该次交互的 target 就是惩罚本身 $r$，当前状态–动作值不再包含掉崖后继续行动的回报；这也让“掉崖率”成为可直接统计的终止事件，表格里的掉崖率与截断率互斥（掉崖就不可能再截断）。引用本章数字时必须带上这条变体差异，不能与文献中的 CliffWalking 数字直接对表。

## 9. 易错点

下面四条在本章的实测数字里各有一个对应反例，改动评估口径前先对照它们。

1. **训练回报含探索噪声，不能当性能。** 训练曲线上的 return 是 $\varepsilon$-greedy 行为策略的回报，混着随机动作，还与评估局数、种子有关；性能结论只能来自保留测试种子上的最终评估，且要注明模式与局数。
2. **两种评估模式不能混报。** greedy 与 stochastic 是同一 $Q$ 表的两种读法，Q-learning 贪心 0% 掉崖、带探索 15% 掉崖就是同一份参数的两面；挑一列下结论等于换问题。
3. **单种子不足以谈提升。** 本章全部数字为 5 种子均值 ± SD，且 SD 是误差带不是显著性检验；SARSA greedy 的 SD 高达 2.057，均值不足以代表每个种子的表现。
4. **平均回报更高 ≠ 更安全。** 同为 stochastic 模式，Q-learning 的 return 0.448 高于 SARSA 的 −0.026，但掉崖率是 15.0% 对 9.0%——回报和风险是两个维度，“更会赚分”不等于“更少掉崖”，两者要分别报告。
