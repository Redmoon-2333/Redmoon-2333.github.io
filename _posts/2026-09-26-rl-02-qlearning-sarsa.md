> 写代码时，TD 目标里的下一个状态价值到底取什么？Q-learning 说取 $\max_a Q(s',a)$，SARSA 说取 $Q(s',a')$——$a'$ 是实际会走的那个动作。两个函数训练出的策略却截然不同。本章用同一个悬崖网格、同一套预算跑完两算法，把这个区别和选择的细节讲清楚。

## 一 · 核心问题：想象最优，还是面对现实

TD 更新的通用形式是 $Q(s,a) \leftarrow Q(s,a) + \alpha[\text{target} - Q(s,a)]$，分歧全部发生在 target 的后半段。

先把两个角色说清：**行为策略**是实际产生数据的策略——智能体每一步按它选动作，本章记作 $\mu$；**目标策略**是被评估、被改进的策略，本章记作 $\pi$。两个算法的分歧，全在 target 按哪个策略来算。

- **Q-learning**：$\text{target} = r + \gamma \max_{a'} Q(s',a')$。它假设“从 $s'$ 开始，之后一切都按最优来”，完全不管当前行为策略实际上会怎么走。这是一种**想象中的最优**。
- **SARSA**：$\text{target} = r + \gamma Q(s',a')$，其中 $a'$ 是行为策略在 $s'$ 真正采样出来的动作。它评估的是“**按我现在这套走法继续走**，值多少”。这是**面对现实**。

差异会通过自举向前传播：更新后的 $Q(s,a)$ 会进入前驱状态（之后会走到 $s$ 的那些状态）的后续 target。Q-learning 用最大动作值构造最优性备份（backup：用一步奖励加后继价值更新当前估计的那一步）；SARSA 用行为策略采到的动作值，因而会把后续探索造成的风险计入目标。这是目标策略的区别；带噪估计经过 $\max$ 引起的过估计属于另一个问题，与目标策略之别无关。两者的初始化、学习率、探索率相同，本章比较的是这两种 target。

Q-learning 的备份用 $\max$，不对行为策略的下一动作取平均，因此是 **off-policy**（target 评估的不是产生数据的那个策略）；SARSA 用行为策略采出的 $a\prime$ 更新，因而是 **on-policy**（评估的正是产生数据的策略本身）。Q-learning 指向最优动作价值 $Q^*$，SARSA 控制则在评估与改进当前 $\varepsilon$-greedy 策略之间迭代。有限预算、固定学习率下，两者的估计都不能直接视为已经收敛。

行为策略 $\mu$ 产生数据，目标策略 $\pi$ 决定备份所评估的后续行为。表格 Q-learning 的标准收敛结论需要状态–动作对得到充分访问、学习率满足随机逼近的衰减条件（不能太大，也不能长期固定不变），并满足折扣或适当的回合终止条件；覆盖条件同样落在 $\mu$ 上。它可利用其他策略产生的有效环境转移，但数据覆盖仍然重要。SARSA 的目标策略与行为策略一致。训练时固定 $\varepsilon>0$，测试时改成 $\varepsilon=0$，换的是执行策略；贪心改进的依据是训练出的 $Q^\pi$，这一步改动不影响它。

终止时两者都不 bootstrap（`target = r`），这与第 1 章的 terminated/truncated 口径一致，见第 8 节。

## 二 · 代码里的两个更新函数

实现位于复现包 `rlpractice/algos/single/tabular.py`，逐行对照：

```python
def qlearning_update(Q, s, a, r, s2, terminated, alpha, gamma):
    target = r if terminated else r + gamma * np.max(Q[s2])
    Q[s, a] += alpha * (target - Q[s, a])

def sarsa_update(Q, s, a, r, s2, a2, terminated, alpha, gamma):
    target = r if terminated else r + gamma * Q[s2, a2]
    Q[s, a] += alpha * (target - Q[s, a])
```

唯一的区别是 `np.max(Q[s2])` 与 `Q[s2, a2]`。主循环里的结构差异也要注意：Q-learning 更新后才重新选动作；SARSA 必须**先在 $s'$ 采出 $a'$，再做更新**，因此多一个参数。

最终评估也写在同一份实现里：greedy 模式用 `np.argmax` 直接取最大动作，stochastic 模式复用训练时的 `epsilon_greedy`（$\varepsilon=0.1$），并且整个评估过程**共享同一个随机数生成器**——若每步重新设置随机种子，采样序列会出现周期性模式，同一策略的评估结果会随实现细节漂移。

## 三 · ε-greedy 与平局约定

行为策略（实际产生数据的那套策略，即第 1 节的行为策略 $\mu$）统一是 $\varepsilon$-greedy（$\varepsilon=0.1$）：以 0.1 概率均匀随机选 4 个动作之一，否则取 $Q$ 值最大的动作。取最大靠 `np.argmax`，它有一个很容易被忽略的约定：**多个动作的 $Q$ 值相等（平局）时，返回索引最小的那个**。表格初始化为全 0 时，每个状态下 4 个动作的 $Q$ 值全相等，于是每一步都选动作 0，智能体开局会固定朝同一个方向走。全零只是最显眼的情形：只要动作 0 属于最大值集合，平局时选中的就是它。这条约定让初始行为可复现、可解释；读别人的 RL 代码时，平局处理也是最容易被忽略、又最能解释“为什么我这版跑出来不一样”的细节之一。

还要分清两个阶段的随机性：**训练阶段**用 $\varepsilon$-greedy 采数据并更新 $Q$；**评估阶段**由协议决定，greedy 模式取纯 $\arg\max$（$\varepsilon=0$），stochastic 模式仍按 $\varepsilon=0.1$ 采样。同一个 $Q$ 表、两种读法，第 5、6 节的全部差异都建立在这条区分上。

## 四 · 手算对照：一次 Q-learning 与一次 SARSA 更新

设当前状态 $s$、动作 $a$，走到 $s'$ 得到 $r=-1$，未终止；$\gamma=1$，$\alpha=0.5$；当前 $Q(s,a)=0$，$s'$ 处四个动作的 $Q$ 行为 $[-2,\,-3,\,-2,\,-4]$，而实际采样出的 $a'=1$。

**Q-learning：**

$$\text{target} = -1 + \max_{a'} Q(s',a') = -1 + (-2) = -3$$

$$Q(s,a) \leftarrow 0 + 0.5 \times (-3 - 0) = -1.5$$

**SARSA（$a'=1$）：**

$$\text{target} = -1 + Q(s',1) = -1 + (-3) = -4$$

$$Q(s,a) \leftarrow 0 + 0.5 \times (-4 - 0) = -2.0$$

同一条转移、同一张 $Q$ 表，Q-learning 取 $s\prime$ 处最大的估计，SARSA 取实际采到的动作估计，所以本例得到 $-1.5>-2.0$。这个大小关系来自备份规则本身：Q-learning 备份最优后继，SARSA 备份行为策略实际走出的后继，两者评估的目标不同。

若取 $\alpha=1$，两个更新值分别为 $-3$ 和 $-4$。后续访问前驱状态时，这些值还会参与备份，差异因而会沿备份向前传播，具体形态取决于后续动作、转移和折扣。

## 五 · 实测同一个悬崖

实验口径：5 个训练种子（0–4），每种子 100,000 环境步预算，$\alpha=0.5$、$\gamma=1.0$、$\varepsilon=0.1$、单局上限 100 步；训练中每 10,000 环境步做一次 20 局贪心验证（种子从 10000 起），只用于观察学习过程；最终测试用保留测试种子（20000 起）每种子 100 局、共 5 种子，greedy 与 stochastic 两套模式**分别落盘**。下表全部为最终测试数字（5 个种子、每种子 100 局），均值 ± 跨种子 SD。

在没有探索噪声时，贴崖走的 7 步路线回报最高。表中 Q-learning 的贪心策略走出了这条路线；SARSA 的平均局长更长且存在截断。局长均值混合了成功、失败和截断回合，20 步量级是三者混合后的结果。

| 算法 | 模式 | return ± SD | 成功率 | 掉崖率 | 截断率 | 局长 |
|---|---|---|---|---|---|---|
| Q-learning | greedy | 0.760 ± 0.000 | 100.0% | 0.0% | 0.0% | 7.0 |
| Q-learning | stochastic | 0.448 ± 0.000 | 85.0% | **15.0%** | 0.0% | 7.3 |
| SARSA | greedy | −0.320 ± 2.057 | 80.0% | 0.0% | **20.0%** | 28.8 |
| SARSA | stochastic | −0.026 ± 1.113 | 85.6% | 9.0% | 5.4% | 20.7 |

SARSA 的 target 会计入后续 $\varepsilon$-greedy 探索带来的风险，因而可能偏向离崖更远的路线。$\varepsilon=0.1$ 表示每步以 10% 概率进入随机选动作分支，不是 10% 掉崖率：若四个动作均匀采样、其中一个会掉崖且贪心动作安全，则该状态单步掉崖概率是 $0.1/4=2.5\%$；整局风险还取决于沿途状态与访问次数。在上表的 stochastic 模式里（同一批测试局、按策略采样执行），SARSA 的掉崖率为 9.0%，低于 Q-learning 的 15.0%，但平均回报也更低。Q-learning 的最大值备份不计后续探索动作的风险，贪心测试走出 7 步路线、掉崖率为 0%；加回探索后，掉崖率升至 15.0%。

## 六 · SARSA 的贪心截断能说明什么

这组数字来自第 5 节的 SARSA 贪心行：掉崖率为 0%，但截断率为 **20.0%**、成功率 80%、return −0.320 ± 2.057、平均局长 28.8 步；训练期验证成功率也从首个验证点的 100% 退到末个验证点的 80%。部分种子最终学到的贪心策略未能在 100 步内到达目标。策略改进定理（对精确价值逐状态做贪心选择，得到的新策略不会更差）的贪心改进保证作用于精确的 $Q^\pi$；本章的贪心策略从有限预算、固定学习率训练出的估计表里提取，两者之间隔着估计误差与未收敛。Q-learning 在同一次最终测试里 5 个种子的贪心回报 SD 为 0.000，这个数值描述的是本次最终测试的跨种子离散度。

换回带探索的 stochastic 模式后（第 5 节表格的最后一行），SARSA 的 return 为 −0.026、成功率 85.6%、截断率 5.4%。这是另一个执行策略的实测表现；随机动作可能帮助离开某些滞留状态，但仅凭汇总指标不能确定具体机制。

一种待检查的机制是确定性动作选择造成滞留或循环：`np.argmax` 在平局时返回索引最小的动作，动作 0 只要与最大值并列，被选中的就是动作 0。要确认本例原因，需要逐种子查看最终 $Q$ 表、沿轨迹记录动作及平局位置，并区分估值误差、循环和单纯路径过长。掉崖率为 0 或早期验证曾成功，都不足以排除最终策略没有学好的可能。

## 七 · 同局数 ≠ 同预算

两算法都是**每种子 100,000 环境步，5 个种子合计 500,000 步**。Q-learning 的 **67,979 回合**与 SARSA 的 **40,757 回合**是 5 个种子各训练 100,000 环境步所累计的回合数之和。按总步数除以总回合数，训练平均局长约为 7.36 与 12.27 步，这与最终贪心测试的 7.0 与 28.8 步属于两个口径。固定环境步预算时，回合数受训练过程中的局长影响，因此曲线应按环境步对齐；中间的回合检查点各自用了多少交互，要按环境步分段统计。

## 八 · 本变体与 Sutton 标准 CliffWalking 的差异

两种变体的差异已在第 1 章第五节列出：标准版掉崖扣分并回到起点、不终止，本变体（`rlpractice/envs/cliff.py`）掉崖与到达目标都 terminated、都不 bootstrap，100 步上限记为 truncated。这里补上它对本章数字的两个直接影响：掉崖即终止，该次交互的 target 就是惩罚本身 $r$，当前状态–动作值不再包含掉崖后继续行动的回报；“掉崖率”因此成为可直接统计的终止事件，与截断率互斥（掉崖就不可能再截断）。引用本章数字前先确认变体，不能与文献中的 CliffWalking 数字直接对表。

## 九 · 易错点

下面四条在本章的实测数字里各有一个对应反例，改动评估口径前先对照它们。

1. **训练回报含探索噪声，不能当性能。** 训练曲线上的 return 是 $\varepsilon$-greedy 行为策略的回报，混着随机动作，还与评估局数、种子有关；性能结论只能来自保留测试种子上的最终评估，且要注明模式与局数。
2. **两种评估模式不能混报。** greedy 与 stochastic 是同一 $Q$ 表的两种读法，Q-learning 贪心 0% 掉崖、带探索 15% 掉崖就是同一份参数的两面；挑一列下结论等于换问题。
3. **单种子不足以谈提升。** 本章全部数字为 5 种子均值 ± SD，且 SD 是误差带不是显著性检验；SARSA greedy 的 SD 高达 2.057，均值不足以代表每个种子的表现。
4. **平均回报更高 ≠ 更安全。** 同为 stochastic 模式，Q-learning 的 return 0.448 高于 SARSA 的 −0.026，但掉崖率是 15.0% 对 9.0%——回报和风险是两个维度，“更会赚分”不等于“更少掉崖”，两者要分别报告。
