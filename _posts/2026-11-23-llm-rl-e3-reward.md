两个成员各触发一个开关，门才会打开。原任务要等有成员进门才给分。刚开始随机走动时，可能很多局都看不到 1 分。如果成员在走近开关时也得到训练信号，小策略能更早看见已有进展。本地实验把这种额外信号叫**奖励塑形**。

## 1. LCA 机制复做：有信息的奖励能加快前期学习

本地任务是一张简化双开关地图：两个成员触发开关，打开门，至少一人到终点。训练使用表格独立 Q 学习，每组 3 个种子，各评价 20 个出生组合。

偏好是两张状态之间的选择，比如成员已踩下开关的状态比还在走廊的状态更接近任务完成。一条手写规则先为成对状态投票，再人为翻转部分标签，构造 70% 或 80% 正确率。Bradley–Terry 评分表根据这些票拟合每个状态的分数，相邻状态的分差给成员提供额外奖励。标签由合成规则生成，原文的语言裁判路线见 [P3](/2026/11/23/llm-rl-p3-credit-assignment/)。

| 条件 | 模拟票数 | 3,000 步成功数 | 36,000 步成功数 |
|---|---:|---:|---:|
| 无塑形 | 0 | 0/60 | 60/60 |
| 70% 正确，全集单票 | 4,400 | 53/60 | 60/60 |
| 70% 正确，全集四票 | 17,600 | 51/60 | 60/60 |
| 70% 正确，子集四票 | 4,400 | 44/60 | 60/60 |
| 80% 正确，全集单票 | 4,400 | 54/60 | 60/60 |
| 80% 正确，子集四票 | 4,400 | 41/60 | 60/60 |

在 `3,000` 步读同一列，无塑形组是 `0/60`，70% 正确的全集单票组是 `53/60`。到 `36,000` 步两组都到 `60/60`，支持前期学得更快。等预算时，「全集单票」给更多状态对各投一票，「子集四票」给少一些状态对各投四票。追加四批标签后，70% 条件下两种分法的早期成功数差为 `−3、+5、+1、−13`，首批的排序随标签批次变化。

## 2. 迁移奖励之后，加上手写强基线

把源队合成偏好学得的评分表冻结，再给角色权限不同的目标队训练。9,000 步时，两队无塑形的成功数为 23/100、0/100，迁移评分表为 97/100、90/100。

后续加入“里程碑＋距离”手写规则，两队同一检查点都达到 100/100；不同源评分表效果还会波动。迁移相对无塑形的收益保留，研究问题转为：语言或学习奖励能在哪些规则难写、依赖会改变的任务上提供额外价值？

## 3. LLM 写奖励程序，更新的是小策略

另一个网格任务把子任务依赖从 v1 改为 v2。冻结语言模型生成或修订奖励代码，再用 Q 学习训练小策略。比较保留旧奖励、从头生成、根据新依赖修订，以及手写势函数。

每组有 5 条生成链，每个奖励候选再取 6 个策略训练种子的平均；同链的连续修订轮次相关。初始结果中，large 模型修订奖励的平均成功率约 0.567，从头生成约 0.465；medium 修订旧表为 0.367。程序检查发现 90 份奖励中 31 份崩溃：15 份涉及沙箱不允许的导入，15 份回答截断，1 份名称错误。

修复执行管线并补采截断项后，medium 修订组达到 0.723，改变了原先的排序。看这张表之前，要先确认哪些程序能运行。过了执行检查，再测奖励是否表达任务目标以及策略最后能否通关。

## 4. 最小 Q 更新看见奖励落在哪里

```python
q = 0.2                 # 小策略对当前状态动作的估计
team_reward = 0.0
member_score_change = 0.4
shaping_weight = 0.25
next_best_q = 0.5
gamma = 0.9
learning_rate = 0.1

training_reward = (
    team_reward + shaping_weight * member_score_change
)
target = training_reward + gamma * next_best_q
q += learning_rate * (target - q)
print(*(round(x, 3) for x in (training_reward, target, q)))
# 0.1 0.55 0.235
```

手算时先看眼前一步。团队奖励为 `0`，状态评分上升 `0.4`，乘权重 `0.25` 后，这一步训练奖励变成 `0.1`。下一状态估计的最佳价值为 `0.5`，乘折扣 `0.9` 得 `0.45`，相加得到 TD 目标 `0.55`。旧 Q 值 `0.2` 朝目标挪 `10%`，增加 `0.035`，变成 `0.235`。如果沿同一步去掉塑形，目标是 `0.45`，同样的更新会得到 `0.225`。

环境真正终止时，TD 目标只取当步的训练奖励。更新写回的是 Q 表中的一个状态动作格，生成奖励的语言模型保持冻结。

## 5. 势函数的轨迹恒等式与实际训练

标准势塑形项为 $F_t=\gamma\Phi(s_{t+1})-\Phi(s_t)$。折扣累加后：

$$
\sum_{t=0}^{T-1}\gamma^tF_t
=-\Phi(s_0)+\gamma^T\Phi(s_T).
$$

$\Phi(s)$ 给状态一个进度分，叫势函数。取 `γ=0.9`，设起点、路上、终点的势分别为 `1、2、0`。两步的塑形分是 `0.9×2−1=0.8` 和 `0.9×0−2=−2`。按回报的折扣相加，得到 `0.8+0.9×(−2)=−1`，恰好是负的起点势。终点势为零时，每条从同一起点出发的轨迹都加上这同一个常数。固定长度且终点势相同，也会得到与动作无关的边界项。若手动屏蔽等待动作，原来抵消的两项要重新核对。

本地观测混叠实验进一步问：即使整轨迹塑形满足恒等式，局部观察下的短步 TD 会不会受影响？若 Critic 无法表示相应势，有限数据、投影和 bootstrap 就可能改变学习。

在 FrozenLake 留出图上，正负隐藏残差势造成精确分析 9.27、有限日志 15.46 个百分点成功率绝对差；Taxi 为 3.75、3.74。合计 28 场景、约 259.8 万转移，双环境晋级门槛未通过，保留作机制案例。

## 6. 奖励—估计器相容性目前还是待测协议

「六臂」指六组使用不同更新规则的训练对照，包括只看局部信息的 TD、能看全局的 Critic、较长的回报，以及直接补偿势值等。目前完成的是协议和公式核算。

协议中的线性回归 $R^2$ 约为 0.411。按 `1−0.411=0.589`，约 58.9% 的势值方差落在该线性模型的残差里。局部观察究竟保留多少信息，还要看表示和预测模型。
