## 前言

漫长的暑假后，终于迎来了新学期。第一天两门课分别是《人工智能导论》和《智能计算系统》，第一节课听下来发现两门课的内容重叠度很高，但侧重不同——导论负责回答"AI 是什么、从哪来"，智能计算系统负责回答"大模型需要什么系统、为什么底层卡脖子"。于是借助AI，将两门课的内容进行一番重组。

## 1. 两门课怎么分工

| | 人工智能导论 | 智能计算系统 |
| --- | --- | --- |
| 定位 | 基础原理 | 深度学习与大模型的工程落地 |
| 内容 | 搜索方法、知识表示、机器学习基础、神经网络、强化学习 | 连接主义一条线：神经网络 → 深度学习 → 大模型；芯片、指令集、框架、部署 |
| 考核 | 3-4 次编程作业 + 知识点考试 | 平时 10%（编程实践）+ 系统架构与设计原则考试 |
| 特色 | 作业全是代码 | 作业不强制统一实现，但必须解读背后原理 |

## 2. 共同的题眼：AI 到底是什么

- 早期定义"像人一样思考/行动"在大模型时代失效了：图像识别、语音识别都超过人，"像人"反而成了低标准。老师认为现在对AI的新定义还没人给出，"可能要等你们这代来定义"。
- 工作定义：用计算机模拟、延伸、扩展人的智能，让机器感知环境、获取知识、使用知识获得最佳结果。
- 图灵测试：A 房间放人、B 房间放机器，裁判问 1000 个问题分不出谁是谁，就算机器有智能。
- 中文房间（塞尔）的反驳：不懂中文的人拿着规则书也能"答对"，但他不懂中文。老师把它直接接到大模型：大模型是黑盒，只是把符号按函数拟合出结果——"它到底懂不懂"和中文房间是同一个问题，至今没有答案。

## 3. 三大流派一张表

| 流派 | 核心思想 | 强项 | 局限 |
| --- | --- | --- | --- |
| 符号主义 | 万事皆可符号化，规则推理 | 数学、几何、交通规则等规则明确领域 | 不通用；情感与模糊知识无法符号化 |
| 行为主义 | 控制论，感知-动作闭环 | 机器人运动控制（人形机器人底层仍是 MPC） | 难出抽象认知与通用能力 |
| 连接主义 | 神经网络拟合 X→Y | 通用性最强，大模型基石 | 概率性错误，黑盒 |

有意思的是符号主义的回归：几何题先把点和边编成字符串、转成自然语言，再让语言模型按语言逻辑解出来——符号化知识和连接主义模型正在融合，AlphaGeometry 这类工作就是这个思路。

## 4. 合并的历史时间线

| 年份 | 事件 | 备注 |
| --- | --- | --- |
| 约前 1000 | 《列子·汤问》偃师造人 | 能歌善舞的假人，拆掉心肝肾分别失能——最早的"机器人叙事" |
| 1943 | M-P 神经元模型 | 连接主义的起点 |
| 1948 | 维纳控制论、香农信息论 | AI 的理论骨架 |
| 1950 | 图灵《Computing Machinery and Intelligence》 | 图灵测试 |
| 1956 | 达特茅斯会议 | "人工智能"命名，今年 70 周年 |
| 1958/1969 | 感知机 /《Perceptrons》 | 第一次寒冬（XOR 局限） |
| 1974/1986 | BP 算法（Werbos 提出，Hinton 等在 Nature 推广） | 老师原话："BP 是捡了别人的瓜" |
| 1998 | LeCun LeNet | CNN 初成体系 |
| 2006 | Hinton 深度信念网络 | 深网可训练 |
| 2012 | AlexNet + GPU | 爆发拐点：22 岁实习生，ImageNet 错误率骤降约 9 个百分点 |
| 2014/2015/2017 | GAN / ResNet / Transformer | Goodfellow、何恺明、Attention 论文 |
| 2022 | ChatGPT | 弱 AI 向 AGI 过渡的"1.5 时代" |
| 2024 | 诺贝尔物理奖（Hopfield/Hinton）、化学奖（AlphaFold） | 学术承认到位 |
| 2025 | DeepSeek 等国产模型、世界模型生成可玩游戏 | 每两三个月一次大新闻 |

贯穿时间线的规律是年轻化：引发这波变革的人几乎都在 30 岁以下，知识半衰期 3-6 个月。学科源头上，AI 从三段论、归纳法、数理逻辑、控制论一路杂糅而来，二战密码破译催生的电子计算机给了它物质基础——它从出生起就是交叉学科。

## 5. 全课最重要的世界观：高维世界只能拟合

导论课把"为什么"讲透：物理定律（F=ma、E=mc²）是一两个字母的"低维精确"，只在理想的低维空间成立；现实世界是高维的——描述一个同学要上万个维度，关系复杂到三维以上，简洁的物理定律就找不到了（三体问题）。高维没有解析解，只能靠数据拟合：W·X 先来一条直线，激活函数把直线掰弯，多层复合拧出任意曲线。神经网络本质上是高维世界的函数拟合器，黑盒但可行。

智能计算系统继而把怎么做解释了一下：连接主义就是这条拟合路线，"又深又宽"的网络就是大模型；神经元本身没有智能，智能在连接里——连接强弱就是权重 W，"系数就是智能"，训练就是调节连接。皮层约 160 亿神经元、每个上万个突触，年轻时连接多所以学得快。

## 6. 产业现状：应用强、底座弱

智能计算系统给出四层判断：

| 层 | 现状 |
| --- | --- |
| 应用层 | 国内市场大、迭代快，但利润薄 |
| 算法层 | 与国际差距小，开源活跃 |
| 系统层 | CUDA 生态垄断，国产框架兼容性生态差 |
| 芯片层 | 英伟达垄断，最薄弱；CPU+GPU 异构效率低能耗高 |

趋势判断：端侧大模型。下一代智能终端 = "AI Agent + 专用芯片"，手机本地推理，大模型统管输入输出与任务调度（老师以苹果的路线为例）。现在的"主机+板卡+风扇空调"是过渡形态。加上导论课的行业观察——代码生成冲击 30%-50% 的初级开发测试岗位，软件工程价值向架构与 AI 集成迁移——整体图景是：纯应用层会越来越卷，价值在向底层和系统层迁移。

## 7. 老师给的职业判断

1. 纯调 API 的"提示词工程师"易被替代；懂底层系统、能优化算力的全栈人才稀缺且高薪（老师口径：毕业 50 万起）。
2. 创新主力 20-30 岁：AlexNet 是 22 岁实习生的作品；DeepSeek 团队平均不到 27 岁，从源码级、第一性原理复现——"物质条件的局限不存在，缺的是想不想做"。
3. 迭代速度决定学习方式：知识半衰期 3-6 个月，死记结论没有意义，掌握底层原理 + 快速适配新工具才是核心竞争力。
4. 跨学科（物理/化学/生物 × AI）背景更具竞争力，科学计算是下一个爆发点。
