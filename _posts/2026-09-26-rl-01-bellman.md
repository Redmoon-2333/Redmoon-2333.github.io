## 前言

我最初把强化学习和监督学习的差别理解成“有没有标签”，后来发现这个说法会误导人。监督学习给的是一个静态答案：输入固定，标签不会因为你做了什么而改变。强化学习给的反馈是会动的——我此刻选的动作决定了下一个状态，而下一个状态下的反馈又取决于我之后怎么走。同样是“没有现成正确答案”，两者的困难完全不在一个层面上。所以真正要回答的问题是：在一个会回应我的环境里，如何把“在交互中优化”这件看似定性的事，拆成可以逐步计算的量。本章用一个 4×6 的悬崖网格做例子，把轨迹、回报、价值函数、Bellman 方程和一步 TD 更新全部手算一遍。

## 一、悬崖网格：一个贯穿全篇的例子

环境是一张 4 行 6 列的网格，共 $4 \times 6 = 24$ 个状态，用行号 $r \in \{0,1,2,3\}$ 和列号 $c \in \{0,1,2,3,4,5\}$ 定位，状态编号取 $s = 6r + c$，因此起点 $(3,0)$ 是编号 18，终点 $(3,5)$ 是编号 23。四个动作是上、下、左、右，对应位移 $(-1,0)$、$(1,0)$、$(0,-1)$、$(0,+1)$；撞到边界时停在原地，不会走出网格。第 3 行中间的四格 $(3,1)$–$(3,4)$ 是悬崖。

奖励规则只有三条：

| 事件 | 奖励 | 是否结束回合 |
|---|---|---|
| 走进普通格 | $-0.04$ | 否 |
| 走进悬崖 | $-1$ | 是（terminated） |
| 走进终点 | $+1$ | 是（terminated） |

普通步是小额负奖励，作用是给“少走弯路”一个稳定的代价；掉崖是重罚；到达终点是奖励。两个终止事件都会结束回合；环境仍可返回终止观测，但终止之后的延续回报按 0 处理。

在这样的环境里，一次**回合**（episode）是从起点出发到掉崖、到达终点或被步数上限截断为止的一段完整交互。一条**轨迹**（trajectory）是这一段里的状态-动作-奖励序列 $s_0, a_0, r_1, s_1, a_1, r_2, \dots$。**单步奖励** $r_t$ 是执行 $a_{t-1}$ 之后环境当场返回的数字；**回合回报**（return）是从某一步开始往后所有奖励的累积：

$$G_t = r_{t+1} + \gamma r_{t+2} + \gamma^2 r_{t+3} + \cdots = \sum_{k=0}^{\infty} \gamma^k r_{t+k+1}$$

其中折扣因子 $\gamma \in [0,1)$。$\gamma=1$ 时用在有真实终止的回合上（本章的两个路线例子就是），$\gamma<1$ 保证无穷序列收敛，也让近期奖励比远期奖励更有分量。

## 二、手算回报：两条路线与一个折扣示例

**路线一：贴崖走，7 步。** 从 $(3,0)$ 出发，先上 1 格到 $(2,0)$，再右走 5 格到 $(2,5)$，最后下 1 格进入 $(3,5)$ 终点。步数 $1+5+1 = 7$，其中前 6 步落在普通格，第 7 步拿到终点奖励：

$$G = 6 \times (-0.04) + 1 = -0.24 + 1 = 0.76$$

**路线二：绕远，9 步。** 先上 2 格到 $(1,0)$，右走 5 格到 $(1,5)$，再下 2 格到 $(3,5)$。步数 $2+5+2 = 9$，前 8 步是普通步，最后一步到达终点：

$$G = 8 \times (-0.04) + 1 = -0.32 + 1 = 0.68$$

两条路线同样安全、同样到达终点，回报差 $0.76 - 0.68 = 0.08$，差额全部来自多走的两步。这就是“普通步 $-0.04$”的设计意图：它把“更短的路更好”编码成了可比较的数字，而不必显式定义“长度”这个概念。

**折扣示例。** 换一个场景：某条轨迹前两步奖励都是 0，第三步拿到 10 分，取 $\gamma = 0.9$，则

$$G = 0 + 0.9 \times 0 + 0.9^2 \times 10 = 0 + 0 + 0.81 \times 10 = 8.1$$

同一个 10 分，如果再晚一步才拿到，权重会掉到 $0.9^3 = 0.729$。折扣让回报成为“既要大又要快”的量，也解释了为什么算法倾向于把高奖励的动作排在时间轴的近端。

## 三、MDP 五元组、价值函数与 Bellman 方程

上面的网格可以写成一个马尔可夫决策过程（MDP）五元组 $\langle \mathcal{S}, \mathcal{A}, P, r, \gamma \rangle$：

- $\mathcal{S}$：24 个状态；
- $\mathcal{A}$：4 个动作；
- $P(s'|s,a)$：状态转移概率。这里除了边界处的确定性滞留，转移是确定的；
- $r(s,a,s')$：上表的三条奖励规则；
- $\gamma$：折扣因子，本章手算取 1，TD 例子取 1，实际训练常取 0.99 一类的值。

策略 $\pi(a|s)$ 是在状态 $s$ 选动作 $a$ 的概率分布。由它定义两个价值函数。**状态价值**是按 $\pi$ 行动时从 $s$ 出发的期望回报：

$$v_\pi(s) = \mathbb{E}_\pi\!\left[G_t \mid s_t = s\right]$$

**动作价值**是先在 $s$ 固定执行 $a$、之后照 $\pi$ 行动的期望回报：

$$q_\pi(s,a) = \mathbb{E}_\pi\!\left[G_t \mid s_t = s, a_t = a\right]$$

两者的联系是一步展开：$v_\pi(s) = \sum_a \pi(a|s)\, q_\pi(s,a)$，而 $q_\pi$ 自己展开一层，就是**贝尔曼期望方程**：

$$q_\pi(s,a) = \mathbb{E}_{s'}\!\left[r + \gamma\, v_\pi(s')\right] = \sum_{s'} P(s'|s,a)\Big(r(s,a,s') + \gamma \sum_{a'} \pi(a'|s')\, q_\pi(s',a')\Big)$$

把最后一项换成了自己的后继，方程就有了递归结构：当前值 = 即时奖励 + 后继值的折扣期望。沿着轨迹不断代入，就还原成上一节的 $\sum \gamma^k r_{t+k+1}$。

取所有策略里最优的那个，得到最优价值 $v_*(s) = \max_\pi v_\pi(s)$、$q_*(s,a) = \max_\pi q_\pi(s,a)$，对应的**贝尔曼最优方程**是：

$$q_*(s,a) = \mathbb{E}_{s'}\!\left[r + \gamma \max_{a'} q_*(s',a')\right]$$

差别只在求和换成了取最大值——最优策略在后继状态上只挑最好的那个动作。这个方程是 Q-learning、DQN 等一批算法的共同出发点。

用后继的估计值去更新当前估计，这种做法叫 **bootstrapping**（自举）。它意味着算法不必等到回合结束才算 $G_t$，只要手里有一个对后继状态的猜测，就能立刻更新当前状态。**一步时序差分**（temporal-difference, TD）方法每走一步即可更新。多步 TD 则可使用更长的片段。蒙特卡洛方法用完整回报，在固定策略下是相应价值的无偏样本，但通常方差较大。TD 依赖后继估计，可能引入自举偏差，通常降低方差；具体大小仍取决于任务与估计质量。

## 四、一步 TD 更新的手算

以 Q-learning 为例，一步 TD 控制更新是：

$$Q(s_t, a_t) \leftarrow Q(s_t, a_t) + \alpha \Big( \underbrace{r_{t+1} + \gamma \max_{a'} Q(s_{t+1}, a')}_{\text{TD target}} - Q(s_t, a_t) \Big)$$

括号里是 **TD error**：新证据（一步真实奖励 + 对后继的估计）减去旧估计。$\alpha$ 是学习率。

代入一组具体数字：智能体在状态 $(1,3)$ 选择动作“下”，走到 $(2,3)$，环境返回 $r = -0.04$；查表得到 $\max_{a'} Q((2,3), a') = 0.5$，当前 $Q((1,3), \text{下}) = 0.2$，取 $\alpha = 0.5$、$\gamma = 1$。第一步算 target：

$$\text{target} = -0.04 + 1 \times 0.5 = 0.46$$

第二步算更新：

$$Q_{\text{new}} = 0.2 + 0.5 \times (0.46 - 0.2) = 0.2 + 0.5 \times 0.26 = 0.33$$

新值 $0.33$ 落在旧值 $0.2$ 和 target $0.46$ 的正中间——$\alpha = 0.5$ 的含义就是“一半信旧估计，一半信新证据”。$\alpha$ 越小越保守，单次更新噪声越小但收敛越慢；$\alpha = 1$ 则完全覆盖旧值。可以看到整条更新链不需要知道转移概率 $P$，也不需要跑完一整局：只要一条 $(s, a, r, s')$ 四元组就能算出结果。这就是 TD 方法能在线工作的原因。

## 五、三种“结束”：终止、截断与标准 CliffWalking 的差异

同样是一局停下来，含义可能完全不同，混为一谈会直接算错价值。

**真实终止（terminated）。** 本变体中，到达终点和掉崖都结束回合。终止转移仍可返回 $s'$，不 bootstrap 的原因是任务规定终止后的延续回报为 0，而不是观测不存在。因此 Bellman target 中的后继价值项取 0：掉崖的 target 只有 $-1$，到达终点的 target 只有 $+1$。

**截断（truncated）。** 本实现默认 `max_steps = 100`，一局走满 100 步就被强行中断。这不是环境的自然结局，只是采样上的止损：智能体仍站在某个普通格上，下一刻理论上还能继续走。所以截断时**仍然要外推**，TD target 里照常保留 $\gamma \max_{a'} Q(s', a')$。把截断当终止会让所有走满上限的局都被记成“价值到此为止”，改变截断点之前那些状态的价值估计（本变体中截断局面不会在回合结束时获得正回报，方向取决于后续奖励结构）；反过来把终止当截断则会给掉崖和终点凭空加上一个不存在的后继。

**与标准 CliffWalking 的差异。** Sutton & Barto 教材里的标准 CliffWalking 规定：掉崖后回到起点继续走，掉崖本身不结束回合；到达目标才自然终止。若额外设置每局步数上限，触及上限属于截断。本变体（移植自源项目的 `01_gridworld_qlearning.py`）掉崖即终止，并显式区分 terminated 与 truncated。两种设定下学出来的策略形状可能接近，但“贴着崖边走”并非两种设定的普遍结果：标准 CliffWalking 中探索会把智能体推入悬崖，而本变体的掉崖终止会改变风险结构——但回报的绝对数值、掉崖后的处理逻辑和终止判定代码都不一样，跨来源比较数字时必须先确认是哪一种变体。

## 六、三个边界提醒

**监督数据未必 IID。** “监督学习假设样本独立同分布”是一句被简化的说法。时间序列预测、用户行为建模、随时间采集的传感器数据都存在自相关，训练集和测试集按时间切分时分布还会漂移。IID 是许多收敛证明的理想假设，不是监督学习的身份标签；强化学习的非 IID 性质更极端——数据分布由当前策略决定，策略一变分布就变——但这不意味着另一边就稳稳满足 IID。

**强化学习未必稀疏延迟。** “强化学习就是奖励稀疏、反馈延迟”是迷思。本章的悬崖网格每走一步都有 $-0.04$，属于稠密奖励；只有在回合制棋类、任务型机器人场景里才常见稀疏奖励。稀疏与否取决于环境设计，不取决于它是不是强化学习。延迟奖励的困难（信用分配）是真实的，但它是需要处理的问题之一，不是定义。

**探索-利用不只 ε-greedy。** ε-greedy 是最简单的平衡方式：以概率 $\varepsilon$ 随机动作，否则取当前最优。但它对所有状态用同一个 $\varepsilon$，也无法区分“我没试过”和“我试过但确实差”。上置信界（UCB）按不确定性加奖励上限，汤普森采样按后验分布抽样，信息性探索则主动选择能减少不确定性 的动作。ε-greedy 是入门默认值，不是这个问题的全部。

还有一个口径问题留在此处：**同局数不等于同环境步预算**。一局可能 7 步结束，也可能拖满 100 步，“训练 500 局”在不同策略下消耗的环境交互量能差一个数量级。凡是跨算法、跨设定比较样本效率，都应该按环境步数（environment steps）而不是局数记账，这个话题在第 11 章会再回来。

## 复习问题

1. 悬崖网格的两条安全路线（7 步与 9 步）回报分别是多少？差额来自什么？如果把普通步奖励改成 $-0.1$，两个回报各变成多少？
2. 贝尔曼期望方程和贝尔曼最优方程只差一处符号，是哪一处？它对应的策略含义有什么不同？
3. 上文 TD 手算中，若 $\alpha$ 从 0.5 改成 0.1，$Q_{\text{new}}$ 是多少？若 $\gamma$ 改成 0.9 呢？（用 $\text{target} = -0.04 + 0.9 \times 0.5$ 计算）
4. 一局走满 100 步被中断，属于 terminated 还是 truncated？更新时 $\max_{a'} Q(s', a')$ 项应保留还是置 0？为什么？
