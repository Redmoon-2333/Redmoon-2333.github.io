最终答案引用了哪条证据，通常比较容易看到。那些让证据能够正确保留下来的动作，却可能不出现在答案里：丢弃噪声、保留旧笔记、重试工具、维持约束。信用如果只追着最终可见内容走，就需要检查这些动作是否仍得到足够学习信号。

这个问题连接 [P6](/2026/11/23/llm-rl-p6-memory/) 的压缩任务，也连接工具使用。两篇关键论文分别从覆盖结构和工具类别的合计信用展开。

## 1. 定位得准，与覆盖得够，是两件事

考虑一个四步链：读取订单、查库存、确认地址、提交订单。验证器在最后提交后才显出成功。

把全部信用给最后一步，定位到了可见结果，却没有给前三个先决动作同等信号。若前三步任一步缺失都会失败，最终结果可见性与学习时应覆盖的动作范围就不重合。

比较聚焦和均匀时，还需要匹配总权重。把四步每步权重从 1 改成只给末步 1，总学习强度也变成原来的四分之一。即使观察到差异，也难归因给定位本身。

## 2. Coverage, Not Targeting 怎样控制比较

论文定义验证器信息密度：

$$
V_d=\frac{k}{C}.
$$

$C$ 是因果先决链长度，$k$ 是链上其正确性能够被验证器逐步、独立检验的步骤数。四个必要步骤只有一个能独立检验时，教学密度为 $1/4$。

原文用冻结的相同 rollout 比较均匀分配、集中到可见进展步、相同集中度但随机打乱位置，主比较是首次策略更新。随机打乱对照帮助区分“挑对了位置”与“集中度、覆盖宽度改变”。

在 τ²-bench retail 的主比较中，5 个种子、95 个题目—种子对上，dense-uniform 相对 binary 的 assert-support 增加 0.079，95% 区间 `[0.009, 0.149]`。另一个 ToolACE-2-8B / BFCL V3 复核使用 32 个种子，concentrated 相对 uniform 的 official success 差为 −0.048。

两个数属于不同设置与指标。合成条件中约 0.8 的交叉点，也不能直接当作所有任务通用的切换阈值。

## 3. TACA：失败轨迹怎样影响工具类别

一次复杂求解可能调用多次工具后仍失败，一次简单题直接作答就成功。若把终局优势广播到生成 token，失败轨迹里较多的工具 token 可能让工具类别累计更多负权重。

这种现象涉及工具 token 数量不平衡与 token 聚合方式。工具 token 的合计标量信用偏负，不表示每个工具 token 都为负，也不能直接替代完整参数梯度分析。

TACA 包含三个部分：

1. 对工具优势做投影，调整组内工具类别的平均信号。
2. 在同题条件下比较使用工具和直接作答的收益。
3. 对先前正确轨迹中的工具调用做监督重放。

监督重放是方法的一部分，需要计入预算。原文 1.5B 模型六个基准平均从 28.63 到 33.24，3B 从 39.90 到 43.51；去掉监督重放的 1.5B 均值为 30.21。这里每题 32 次采样是评估预算，不是 32 个训练种子。

原诊断更直接涉及工具执行质量下降，工具使用率大体稳定。简单概括为“训练后完全不调用工具”，会丢掉它真正测到的问题。

## 4. 回到压缩：保护性动作怎么定义

在有限槽位里，丢弃无关新事实可以保护有用旧事实。最后回答没有引用这条被丢弃的事实，但丢弃动作仍可能是正确决策。

本地 Pos-Route 对成功轨迹按最终槽位注意力加权，还给每个动作保留 0.25 的加性底座。它的 `drop` 正信用并非零；与被引用写入相比，相对权重可能更小。

最难条件下，它的最终准确率比共享优势基线低 11.60 个百分点。这是本地小模型代理现象。要验证是否由保护性动作覆盖造成，应比较：均匀权重、来源加权、随机打乱同样权重、提高底座、对 `drop` 专门补偿。当前结果还没有完成这组隔离。

## 5. 两个仍在探索的候选

**C01 改**拟检验保护性动作覆盖与逐渐退火的恢复诊断。先保留共享终局信号，再逐步改变诊断权重，检查是否兼顾学习速度和末端表现。旧硬屏蔽版本的末端门槛仍为 NO_GO；它早中期出现的提升不能算到尚未运行的退火方案头上。

**C03**拟研究任务结构与验证器密度能否指导覆盖程度。真正困难的步骤是在线测量 $k,C$ 或可靠替代量，而不是先假定已经知道密度。还需要与强均匀基线、固定混合比例和匹配集中度随机对照比较。

两者目前都是候选问题。它们与论文之间的联系是可检验的机制假设。

## 6. 读过程信用论文时看这四个量

| 量 | 具体看什么 |
|---|---|
| 信息来源 | 终局、过程规则、Critic、语言裁判、真实续跑 |
| 覆盖范围 | 哪些角色、步骤、token 和动作类别收到信号 |
| 权重尺度 | 总和、均值、长度归一化、正负截断 |
| 比较预算 | 新回放、裁判调用、监督重放、原始采样 |

方法可能同时改动多项。把它们拆开，才能看懂收益来自额外信息、更广覆盖，还是不同的更新尺度。
