选桥例子里，旧版 A 常只报一座桥，更新后更常把两座桥都报全。如果训练 B 还依赖旧记录，它就会频繁看到现在较少遇到的缺字段报告。TeamTR 研究的这种**分布错配**，在本地分别用表格模型和原生仓储环境来测量。

区分两种过时，可以先定格“B 已经到了路口”。旧队和新队到路口的次数不同，属于访问分布的变化；在同样的路口继续走时，队友支援的时机变了，属于后续行为的变化。要知道差从哪来，可以分别替换“到哪里停”与“停下后由谁继续”，第 1 节的四种组合就在做这件事。

## 1. “旧”可以发生在两个地方

一个梯度估计既依赖访问了哪些状态，也依赖从这些状态往后怎样行动、怎样产生回报。

| 记号 | 状态来自哪里 | 后续队友策略 |
|---|---|---|
| $g_{00}$ | 旧团队 | 旧团队 |
| $g_{01}$ | 旧团队 | 新团队 |
| $g_{10}$ | 新团队 | 旧团队 |
| $g_{11}$ | 新团队 | 新团队 |

两个下标分别表示起点和续跑策略，`0` 是旧，`1` 是新。其中 $g_{01}-g_{11}$ 固定新版续跑，换起点；$g_{10}-g_{11}$ 固定新版起点，换续跑策略。两项之和再加上交互项 $g_{00}-g_{01}-g_{10}+g_{11}$，得到整体的旧减新 $g_{00}-g_{11}$。

「状态占用」指策略在交互过程中多频繁到达各个状态。拿选桥记录手算，旧团队有 `80%` 的起点缺字段，新团队只有 `20%`。固定同一个新版续跑策略，假设从缺字段、字段齐全起点得到的某一梯度分量均值分别为 `0.1`、`0.5`。旧起点加权得 `0.8×0.1+0.2×0.5=0.18`，新起点加权得 `0.2×0.1+0.8×0.5=0.42`。差 `−0.24` 单由起点的组成变化得到。

如果旧版续跑得到的两项均值分别为 `0.05`、`0.45`，可以把四格全算出来。这里用一个标量表示梯度的某一分量。

```python
def gradient(p_missing, missing, complete):
    return round(p_missing * missing + (1 - p_missing) * complete, 2)

g00 = gradient(0.8, 0.05, 0.45)
g01 = gradient(0.8, 0.10, 0.50)
g10 = gradient(0.2, 0.05, 0.45)
g11 = gradient(0.2, 0.10, 0.50)
parts = g01 - g11, g10 - g11, g00 - g01 - g10 + g11
print([round(x, 2) + 0.0 for x in parts], round(g00 - g11, 2))
# [-0.24, -0.05, 0.0] -0.29
```

本例交互为零，因为换续跑策略对两种起点各减 `0.05`。若旧版续跑对缺字段报告特别不擅长，两种起点的变化大小就不同，交互项会留下这部分差异。

只改一个数看看：把旧策略处理缺字段时的 `0.05` 改成 `−0.05`，还用原来的 `0.45` 处理齐全字段。旧起点有八成缺字段，$g_{00}$ 从 `0.13` 降到 `0.05`；新起点只有两成缺字段，$g_{10}$ 从 `0.37` 降到 `0.35`。这两格的降幅不同，所以交互项变为 `−0.08 − (−0.02) = −0.06`。旧起点中容易遇到的缺字段，刚好也是旧续跑更不擅长处理的情况。

## 2. 表格模型的回报差

本地有限状态模型对 2–12 名成员精确计算。测得状态漂移随人数的增长指数约 1–1.5，目标偏差指数约 0.06–0.59，重采样带来的最大回报增益约 0.014。

理论上界给出允许的最大幅度。本地表格模型测到的漂移和收益描述这里的有限状态任务，可以据此估计在原生环境里需要多精细的测量。

## 3. 原生 RWARE 怎样测

仓储模拟器中，每个成员使用公开的 IPPO（独立 PPO）循环策略搬运货架。实验冻结负责记忆的 GRU 主干，再加线性残差头微调动作分布。残差头是在原动作分数上加一个可控的改变量。

比方说，屏幕上同样是「面前有货架」，另一条走廊的队友却可能正搬着货，也可能空手。分叉要保存整个环境、随机源和所有成员的循环隐藏状态。如果只复制眼前画面，马上会把续跑差和起点差混在一起。

给队友设置目标 KL 0.01、0.05、0.10，再测新状态分布上的实际 KL。KL 描述旧、新策略的动作概率分布相差多远。用校准快照调好的变化幅度，要在训练后常访问的状态上重新量一次。新状态可能看到更大的概率变化。

## 4. 为什么还要做 fresh-null

即便策略相同，占用快照抽样与后续采样也会让梯度不同。额外独立采集新的占用快照，并以同预算续跑形成 $g_{11}^{\text{null}}$，估计这两层测量噪声。

比较量为：

$$
\text{比值}=
\frac{\|g_{01}-g_{11}\|}
{\|g_{11}^{\text{null}}-g_{11}\|}.
$$

例如两次新鲜测量的梯度距离为 `0.02`，旧起点与新起点测得的距离也是 `0.02`，比值就是 `1`。换成旧数据带来的读数差，和同一方法再抽一次差不多。这个比值是信号相对噪声的大小，不是显著性检验；要判断哪次更新更好，再让两份更新后的策略在同一批独立回合里跑，比较真回报。

## 5. 已有预试得到什么

预试使用一个公开 seed0 检查点，每个占用集合 8 个快照×5 个动作×4 次续跑，更新后的回报比较使用 32 个共享评价回合。既有预试实际推进 955,152 步，三档结果为：

| 目标 KL | 新鲜占用实际 KL | 占用差 / fresh-null 噪声 |
|---|---:|---:|
| 0.01，主设置 | 0.009327 | 1.001 |
| 0.05 | 0.161645 | 2.516 |
| 0.10，压力设置 | 1.249767 | 0.936 |

主档实际 KL `0.009327`，接近设计的 `0.01`；它的梯度差约等于再采一次新鲜数据的波动。中档的 `2.516` 是在实际 KL `0.161645` 的条件下测到的，读这行要用实测列。各组新鲜分叉有约 37.5%–87.5% 的续跑拿到零分；目标动作是否改善搬运，回到独立评价回合看。

原预试的判定是 `STOP`：主设置的梯度差接近采样噪声，更新后的独立回报也未显示稳定损害。保留完整状态恢复和两次新鲜采样的做法，用于以后估计测量噪声。

## 6. 这对 LLM 课题意味着什么
