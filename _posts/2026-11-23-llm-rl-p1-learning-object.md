侦察员 A 看见北桥限重 6 吨、南桥限重 3 吨。运输员 B 知道货车重 5 吨。A 发来两座桥的限重，B 选了北桥，货车顺利通过，两人共同拿到 1 分。这一分究竟会让 Qwen 更会写报告，还是让 B 更会选桥？看训练程序更新的是谁的参数。

这是贯穿本系列的纸上选桥任务。每局恰有一座桥可通行。给定 B 看见的重量，可通行桥出现在两侧的概率各是 50%。规则模拟货车通行，成功奖励 1，失败奖励 0。

## 1. 先把强化学习的几个词放进任务

| 概念 | 在选桥任务中的含义 |
|---|---|
| 环境状态 | 两座桥限重、货车重量、当前轮次等完整信息 |
| 局部观察 | A 只看到限重，B 只看到重量 |
| 动作 | A 发送消息，B 选择桥；也可以把“请求复核”设计成动作 |
| 策略 | 在当前可见信息下，选择各动作的概率分布 |
| 轨迹 | 从看到信息、发送消息到选择桥、得到结果的整段经历 |
| 奖励 | 环境对某一步或最终结果给出的数值 |
| 回报 | 从当前时刻开始，后续奖励按约定累积后的数值 |

例如 B 读完消息后，以 0.7 的概率选北桥、0.3 的概率选南桥。产生两项概率的模型叫 Actor；它按自己看到的信息给出选择规则，这就是策略。抽中的「北桥」是实际动作。参数是 Actor 内部产生这些概率用的数，训练就是反复调整这些数。PPO（近端策略优化）用采样结果调整策略，MAPPO 把这类更新用在多个智能体上。

如果当前所有奖励都在终点发放，且折扣系数取 1，本局回报就等于最后的 0 或 1。如果每走一步还要付成本，或者使用折扣，回报就需要把这些项一起算进去。

折扣把更远的奖励乘上更小权重。例如立即奖励 0.2、下一步奖励 1，折扣取 0.9，当前回报就是 `0.2 + 0.9×1 = 1.1`。训练目标通常是让许多局的预期回报提高。

## 2. 第一种搭法：Qwen 冻结，小 Actor 学决策

A 的小型 Actor 先决定报告哪一部分，可以只报告一座桥，也可以报告两座桥。开源权重模型 Qwen2.5-7B-Instruct 收到报告选项和相应数据，把它组织成一句话。

1. A 的 Actor 抽到「报告两边限重」，系统把 `北桥=6，南桥=3` 交给 Qwen，Qwen 发出「北桥限重 6 吨，南桥限重 3 吨」。
2. 接收接口把消息转成两个限重字段。B 的 Actor 看到 `[车重=5, 北桥=6, 南桥=3]`，从自己的动作分布里抽到「北桥」。
3. 环境检查 `5 <= 6`，本局成功，发放团队奖励 `1`。训练记录保存 A 与 B 各自的输入、实际动作和采样概率。
4. 为了手算，假设两次决策的价值预测都为 `0.6`。回报为 `1`，比预测高 `1−0.6=0.4`，这个差叫优势。正优势推动 Actor 更偏向自己实际选过的动作；Critic 用回报作为目标，学习把预测调得更准。

Critic 是预测回报的模型。假设在相似条件下，当前队伍约十局通行六局，就可以把 `0.6` 理解为参照水平。MAPPO 训练时可让 Critic 同时看见桥况和车重；执行时，B 仍从收到的消息取得桥况。这叫**集中训练、分散执行**（CTDE）。

```text
局部观察 → 小 Actor 选动作 → 冻结 Qwen 组织文本
         → B 的 Actor 选桥 → 环境给奖励 → MAPPO 更新小 Actor / Critic
```

Qwen 冻结时，同一套权重可以根据不同限重和报告选项写出不同句子。A 更会挑要报告的内容、B 更会使用收到的字段，都能提高团队成功率。要测各自的变化，可以固定 B、只把 A 换成训练后的版本做一次对照，再固定 A、比较两个版本的 B。

LLM-MCA 也把语言模型和下层决策策略分开，但语言模型负责另一份工作：读团队记录，为每位成员提供反馈。原文使用 Gemma-7B 和 Double DQN。上面的选桥演示采用 Qwen 和 MAPPO。

## 3. 第二种搭法：Qwen 自己就是 Actor

让 A 的 Qwen 直接生成消息，让 B 的 Qwen 直接生成答案。token 是模型处理文本的单位，一段短语可被切成多个 token，具体切法由分词器决定。模型每生成一步，就从词表选一个 token，写进当前文本，再根据更新后的文本预测下一步。

设输入为 $x$，生成三个 token：$y_1,y_2,y_3$。整段输出概率为：

$$
\pi_\theta(y\mid x)
=\pi_\theta(y_1\mid x)
\pi_\theta(y_2\mid x,y_1)
\pi_\theta(y_3\mid x,y_1,y_2).
$$

这里 $\theta$ 是待训练参数，$\pi$ 是策略分布。实际训练常使用对数概率，把连乘变成相加：

$$
\log\pi_\theta(y\mid x)
=\sum_t\log\pi_\theta(y_t\mid x,y_{1:t-1}).
$$

$y_{1:t-1}$ 表示这条回答前面已经生成的 token，第一步时为空。可以把小 Actor 的「北桥/南桥」两个选项扩展为 Qwen 的整个词表，生成一句话相当于连续做很多次选择。

环境判定桥能否通过可以是普通 `if` 规则。规则自身无须可导；策略梯度通过模型给实际动作的概率回传：

$$
L_{\text{actor}}=-A\log\pi_\theta(y\mid x).
$$

$A$ 是优势，表示这次结果相对预期好多少。若本局奖励为 1、参照价值为 0.6，教学优势就是 0.4。这个样本给所选动作正向信号，优化器会把它和同批其他样本的梯度合起来更新。

## 4. 用四选一的小代码看见梯度

下面用四个候选动作代替完整词表。装有 PyTorch 就可以运行，优化器更新的是四个分数。

```python
import torch
from torch.distributions import Categorical

logits = torch.nn.Parameter(torch.zeros(4))
optimizer = torch.optim.SGD([logits], lr=0.1)

action = torch.tensor(1)          # 这局实际选择了第 1 号动作
advantage = torch.tensor(0.4)     # 评分在 Actor 更新中当作固定权重

dist = Categorical(logits=logits)
loss = -dist.log_prob(action) * advantage.detach()

optimizer.zero_grad()
loss.backward()
print("各 logit 的梯度：", logits.grad)
optimizer.step()
print("更新后的动作概率：", logits.softmax(dim=-1).detach())
```

代码的下标从 0 开始，`action=1` 表示第二个候选。

1. `logits` 是四个待训练的原始分数。它们开始时都为 `0`，softmax 对四个相同分数均分概率，每项为 `0.25`。
2. `Categorical` 把四项概率当成一个四选一分布。`dist.log_prob(action)` 取出已选动作的对数概率 `log(0.25)`。`advantage.detach()` 把 `0.4` 当作这次更新的固定评分。
3. `zero_grad()` 清掉旧梯度，`backward()` 计算当前梯度。对第二项是 `0.4 × (0.25−1) = −0.30`。其余三项是 `0.4 × 0.25 = 0.10`，因为四个候选共用 softmax 的分母。
4. `step()` 用 `新分数 = 旧分数 − 0.1 × 梯度` 更新。四项变成 `[-0.01, 0.03, -0.01, -0.01]`。第二个动作的新概率为 `exp(0.03) / (exp(0.03) + 3 × exp(-0.01)) ≈ 0.2576`。

梯度描述分数增加时损失如何变化。第二项的梯度为负，增大它会降低当前损失，所以优化器上调了这个分数。

把损失写成 `-reward` 时，选桥规则得到的 `1` 已经是一个常数。四个分数怎么微调，常数都固定。`log_prob` 把这个评分连接到实际选过的动作，再经 softmax 连到待更新的分数。

在真实语言模型中，还要对齐“哪个位置的 logits 预测哪个输出 token”，用输出掩码排除提示词与补齐位置。P2 会把这些细节和 PPO 连起来。

## 5. 第三种搭法：主干冻结，LoRA 在学习

全量微调更新 Qwen 的大量主干参数。LoRA 在部分线性层旁加入低秩增量：

$$
W_{\text{eff}}=W_0+UV.
$$

$W_0$ 保持冻结，$U,V$ 接收梯度。设某个输入经过原矩阵得到数值 `2`，适配器贡献从 `0` 变成 `0.3`，此处相加后的结果就变成 `2.3`。后面的层接到新数值，生成概率也能随之变化。

若 $W_0$ 为 $d_{\mathrm{out}}\times d_{\mathrm{in}}$，则 $U$ 为 $d_{\mathrm{out}}\times r$、$V$ 为 $r\times d_{\mathrm{in}}$，其中 $r$ 远小于两个原维度。训练参数量是 $r(d_{\mathrm{out}}+d_{\mathrm{in}})$，低秩结构让这部分参数显著少于完整矩阵。

例如 `1024×1024` 的矩阵有 `1,048,576` 个数。取 `r=8` 时，两块适配矩阵共 `16,384` 个数。QLoRA 还用低精度存储冻结主干，以节省显存。

| 实际设置 | 被优化的参数 | 应怎样描述 |
|---|---|---|
| 冻结 Qwen＋小 Actor | 小 Actor、可选 Critic | 控制器学习 |
| Qwen 全量策略微调 | Qwen 主干、可选 Critic | LLM 接受 RL 更新 |
| 冻结主干＋可训练 LoRA | LoRA、可选 Critic | LLM 的适配器接受 RL 更新 |
| 只修改提示词或记忆 | 无梯度更新，除非另有训练器 | 输入或上下文改变 |

看代码时，先找产生动作的模型，再沿 `log_prob` 查到损失和梯度，最后检查优化器持有哪些参数。

## 6. 共同得分之后，还有信用问题

假设 B 没用消息也猜对了桥。两人共用 `+0.4` 的优势，A 这次选中的报告动作依然得到正权重。要测报告的作用，可以固定 B 的策略，回到同一个选桥起点，分别给 B 原报告和一条替代报告，让 B 在两路重新选桥。怎样比较这两路，见 [P3 的信用分配算例](/2026/11/23/llm-rl-p3-credit-assignment/)。
