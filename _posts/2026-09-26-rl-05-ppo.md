上一章搭好了 REINFORCE 与 Actor-Critic 的更新框架，这一章要回答的是：当同一批轨迹数据被反复拿来更新好几轮时，怎么防止策略一步迈得太大、直接跑出原来的行为分布。更具体地说，PPO 的那个 clip 到底约束了什么、又没有约束什么——这是本章要算清楚的核心问题。

## 1. 问题：同一批数据反复用，策略为什么会跑偏

策略梯度的理论推导假设样本来自**当前**策略。但采样很贵：本实验每次 rollout 收集 512 步环境交互，如果每采一次只做一次梯度更新，环境步预算 100k 里只有一百多次更新，样本利用率极低。工程上的通解是**数据复用**：采一批数据，做多个 epoch 的 minibatch 更新（本实验 4 epochs、minibatch 64，即每批数据每个样本被重新使用 4 次）。

复用带来一个直接后果：从第二个 minibatch 开始，被评估的策略 $\pi_\theta$ 已经不是产生数据的行为策略 $\pi_{\theta_{old}}$ 了。数据是旧策略分布下的经验，损失却按新策略的期望在写，两者之间的错配会随更新步数累积。表现出来有两类：一是 advantage 估计基于旧的价值函数，新策略下已经不准；二是策略可能一步大幅偏离，性能悬崖式下跌且难以恢复。这一章关注的是后者——怎么在目标函数层面限制单次更新的幅度。

## 2. 推导链一：重要性采样与数据复用

先固定状态 $s$，并假设新策略的动作支撑集包含在旧策略支撑集中。以即时奖励 $r$ 为例，动作层面的重要性采样恒等式为

$$\mathbb{E}_{a\sim \pi_{\theta_{old}}}\left[\frac{\pi_\theta(a\mid s)}{\pi_{\theta_{old}}(a\mid s)}\,r\right] = \mathbb{E}_{a\sim \pi_\theta}[r]$$

记概率比 $r_t(\theta)=\dfrac{\pi_\theta(a_t\mid s_t)}{\pi_{\theta_{old}}(a_t\mid s_t)}$。满足支撑集条件时，上述动作期望恒等式对不同 $\theta$ 都成立，无偏性并不要求 ratio 为 1。新旧动作分布相差较大时，重要性权重的方差可能很大。PPO 还固定使用旧策略的状态样本和优势估计，单步动作比率没有校正完整轨迹或状态访问分布，因此它构造的是局部代理目标，而不是新策略真实回报的无偏估计。TRPO 在代理目标上施加 KL 约束；PPO-Clip 改用裁剪目标。

PPO 的出发点是：能不能把「信任域」换成一个一阶的、在普通 Adam/SGD 上就能跑的形式？这就是代理目标。

## 3. 推导链二：代理目标与 PPO-Clip

PPO-Clip 的代理目标（PPO 记作 $L^{CLIP}$，取负即要最小化的损失）是

$$L^{CLIP}(\theta)=\mathbb{E}\left[\min\big(r_t(\theta)\hat{A}_t,\ \text{clip}(r_t(\theta),1-\varepsilon,1+\varepsilon)\,\hat{A}_t\big)\right]$$

本项目的实现（`rlpractice/algos/single/pg.py` 的 `ppo_surrogate`）就是它：

```python
def ppo_surrogate(ratio, adv, clip):
    surr1 = ratio * adv
    surr2 = th.clamp(ratio, 1 - clip, 1 + clip) * adv
    return -th.min(surr1, surr2)
```

$\min$ 保证裁剪代理目标逐样本不大于未裁剪的 $r_t\hat A_t$，但这不等于真实策略回报的下界，也不保证每次更新都改善性能。$\hat A>0$ 时目标为 $\min(r,1+\varepsilon)\hat A$，提高 ratio 超过上界不再增加该样本的收益；$\hat A<0$ 时目标为 $\max(r,1-\varepsilon)\hat A$，降低 ratio 超过下界也不再增加收益。它削弱沿优势所指方向过度更新的激励，不是 TRPO 约束的等价实现。本实验取 $\varepsilon=0.2$。

注意这里 $\min$ 的两项都乘了同一个 $\hat{A}$，所以裁剪永远作用在**对当前目标更不利**的那一侧，这正是「悲观」的含义；若写成 $\text{clip}$ 直接包住 $r\hat{A}$（而不是包 $r$ 再乘 $\hat{A}$），在 $\hat{A}<0$ 时语义就反了——这是实现里最容易写错的一处，`surr2 = clamp(ratio, ...) * adv` 的写法顺序不能调换。

## 4. 纠正误解：clip 不是概率比的硬约束

源材料里曾把 clip 说成「把概率比强行限制在 $[1-\varepsilon,1+\varepsilon]$ 内」，这是错的，本章明确纠正。

用数值反例验证：取 $r=1.5$、$\hat{A}=1$、$\varepsilon=0.2$。则

- $\text{surr1}=1.5\times 1=1.5$
- $\text{surr2}=\text{clamp}(1.5,0.8,1.2)\times 1=1.2$
- $\min(1.5,\,1.2)=1.2$

最大化的代理目标取 1.2，代码返回的最小化损失为 **−1.2**，但 **ratio 仍为 1.5**。裁剪没有把参数投影回可行域。只有在 $\hat A>0,r>1+\varepsilon$ 或 $\hat A<0,r<1-\varepsilon$ 时，该样本的裁剪代理项才成为常数；相反方向越界时仍有梯度。

## 5. 不对称性：adv 的符号决定梯度在哪一侧归零

真正被约束的是**梯度**，而且方向不对称：

- $\hat{A}>0$（想提高该动作概率）：当 $r>1+\varepsilon$，$\min$ 选中常数项 $ (1+\varepsilon)\hat{A}$，该样本代理项的梯度为 0，但动作概率仍可受其他梯度影响；而 $r<1-\varepsilon$ 时仍取 $r\hat{A}$，梯度正常。
- $\hat{A}<0$（想降低该动作概率）：当 $r<1-\varepsilon$，$\min$ 选中常数项 $(1-\varepsilon)\hat{A}$，该样本代理项的梯度为 0，但动作概率仍可受其他梯度影响；而 $r>1+\varepsilon$ 时取 $r\hat{A}$，梯度正常。

裁剪只在“继续朝优势所指方向走”的越界区域将该样本代理项的梯度置零，反向越界仍保留梯度。其他样本、熵项、共享价值网络以及优化器状态仍可能改变该动作的概率，因而不能说动作概率会停止变化。测试 `test_ppo_clip_gradient_zero_outside_interval` 所对应的是这两个符号相关的平坦区域，不是所有区间外样本。

## 6. GAE：优势估计的偏差—方差折中

裁剪调节代理目标的更新激励，$\hat{A}_t$ 管的是「往哪个方向走」。GAE 用 TD 残差的指数加权平均估计优势：

$$\delta_t=r_t+\gamma V(s_{t+1})-V(s_t),\qquad \hat{A}_t=\delta_t+\gamma\lambda\,\hat{A}_{t+1}$$

$\lambda=0$ 退化为一步 TD 优势；$\lambda=1$ 时得到折扣多步回报加段尾 bootstrap 再减 $V(s_t)$，只有完整采到真实终止时才等于纯蒙特卡洛优势。有限 rollout 和时间截断边界仍需 bootstrap，是否取 $\gamma=1$ 不改变这一边界条件。CartPole 默认每步奖励为 $+1$，是稠密奖励环境。本实验用 GAE$(0.99,0.95)$。真实终止时置零的是后继价值，TD 目标仍包含即时奖励；人为截断保留下一状态价值，但两类回合边界都切断优势递推，避免接上重置后的回合。实现还对整批优势标准化，以调整梯度尺度。

## 7. 多 epoch 与 minibatch：数据陈旧问题

完整 rollout 的更新循环是 4 个 epoch ×（512 / 64 = 8 个 minibatch），共 32 次参数更新，每个样本使用 4 次。只有这批数据的**第一次参数更新前**，新旧策略相同、ratio 为 1；同一 epoch 的后续 minibatch 也已面对更新后的策略。旧 log-prob 和优势在这批更新中固定，增加 epochs 会提高复用次数，也可能增大新旧策略的差异。clip 只削弱特定方向的代理收益，不能保证阻止漂移或性能下降。

## 8. 诊断量：approx_kl 与 clip_frac 怎么读

复现包每个更新点把两个诊断量写入 manifest（`log.event("ppo_diag", ...)`）：

- **approx_kl** $=\mathbb{E}[(r-1)-\log r]$，是 $D_{KL}(\pi_{old}\|\pi_\theta)$ 的非负近似，衡量新旧策略实际偏了多远；
- **clip_frac** $=\mathbb{P}(|r-1|>\varepsilon)$，衡量有多少样本落在裁剪区间外。

clip_frac 只统计 ratio 越界比例，不等于“梯度被裁掉的比例”，也不反映越界幅度。approx_kl 估计旧状态分布上的策略变化，两者都不是性能或安全保证：clip_frac 低也可能漏掉少数很大的比率偏移，KL 小也不能保证回报改善。应结合多次更新的趋势、独立评估回报及优势和价值损失判断；持续较大的 KL 可以提示检查学习率或 epochs，但没有统一的失败阈值。诊断曲线见下图。

## 9. GRPO 边界：保留了什么，去掉什么

DeepSeekMath（arXiv:2402.03300v3，式 3）中的 GRPO 与 PPO 有以下联系（原文出处见第 12 章）：

- GRPO **保留**重要性比率 $\pi_\theta/\pi_{\theta_{old}}$、裁剪 $\text{clip}(\cdot,1-\varepsilon,1+\varepsilon)$ 与逐 token 平均，并在**最大化目标中**减去 KL 惩罚，即加入 $-\beta\,D_{KL}(\pi_\theta\|\pi_{ref})$；
- GRPO **去掉**的是被学习的 value function（critic），优势改为同一 prompt 采样一组回答、用**组内相对奖励**标准化得到；
- DeepSeek-R1（arXiv:2501.12948v1 §2.2.1 式 1）的目标函数同样保留 $-\beta\,\mathbb{D}_{KL}$ 项；标题中的 KL 系数设置取决于具体版本与训练阶段，本章不对未逐版核实的数值下断言。

GRPO 保留了 PPO-Clip 的 ratio 与裁剪代理机制，主要替换了优势估计：不再训练 value function，而使用同一 prompt 下的组内相对奖励。裁剪限制的仍是特定方向的代理优化激励，不是策略漂移的硬上界；重要性比率参照的仍是采样旧策略。

## 10. 本实验口径与实测结果

本实验配置：rollout 512、4 epochs、minibatch 64、clip 0.2、GAE(0.99, 0.95)、lr 3e-4、ent 系数 0.01、vf 系数 0.5、grad clip 0.5、MLP(4,64,64)、预算 100k 环境步，5 个训练种子；验证 20 局、最终测试 100 局均用**贪心（argmax）**动作，验证种子 10000+。最终数字取**一次性复评**（种子 30000–30099，见第 11 章披露）；误差带为跨种子 SD。配置比较过 lr 5e-4、epochs 10 与 γ 0.999 三种改法，均不优于原配置，故 PPO 保持上表不变。

## 11. 易错点小结

1. **把 clip 说成概率比的硬约束**。$r=1.5$、$\hat{A}=1$、$\varepsilon=0.2$ 时最大化代理目标取 1.2，最小化损失为 −1.2，ratio 仍是 1.5；被限制的是目标与梯度，不是参数或概率。
2. **clip_frac 高就判定训练坏了**。它只表示越界比例，应结合 KL 趋势与独立评估；KL 小不保证训练有效，KL 大也不能单独判为更新失败。
3. **只看第一个 epoch**。多 epoch 更新会继续使用旧策略数据，ratio 可能进一步偏离 1，epochs 是有代价的旋钮。
4. **混淆随机与贪心评估**。两种评估都有效：采样评估随机策略，argmax 评估其确定性版本，回报高低没有通用的大小关系。比较时需统一或分列报告动作模式；本系列这组验证与测试采用贪心。
