> 第 2 章的表格 Q-learning 在离散小环境里跑得很稳，但 CartPole-v1 的状态是小车位置、速度、杆角度、角速度四个连续实数——这是个物理平衡任务：一根杆铰接在能沿轨道左右移动的小车上，算法用“向左推”和“向右推”两个动作把它撑住（第五节展开）。对这样的状态，任意精度的切分都会造出天文数字个格子——表格存不下，只能用一个神经网络去逼近 $Q(s,a)$。本章要回答的问题是：逼近之后冒出哪些表格时代不存在的新问题，DQN 的经验回放与目标网络各自解决其中哪一个。前四节从机制上回答这个问题；第五、六节的实验检验的是完整配置：回放、目标网络和三个小机制一起用上，DQN 能不能在 100,000 步内学会把杆撑满 500 步。

## 一 · 函数逼近引入的新问题：误差共享与外推

表格存不下，那退一步——把连续状态粗离散化、只留少量格子？这条路两头不讨好：切分粗了丢信息，同一个格子里的两个状态其实处境不同，Q 值只能取平均；切分细了稀疏，大量格子在整个训练预算里访问不到几次，估值永远学不出来。绕开这道两难的是函数逼近：相邻状态共享参数，见过一次的区域附近都能给出估值。但泛化有代价——它引入两个新问题：**误差共享**与**外推**。

先看**误差共享**。表格表示下，每个状态-动作对的值独立存放，更新第 $(s,a)$ 格不会动到别的格。换成网络后，所有 Q 值由同一组参数生成：改一个参数，全部状态的估值都会跟着动。于是一个状态上学到的误差会传播到没见过的状态上，这在表格时代根本不会发生。

更麻烦的是外推。网络只在回放里出现过的状态附近拟合得比较准，对数据稀疏区域的 $Q(s,a)$ 没有约束——那里的输出本质上是外推值，可能明显偏高。而 TD 目标里有一个 $\max_{a'}$：它会主动去挑那个被外推高估的动作作为目标，再把高估写回网络。高估 → 更高的目标 → 更高的估计，构成正反馈。这就是逼近误差与外推误差在自举（bootstrapping，回忆第 1 章：用自己的后继估计当目标）学习里被放大的机制。

学界把 **bootstrapping + 函数逼近 + off-policy** 三者同时出现称为“致命三要素”（deadly triad）：自举让网络把自己的输出当作目标的一部分，误差被自己喂给自己；函数逼近让误差在参数间互相传播；off-policy 让训练数据的分布与最终要评估的（贪心）策略分布不一致，数据少的地方恰恰是外推最不可靠的地方。三者各自存在时大多无害，凑在一起时训练可能缓慢发散或剧烈震荡。直觉上：你在用一个不完美、还在变化的模型，去监督另一个用同样不完美、还在变化的模型算出来的目标。DQN 的两个核心组件——经验回放与目标网络——就是分别从“数据”和“目标”两端把这个回路稳住。

## 二 · 经验回放：打断时间相关性，提高样本复用

原始在线采集时，相邻样本来自同一条轨迹的相邻两步：状态几乎一样、动作连续、回报高度相关。随机梯度下降默认样本近似独立，喂给它一串强相关的样本，更新方向会来回摆。经验回放把转移 $(s,a,r,s',d)$ 存进定容缓冲区，训练时从中随机采一批（当前 v2 为 batch 32）：随机打散后，一批样本跨越许多不同轨迹、不同训练阶段，时间相关性被打破，批内梯度的方差显著下降。

本实现设了 1,000 步 warmup：开头只采集不学习，让缓冲区先攒下一批足够多样的转移再开始回归，避免在近乎随机的早期网络上做无意义的更新。

第二个好处是样本复用。一条昂贵的真实交互转移可以被采中很多次，每次参与一次参数更新，这在交互预算受限时直接提高了数据效率——DQN 之前的方法往往一局数据只用一次。

回放同时把 off-policy 变得自然而合法：行为策略是带 ε 的 ε-greedy，目标策略是贪心，回放缓冲区正是这类“旧策略数据 + 新目标”组合的载体。代价是数据的新旧混合，后文易错点一节会展开。

## 三 · 目标网络：让目标“慢下来”

DQN 的 TD 目标为：

$$y = r + \gamma \max_{a'} Q_{\text{target}}(s', a')$$

如果 $Q_{\text{target}}$ 就是正在训练的在线网络，那么每做一次梯度更新，监督目标本身也跟着变——相当于盯着一个移动的靶子做回归，目标与预测互相追逐，容易震荡甚至发散。目标网络是在线网络的一份拷贝，在两次同步之间参数完全冻结，于是每次更新都是在解一个近似固定的回归问题；网络有一整段时间去逼近当前目标，然后目标才跳到新位置。让目标“慢下来”，正是自举学习稳定的关键。

本实现里两者的关系很具体：warmup 1000 步之后，**每个环境步做一次梯度更新**，而目标网络**每 500 个环境步同步一次**（`env_steps % target_sync == 0`）。在 100,000 步预算下，全程约 9.9 万次更新、约 200 次同步（具体次数取决于 warmup 边界）——学习阶段每个完整目标版本约用于 500 次回归。同步太频繁退化成无目标网络，太稀疏则目标严重滞后于在线网络，学到的策略变慢；500 步是当前 v2 采用的折中，不是普适常数。

**每个环境步在做什么。** 把回放与目标网络拼进循环，本实现每步固定执行：① 按当前 ε 选动作，与环境交互一步；② 把转移压入回放；③ 过了 warmup 就随机采一个 batch；④ 用目标网络算出 $y$，以 Huber 损失更新在线网络并裁剪梯度；⑤ 每到 `target_sync` 就把在线网络同步给目标网络。每累计 10% 预算，另起一路用贪心策略做一次 20 局的独立验证，不干扰训练环境。这些机制彼此独立，却服务同一件事：让每一步回归的数据分布和监督目标都尽可能稳。

## 四 · 三个稳住训练的小机制

**ε 从 1.0 衰减。** 训练采用 ε-greedy，ε 在前 10,000 步（预算的 10%）内从 1.0 线性降到 0.05，之后保持 0.05 不再下降。开局 ε=1.0 即全随机：让回放尽快填入状态空间各处的多样样本，缩小上一节说的“数据空白区”，因为外推误差恰好在那里最大。余下 90% 预算保留 5% 随机动作，是为了持续补充非贪心策略下的转移——回放需要覆盖下一状态的分布，全贪心会把数据收窄到一条轨迹附近。ε 始终不降到 0，是因为训练期需要探索。

**Huber 损失。** 实现用 `nn.SmoothL1Loss`，即 Huber 损失：误差小时是平方（与 MSE 一致，梯度平滑），误差超过阈值后转为线性。Q 学习的回归目标含噪声与偶发高估，属于离群样本，平方损失对预测值的梯度随残差线性增长，而不是平方增长。Huber 的线性段把大残差对应的损失导数限制为常数幅度，减轻离群样本的影响；这不等于限制整个网络的参数梯度。

**梯度裁剪。** `clip_grad_norm_` 把全局梯度范数限制在 10 以内。与 Huber 同方向：Huber 从损失端压低离群样本的贡献，裁剪在反传阶段把全局梯度范数压到阈值内，但这不等于限制优化器单步更新的实际幅度（Adam 等自适应优化器会按自身状态缩放），两者叠加，防止某一批异常样本造成参数突跳。

## 五 · 实验目标与口径

先交代任务本身。CartPole（倒立摆）是一根杆通过铰链装在一辆小车上的物理装置：杆能自由向两侧倾倒，小车只能沿一条水平轨道左右移动。每一步算法只有两个选择——把小车向左推或向右推，靠移动底座把杆扶正；观测是小车位置与速度、杆的倾角与角速度这 4 个实数。每存活一步奖励 +1，没有其他得分动作。回合在两种越界条件下立即失败终止：杆偏离竖直超过 12°，或小车偏离轨道中心超过 2.4 个单位；扛满 500 步则按时间截断结束，代表这一局已解决。

实验把前四节的组件拼成一套完整 DQN，在 CartPole-v1 上跑 5 个训练种子，回答一个问题：这套配置能否在 100,000 环境步内稳定解决任务。选 CartPole 有两个理由：4 维连续状态让第 2 章的 Q 表无从下手，必须用网络逼近；动作只有左、右两个，$\max_{a'}$ 可以直接取，函数逼近带来的问题不会和动作空间的困难混在一起。成败判据在训练前就定下：撑满 500 步算成功，中途越界（杆倾角超过 12° 或小车出界）终止算失败，只看独立的贪心评估。

实验只有一套配置，没有去掉回放或目标网络的对照组。结果能说明这套配置解决任务的程度和种子间的离散，不能拆出每个组件各自的贡献；组件的作用来自前四节的机制分析。

环境与判据：**CartPole-v1**。`terminated`＝失败终止（杆倾角或小车位置越界），项目日志里记为 `fell`——这只是代码沿用的字段名，统一指这两类失败，并不专指杆倒下；`truncated`＝撑满 500 步＝成功（`success`：truncated 且未 terminated）。

| 项 | 取值 |
|---|---|
| 预算 | 100,000 环境步 |
| 训练种子 | 0–4（共 5 个） |
| 验证 | 每 10% 预算（10,000 步）一次，每次 20 局，贪心，种子 10000 起 |
| 最终测试 | 训练结束后 100 局，贪心；正文数字取**一次性复评**（种子 30000–30099，见第 11 章披露） |
| 网络 | MLP(4, 128, 128, 2)，ReLU |
| 回放 | 容量 50,000，batch 32，warmup 1,000 |
| 目标网络 | 每 500 步同步 |
| ε | 1.0 → 0.05，线性 10,000 步 |
| 优化 | Adam，lr $1\times10^{-3}$，γ 0.99，grad clip 10，CPU |

> **配置版本**：初版（batch 64、每 1,000 步同步、ε 50,000 步衰减）在同样的 100,000 步预算里只把回合长度推到 94.7 ± 10.9、成功率 0.7%。逐项排查后冻结为上表的 v2，以 5 个种子重跑；旧运行原样归档保留。整个过程与处置写在第 11 章。

**bootstrap 口径。** 失败终止（`terminated`，杆倾角或小车位置越界）时 TD 目标退化为 $y=r$，不外推：越界意味着这一局已经结束，终止后延续回报按 0 处理，即使环境仍返回终止观测。撑满 500 步（`truncated`）时照常外推 $y = r + \gamma \max_{a'} Q(s',a')$：500 步是人为时限，不是任务失败，此刻杆还立着，“再撑几步”的回报真实存在。若把撑满时限也当终止，会系统性低估所有“接近时限”的状态，把人为上限学成任务上限。全项目对真实终止与时间上限的区分原则一致（含第 2 章表格 Q-learning），但具体实现细节不同：第 4 章的 REINFORCE 逐回合计回报，没有零尾值这一步。

## 六 · 实测结果

对第五节的问题，答案是没有做到稳定解决：5 个种子里 3 个撑满 500 步，另外 2 个在预算内没有学会。

以下均为 5 个训练种子、每个 100,000 环境步；最终测试是配置冻结后的一次性复评（100 局贪心 × 5 种子，种子 30000–30099）：

- **最终测试平均回报：331.2 ± 233.2（跨种子样本 SD）**，平均回合长度 331.2 步；
- **成功率 60.0%**（撑满 500 步记为成功），失败率 40.0%；
- 逐种子平均回报：500、34、500、122、500——**5 个种子里 3 个完全解决（满分 500），2 个明显失败**；
- 验证成功率（每 10,000 步 20 局）：首个验证点 0.0% → 末个验证点 60.0%。

这个结果的形状本身就是第 11 章的素材：均值 331 来自“3 个种子满分、2 个种子低分”的离散结果，233 的跨种子 SD 反映的是这 5 个训练种子的离散程度，而非某个总体分布形状或单种子的评估波动。只报一个均值会让人以为 DQN“学到一半”，只报最好的种子则会以为它稳定解决。

## 七 · 与第 2 章对照：表格为什么不需要这些

第 2 章的表格 Q-learning 没有回放、没有目标网络，在状态–动作对获得充分访问且步长合适的条件下也能收敛，原因在于表格结构本身：每个格子独立，更新一个格子不牵动其他格子，不存在参数共享导致的误差传播，也没有“没见过的区域靠外推”的问题；目标 $r + \gamma \max Q(s',a')$ 里用的 $Q$ 也是逐格独立的，一处更新不会全局改变目标面。表格学习仍有自举误差和采样方差。

DQN 把三者全换了：误差共享、依赖外推、目标由网络自身生成。回放负责数据端——去相关、复用、覆盖更多分布；目标网络负责目标端——把移动的靶子变成阶梯式移动的靶子。这两项是经典 DQN 的稳定化组件，降低相关采样与移动目标带来的风险，但不提供不发散的保证。移除后的表现取决于任务、网络和配置，需要消融验证。

## 八 · 易错点

1. **用训练回报报性能。** 训练回报是 ε-greedy 下、含大量随机动作的回合收益，早期 ε≈1.0 时它几乎衡量随机策略，既低估学成的策略，又与评估口径不同。性能只报独立评估：验证 20 局、测试 100 局，均为贪心。
2. **回放中新旧数据的偏差来源。** 缓冲区里存的是 $(s,a,r,s')$ 这样的环境固定记录，回归目标每次都用当前目标网络现算，所以标签里不含“写入时的旧估值”；真正的偏差在分布上：早期数据由高 ε 的旧策略收集，覆盖较广，但其中许多状态在后续低 ε 阶段很少被访问，训练采样分布与最终贪心评估的访问分布并不一致。读曲线拐点时要意识到，回放里始终混着“上一阶段的经验”，新旧混合的比例随训练进程缓慢变化。
3. **ε 衰减与评估模式混淆。** ε 只作用于训练的行动选择；验证、测试走 `greedy()`，不看 ε。把训练步上的 ε 当成“当前策略的探索率”去解释评估结果，或把带 ε 的评估结果混入贪心结果，都会混淆口径。单独报告的随机策略评估同样有效。
4. **评估须独立并注明动作模式，本实验采用贪心、按种子隔离。** 验证种子从 10000 起；历史测试种子从 20000 起，正文采用配置冻结后 30000–30099 的一次性复评，与训练种子 0–4 完全不相交；混用训练环境实例或训练种子，会把训练期见过的状态当成泛化能力。局数与环境步预算是两回事：100,000 是训练预算，100 局是测试样本量。

## 代码实现

对应 `复现包 rlpractice/algos/single/dqn.py`（完整实现见复现包）：

```python
def eps_at(step: int) -> float:
    frac = min(1.0, step / max(1, int(cfg["eps_decay_steps"])))
    return float(cfg["eps_start"]) + frac * (float(cfg["eps_end"]) - float(cfg["eps_start"]))

# ...（省略 episode 记录与评估分支，以下为每环境步的主循环）

while env_steps < budget:
    a = train_action(obs, eps_at(env_steps))
    obs2, r, term, trunc, info = env.step(a)
    env_steps += 1
    replay.push(obs, a, r, obs2, done_terminal=term)
    obs = obs2

    if replay.n >= int(cfg["warmup"]):
        bs, ba, br, bs2, bd = replay.sample(int(cfg["batch_size"]), rng)
        bs_t = th.as_tensor(bs, device=device)
        ba_t = th.as_tensor(ba, device=device)
        br_t = th.as_tensor(br, device=device)
        bs2_t = th.as_tensor(bs2, device=device)
        bd_t = th.as_tensor(bd, device=device)

        q = net(bs_t).gather(1, ba_t[:, None]).squeeze(1)
        with th.no_grad():
            q_next = target(bs2_t).max(1).values
            y = br_t + float(cfg["gamma"]) * q_next * (1.0 - bd_t)
        loss = loss_fn(q, y)
        opt.zero_grad()
        loss.backward()
        nn.utils.clip_grad_norm_(net.parameters(), float(cfg["grad_clip"]))
        opt.step()
        updates += 1
        if env_steps % int(cfg["target_sync"]) == 0:
            target.load_state_dict(net.state_dict())
```

这段是第五节配置与自举口径的落地：`eps_at` 对应 ε 线性衰减，`replay.push(..., done_terminal=term)` 只把失败终止记为终止，于是 `y = br + γ·q_next·(1-d)` 仅在越界失败时抹掉外推项，撑满 500 步照常 bootstrap。
