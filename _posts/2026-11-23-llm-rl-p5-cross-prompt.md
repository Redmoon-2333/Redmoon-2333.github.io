把 `4` 从 `2+2` 的答案栏搬到 `1+3`，两题都对。把它搬到 `2+3`，第三题答错；有遗漏的判题器却可能照样给分。Qwen 用同一组参数做这些题。在一道题上学到的偏好，别的题也可能跟着变。

一次答案交换有三种需要记下的结果：换过去仍正确，是正常复用；换过去答错且被拒，说明检查起了作用；换过去答错却过关，才记为错答迁移。先用独立答案表确认对错，再读训练验证器的分数，不能用同一个有漏洞的检查来证明自己没有误判。

## 1. 为什么一题的更新会影响另一题

用两个参数手算。题 A 的更新把第一个参数提高 `0.1`，第二个不变。假设在当前模型附近，第一个参数每提高一小截，题 B 某个答案的概率按 `0.3` 倍的速率上升。代入这一步，概率约增 `0.1×0.3=0.03`。如果 B 的这项概率只对第二个参数敏感，这一步的近似变化是 `0`；如果变化速率是 `−0.3`，概率则约降 `0.03`。

《Wrong the Same Way》用经验切核度量梯度之间的联系。纸上可以把 A 带来的参数改变量记成 `(0.1, 0)`，把 B 的答案概率对两个参数的变化率记成 `(0.3, 0)`。两对数分别相乘后相加，得到 `0.03`。如果 B 的变化率向量是 `(0, 0.3)`，结果就是 `0`：两题共用一份参数，A 这次更新却没动到 B 敏感的那一项。答案能被采到的机会和学习率，还会影响这种变化能积累多少。

## 2. “漏洞普适度”已经包含错误条件

Wrong the Same Way 定义每题的错误接受集合：

$$
H(x)=\{y:V(x,y)=1,\ C(x,y)=0\}.
$$

对一个候选输出 $h$，可数它在多少题上属于这个集合：

$$
u(h)=\frac{|\{x:h\in H(x)\}|}{N}.
$$

$N$ 是所考察的题目数。这个量同时需要验证器接受和真实错误两个条件。只计算 $V$，得到的是跨题接受率。

例如让验证器用同一个回答 `4` 复评下面两组题。每组得到的代理分都是 `[1, 1, 1]`。

| 目标题 | 答案键 | `4` 的跨题接受率 | `4` 的错误接受占比 |
|---|---|---:|---:|
| `2+2`、`1+3`、`6−2` | `4, 4, 4` | `3/3` | `0/3` |
| `2+2`、`1+3`、`2+3` | `4, 4, 5` | `3/3` | `1/3` |

两组的接受记录一模一样。只看接受率的筛查器也会给出相同判断；用独立答案键，才看得出第二组多放过了一条错误。

## 3. 当前 C02 候选：先筛查，再判断怎样更新

C02 暂定研究不完美验证器下的在线抗捷径。现有设想是：从高奖励回答中抽样，把回答交给同批其他题的验证器，取得跨题接受特征，再决定是否需要进一步审计或调整训练权重。

这里有三个分别需要实验回答的问题：

| 环节 | 需要建立的证据 |
|---|---|
| 筛查 | 跨题特征能否区分错误捷径与通用正确答案 |
| 干预 | 使用该特征后，错误输出的学习趋势怎样改变 |
| 净收益 | 在匹配计算预算下，独立任务质量是否改善 |

初始协议拟抽查 5% 的高分回答。若一批有 200 条，抽中 10 条，每条换 4 道题复评，就新增 40 次判分；解析和独立审计再单独计数。这是预算示例，抽样比例要和误报、漏报一起测。

## 4. 一个能真正区分解释的实验

先设计三类可控答案：跨题通用的正确规则、跨题通用的错误接受模式、只在单题触发的错误。让它们在训练前的频率和代理奖励尽量匹配，再比较检测分布。

若筛查器只把“共享”当作问题，它会同时惩罚通用正确规则。若它确实识别了错误结构，应该在保留正确复用的同时，更集中地标记假阳性。

在有精确参照的受控环境中，把真值留给独立评价器。候选训练器读取代理分以及交换评分产生的特征。这样可以检验它在真实答案不可用时还能识别多少错误。

下面的代码分别计算接受率和错误接受占比，分母统一为目标题数。

```python
def acceptance_rate(accepted_on_targets):
    # 每个元素表示同一回答在一个目标题上是否被代理接受
    return sum(accepted_on_targets) / len(accepted_on_targets)

def false_accept_share(accepted_on_targets, correct_on_targets):
    # 此处按全部目标题为分母，对应漏洞普适度的离散估计
    false_accepts = sum(
        accepted and not correct
        for accepted, correct in zip(
            accepted_on_targets, correct_on_targets, strict=True
        )
    )
    return false_accepts / len(accepted_on_targets)

accepted = [True, True, True]
correct = [True, True, False]
print(acceptance_rate(accepted))               # 1.0
print(round(false_accept_share(accepted, correct), 3))  # 0.333
```

第二个函数需要额外的 `correct` 标签，所以它用于评估筛查。假设筛查器把这组三条全标了「可疑」，它找到了那 1 条错误，同时误拦了 2 条正确复用。错误检出率是 `1/1`，正确复用误拦率也是 `2/2`。两项一起读，才能看出全部标记并没有分辨能力。

## 5. 强对照要排除什么

至少保留相同采样与评分预算下的基础策略更新、随机衰减同样数量样本、统一降低学习率或加强 KL，以及可获得的验证器修补方案。

随机衰减用于排除“少学了一点就更稳定”；降低学习率用于排除更新强度变化；修补验证器检验能否用更直接的工程改进解决问题。误伤率需要在通用正确答案上单独报告。

不同论文提供不同条件：Optimistic Verifiers 有外部规则解释参照；Reward Suite Is Leaky 的额外测试仍需审计；Wrong the Same Way 提供受控共享机制。把这些条件写清，才能判断方法在哪一种任务上有可检验的增量。
