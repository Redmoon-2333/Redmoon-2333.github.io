“谁贡献大”“谁先出错”“删掉谁的消息能救回来”看起来相似，实际对应不同目标。选错标签，就算模型打分很稳定，也可能指导了错误的行动。

本篇承接[论文 P3](/2026/11/23/llm-rl-p3-credit-assignment/)，把联盟执行、日志标签和修复干预分别解释。

## 1. 三角色联盟：让缺席真的发生

数学求解团队由起草者 D、批评者 C、修订者 R 顺序工作。起草和修订使用 Qwen2.5-3B，两组团队只改变批评者配置。

对每道题实际执行不同成员组合，得到 $v(S)$，即成员集合 $S$ 按定义运行后的结果。缺席规则需要明确：没有草稿时批评者不工作，修订者可以独立解题，空团队结果设为零。

Shapley 值把成员加入不同子集时带来的结果差，加权平均：

$$
\phi_i=\sum_{S\subseteq N\setminus\{i\}}
\frac{|S|!(n-|S|-1)!}{n!}
\bigl[v(S\cup\{i\})-v(S)\bigr].
$$

$N$ 是全部成员，$n$ 是人数。权重对应随机加入顺序中该子集先出现的比例。

## 2. 核心计算与一个能手算的例子

```python
from itertools import combinations
from math import factorial

def shapley(players, values):
    n = len(players)
    result = {}
    for player in players:
        others = [p for p in players if p != player]
        credit = 0.0
        for size in range(n):
            for subset in combinations(others, size):
                before = frozenset(subset)
                after = before | {player}
                weight = (
                    factorial(size) * factorial(n - size - 1)
                    / factorial(n)
                )
                credit += weight * (values[after] - values[before])
        result[player] = credit
    return result

values = {
    frozenset(): 0,
    frozenset({"A"}): 1,
    frozenset({"B"}): 0,
    frozenset({"A", "B"}): 1,
}
print(shapley(["A", "B"], values))  # A: 1.0，B: 0.0
```

A 单独就能成功，B 无论先来后到都没改变结果，因此其信用为零。真实实验则用保存的各联盟输出判分。

这种信用依赖当前模型、缺席规则、采样与任务指标。它不是跨所有可能队友和协议的永久贡献。

## 3. 语言裁判与联盟信用差多少

300 道题、两组团队的裁判评分与 Shapley 秩相关约为 0.269–0.532；其中一组有效统计分母为 298。零 Shapley 的成员记录中，裁判给高于 0.2 的比例约 13%–72%。

裁判同时看到标准答案、最终答案、团队回报和完整转录，属于有金标的离线诊断。

这里使用 Spearman 秩相关，比较两种分数的排序是否一致；接近 1 表示排序更接近，不要求分数本身相等。零贡献信用仍需按本实验的缺席与采样规则理解。

与简单规则也要比较。在 mediumC 团队，大裁判相关 0.269，末发言者规则为 0.380；不能概括成裁判全面优于这些廉价对照。

后续离线诊断多测修订者独立作答的 $v(R)$，再用 `max` 规则补某些联盟值，相关达到 0.978/0.983，精确匹配 283/300、281/298。当前分析复用已有全联盟结果，没有新的模型调用；选联盟与补值规则是这个串行任务的事后诊断，尚未成为在线学得的通用选择器。

## 4. Who&When：先找到人，再找到步骤

本地使用 184 条作者日志，其中 126 条算法生成、58 条人工编写，比较一次整体判断、逐步检查、二分查找。模型替换为当前可用冻结模型，因此是换模型基准复做。

一个早期候选筛选在 24 题里只包含 12 个标注步骤。若正确步骤不在候选里，后面的评分器再强也选不中。候选召回需要先测。

完整实验还发现官方子串评分与严格步号解析不同：人工日志二分、给答案条件下，分别为 24.14% 与 15.52%。本文后续精确步骤采用严格步号口径。

人工标注是该基准的参考标签；它没有执行每个动作替换后的环境反事实。

## 5. 先整体找成员，再在该成员发言中逐步检查

复用同一批日志与成员判断，混合方法在算法日志两条件下达到 34.9%/36.5% 精确步准确率，逐步法为 24.6%/27.0%。给真实成员作为诊断条件时，达到 53.2%/54.8%，显示成员定位仍是一个明显瓶颈。

人工日志上的混合结果为 22.4%/12.1%，没有形成相同提升。不同日志生成方式需要分别分析。

在人工日志已报出步骤的子集上，追加回看把错误距离中位数从约 7–7.5 步降到 4 步，同时增加提前报错；算法日志相应中位数仍为 1 或 0。离得更近和精确命中可以变化不同。旧分析合并同日志两个条件计算的一项显著性没有处理聚类，正文不将其作为独立日志显著改善的依据。

## 6. 低贡献消息就是最值得删除的吗

另一组四草案终审任务实际执行全部 16 个消息子集，再比较 Shapley 与“删掉一条后最终结果是否改善”。

初始 112 个分支全部截断，不能用于质量结论。改成结构化输出后，24 题有 22 题可完整评分；14 个失败里只有 2 个能由单条删除修复。可修复候选少，会限制删除选择器的效应上限。

事后案例换消息布局，同一删除的结果差可为 0、+1、−1。成员平均边际信用、当前完整上下文的留一删除收益，以及错误最初出现的位置，确实可能不同。

## 7. 下一步怎样选目标

| 目标 | 合适的标签或比较 |
|---|---|
| 学习个体边际作用 | 定义缺席规则后的联盟值、配套信用 |
| 对齐人工故障定位 | 严格成员与步号、日志聚类评价 |
| 选择一条可救回的删除 | 完整上下文留一干预收益、可修复率 |
| 给策略更好更新信号 | 除标签准确外，再测训练后的真实回报 |

这些实验已经明确了标签与干预的区别。接下来若训练信用模型，应先确定它服务哪一种决策，再选择评价对象。
