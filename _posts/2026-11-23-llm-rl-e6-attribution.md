起草员把乘法算错，修订员发现错误，却在最后一步抄错数字。翻日志能找出最早的错在草稿里。想知道删掉草稿能不能救回这题，要让修订员不看草稿重新做：做对，删除才有收益；还是抄错，最早出错的标注不变，删除收益却是零。

## 1. 三角色联盟：让缺席真的发生

数学求解团队由起草者 D、批评者 C、修订者 R 顺序工作。起草和修订使用 Qwen2.5-3B，两组团队只改变批评者配置。

对每道题实际运行不同成员组合，每种组合叫一个联盟。$v(S)$ 记联盟 $S$ 的结果，例如 $v(\{D,R\})$ 是保留起草和修订、跳过批评后得到的分数。没有草稿时批评者不工作，修订者可以独立解题，空团队得零分。

Shapley 值把成员加入不同子集时带来的结果差，加权平均：

$$
\phi_i=\sum_{S\subseteq N\setminus\{i\}}
\frac{|S|!(n-|S|-1)!}{n!}
\bigl[v(S\cup\{i\})-v(S)\bigr].
$$

$N$ 是全部成员，$n$ 是人数。权重对应随机加入顺序中该子集先出现的比例。

## 2. 核心计算与一个能手算的例子

```python
from itertools import combinations
from math import factorial

def shapley(players, values):
    n = len(players)
    result = {}
    for player in players:
        others = [p for p in players if p != player]
        credit = 0.0
        for size in range(n):
            for subset in combinations(others, size):
                before = frozenset(subset)
                after = before | {player}
                weight = (
                    factorial(size) * factorial(n - size - 1)
                    / factorial(n)
                )
                credit += weight * (values[after] - values[before])
        result[player] = credit
    return result

values = {
    frozenset(): 0,
    frozenset({"A"}): 1,
    frozenset({"B"}): 0,
    frozenset({"A", "B"}): 1,
}
print(shapley(["A", "B"], values))  # A: 1.0，B: 0.0
```

A 单独就能成功。若 A 先加入，B 的边际贡献是 `v(AB)−v(A)=1−1=0`。若 B 先加入，B 的贡献是 `v(B)−v(空)=0−0=0`。两种加入顺序各一半，所以 B 的平均信用为 0。同理 A 的两次边际贡献都是 1。`values` 保存每个联盟的实际得分，在纸上例子中由表直接给出，真实实验则让每个联盟运行后判分。

缺席规则会改写每一小队拿到的输入。例如没有批评者时，可以让修订者直接读草稿；若实际系统遇到空缺就停止，这一小队会拿另一种分数。Shapley 按实际约定重新计算。对三位成员要填 $2^3=8$ 个联盟的值；每多一人，组合数就翻一倍。

也可以把表改成 `v(空)=v(A)=v(B)=0`、`v(AB)=1`，模拟缺谁都打不开门。先来的成员边际贡献为 0，后来的贡献为 1；随机加入时两人各有一半机会成为后到者，分数各是 `0.5`。这个例子里，需要共同完成的工作被平分，最后发言的人不会因此拿走全部信用。

## 3. 语言裁判与联盟信用差多少

300 道题、两组团队的裁判评分与 Shapley 秩相关约为 0.269–0.532；其中一组有效统计分母为 298。零 Shapley 的成员记录中，裁判给高于 0.2 的比例约 13%–72%。

裁判在这次离线诊断中看得见标准答案、最终答案、团队回报和完整转录。Spearman 秩相关只看排序。若两套分数都把 D 排第一、R 排第二、C 排第三，即使一套打 `0.9、0.5、0.1`，另一套打 `1、0.2、0`，同样的名次仍会得到相关系数 1。

mediumC 团队中，按末发言者打分的秩相关为 0.380，大模型裁判为 0.269。这组结果给出了一个成本更低、排序也更接近联盟信用的参照。

后续离线诊断从全联盟记录取修订者独立作答的 $v(R)$，再用 `max` 规则补部分联盟值，相关达到 0.978/0.983，精确匹配 283/300、281/298。联盟和补值规则是在当前串行任务上确定的。泛化评价需要另选任务，预先固定挑选办法。

## 4. Who&When：先找到人，再找到步骤

本地用冻结模型阅读 184 条作者公开的日志，其中 126 条由算法生成，58 条人工编写。比较三种读法：一次看全篇、每步逐一检查，或先查前半段是否已经出错，再缩小到一段。

早期筛选在 24 题里只找回 12 个标注步骤。即使下一层能从候选中次次选对，整条流程的准确率上限也只有 `12/24=50%`。先数标注步骤出现在候选里的次数，再测评分器的排序。

完整实验还发现官方子串评分与严格步号解析不同：人工日志二分、给答案条件下，分别为 24.14% 与 15.52%。本文后续精确步骤采用严格步号口径。

严格步号要求回复指向标注的那一步。例如标签是 `2`，文本回了 `12`，按子串查找能找到 `2`，严格解析则记错。人工标签回答的是「标注员指认了哪一步」，修复收益要靠重新执行测量。

## 5. 先整体找成员，再在该成员发言中逐步检查

复用同一批日志与成员判断，混合方法在算法日志两条件下达到 34.9%/36.5% 精确步准确率，逐步法为 24.6%/27.0%。给真实成员作为诊断条件时，达到 53.2%/54.8%，显示成员定位仍是一个明显瓶颈。

人工日志上的混合结果为 22.4%/12.1%。这里按人工和算法生成两类日志分别报告。

在人工日志已报出步骤的子集上，追加回看把错误距离中位数从约 7–7.5 步降到 4 步，同时增加提前报错。算法日志对应的中位数仍为 1 或 0。精确命中看步号是否相同，距离指标允许量出错了多远。同一日志的两个条件需要按日志配对，评估不确定性时也以日志为单位。

## 6. 低贡献消息就是最值得删除的吗

另一组四草案终审任务实际执行全部 16 个消息子集，再比较 Shapley 与“删掉一条后最终结果是否改善”。

初始 112 个分支全部截断。改成结构化输出后，24 题有 22 题可完整评分。14 个失败里有 2 个能由单条删除修复，这是该批样本中理想删除选择器能够救回的题数。

用一个手算例子看差别。甲、乙各自单独答对，合起来时发生冲突，终审选了一个错误说法。记 `v(空)=0`、`v(甲)=v(乙)=1`、`v(甲乙)=0`。甲的 Shapley 为 `(1−0+0−1)/2=0`，乙也是 0。若只看正在失败的完整团队，删除甲后乙单独得 1，修复收益为 `1−0=+1`。零平均信用在这里仍对应有效删除。

保存的事后案例中，改变消息布局后，同一删除的结果差可为 0、+1、−1。上线删除策略前要在完整上下文里逐条验证，并报告有多少失败确实能靠一次删除救回。

## 7. 下一步怎样选目标

| 目标 | 合适的标签或比较 |
|---|---|
| 学习个体边际作用 | 定义缺席规则后的联盟值、配套信用 |
| 对齐人工故障定位 | 严格成员与步号、日志聚类评价 |
| 选择一条可救回的删除 | 完整上下文留一干预收益、可修复率 |
| 给策略更好更新信号 | 除标签准确外，再测训练后的真实回报 |

选桥时，先换掉高分报告，让当前接收者重新选桥，这是测报告有没有改变选择。再比较用这种分数训练和用团队奖励训练的 Actor，在同一批新题上的回报，才是在测分数能否指导学习。两种对照见[论文 P3](/2026/11/23/llm-rl-p3-credit-assignment/)。
