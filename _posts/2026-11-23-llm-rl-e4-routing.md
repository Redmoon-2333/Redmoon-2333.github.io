小模型不够准，可以多采样、调用大模型或先复核。哪一种划算，需要在相同任务和明确预算下比较，不能只看最高准确率。

本篇的大部分模型是冻结的。离线训练路由器、回放已有答案与微调 Qwen，是不同的学习对象。

## 1. 搜索实验：先核验候选，而后解释搜索

24 点材料包含作者公开的 IO、CoT 与树搜索日志。100 道题中，宽度五的树搜索在最终候选中有解的为 69/100，20,500 个候选的独立验算与缓存标志一致。

它与论文另一轮报告的 74% 使用不同日志。此次是已有输出复算，没有新调用 GPT-4，也没有把多候选预算当成与单次回答等价。

首步可行候选覆盖率随搜索筛选有损失，末层有效候选没有再损失。保存各层候选，可以定位错误发生在生成、评估还是保留阶段。

## 2. 离线路由：同样 218 次升级怎么花

另一组材料回放 RouteLLM 作者的双模型逐题输出。432 题用于校准，875 题评价，限定 218 个升级名额：

| 分配规则 | 答对数 |
|---|---:|
| 增益回归 | 624/875 |
| 根据小模型输出长度 | 621/875 |
| 均匀随机升级的精确期望 | 600.33/875 |

回归与长度规则只差 3 题，需要逐题配对看。升级次数也不等于真实时延或金额；这一轮只是已有答案的离线选择。

## 3. 400 题三档路由：自一致性提供了什么

本地 Qwen2.5-3B、远程 qwen3.8-flash 与 deepseek-flash 分别求解和复核。实际返回模型名用于结果归属。

小模型单次准确率 84.25%，大模型 97.75%。让本机对每题额外采样，用是否存在答案分歧决定升级，130/400 题交给大模型，最终 391/400，即 97.75%；远程输入与输出 token 合计均摊约 101.69/题。

代价包括额外本机采样；五次本机采样的记录总量均摊约 1,730.20 token/题。远程 token 减少，不能直接称总推理工作减少。

三级级联达到 98.25%。这些是该批数学题上的冻结输出结果，还需要独立校准集固定阈值、在新题验证规则。

## 4. 随机基线应该怎样算

原分析代码在列表内为每一题重建同一个种子的随机数生成器，得到相同随机分数；稳定排序实际选中了输入前缀。新文章采用均匀抽取固定名额的精确期望。

若小模型正确率为 $a_s$，大模型为 $a_l$，随机升级比例为 $f$，则：

$$
\mathbb E[a_{\text{random}}]=(1-f)a_s+fa_l.
$$

```python
small_accuracy = 0.8425
large_accuracy = 0.9775
for fraction in (0.10, 0.15, 0.20, 0.30):
    expected = (
        (1 - fraction) * small_accuracy
        + fraction * large_accuracy
    )
    print(fraction, round(expected * 100, 4))
# 85.6, 86.275, 86.95, 88.3
```

期望公式包括“大模型把原本正确题答错”的情况，因为它对每题都按同样概率替换。报告随机波动范围时，再按完整子集抽样，而不是重建常数分数。

## 5. 复核：能发现错，还要看值不值得问

在 400 题实验中，小模型自检的错误标记精确率约 0.26；远程复核约 0.95–0.98，但每题复核输入与输出合计约 391–468 token，比大模型直接重答约 249 token 更贵。本文未另行指定时，token 成本均为输入与输出之和。

模拟故障环境用信息价值比较“问”与“不问”。EVSI 是额外信息带来的预期决策毛收益，减掉询问价格后得到预期净收益。该批实测净省在办公室为 +65，图书馆为 −151；换环境，成本与动作差异就会改变结论。

如果第二条报告只是已知的第一条完整副本，内容没有新增信息。强制花满预算会买到没有价值的询问，允许停止的策略必须保留。

## 6. 从日志学习复核，也要面对强规则

8,000 条单动作模拟日志训练线性价值函数，再评价 2,400 个新快照。学习器两队净额为 −293/−105，与学习器相同询问次数的随机对照为 −287/−114。价值规则为 +47/+67，其等次数随机对照为 −101/−59。两套比较分别匹配各自购买次数，不能横向当作三者同预算。

这里的状态来源类别是显式可见的，强规则能够直接利用。它是上下文赌博机式决策，不是多轮语言模型 RL。新的学习器需要先在规则难以表达的条件中寻找增量。

## 7. 只看题目预测小模型会不会错

同一批 400 题中，大模型只读题面预测小模型成败，AUROC 为 0.752；附上 30 题历史后为 0.753。小模型输出长度为 0.733，自一致性为 0.940。

AUROC 衡量区分正确与错误的排序能力；概率是否校准是另一件事。历史改善校准，不一定改善区分。无历史预测平均约 219 token，附 30 题历史后约 2,560 token；直接解题约 249 token。

这些结果把下一步问题收窄为：便宜可得的信号能否提供可靠增量，以及增加检测流程是否真的比直接解决任务省。
