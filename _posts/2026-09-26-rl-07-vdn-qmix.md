> 第 6 章我把 IQL 的三个失效模式摆完，留下一个两头都躲不开的问题：团队奖励只有一个标量，它评价的是两个人**一起**走出的那一步，可执行时每个 agent 只能用自己的观测各选各的动作。直接学联合 $Q(s,a_1,\dots,a_n)$，动作空间随 agent 数指数增长；不学联合价值，团队信号又无处安放。本章走值分解这条中间路线：先写 $Q_{tot}=f(Q_1,\dots,Q_n)$，再比较两种 $f$——VDN 的加和与 QMIX 的单调混合，看清各自省了什么、换掉什么、代价在哪。

## 一 · 核心问题：只有一个团队奖励

走廊的 +10 只在「两人都到位、门已打开」时出现，撞车的 −0.2 是两人动作组合的产物。奖励评价的对象始终是**联合动作** $(a_1,\dots,a_n)$，于是同一个标量要同时满足两个互相拉扯的要求：

- **建模上要合**：学习信号必须来自联合价值 $Q_{tot}(s,a_1,\dots,a_n)$，否则分不清「我走对了但你没配合」与「我们配合成功」，第 6 章的信用分配问题原样保留。
- **执行上要分**：部署时每个 agent 只有自己的局部观测 $o_i$ 与自己的 Q 网络，既看不到全局状态 $s$，也无法枚举别人的动作，最优联合动作必须能拆成 $n$ 个独立的 $\arg\max$。

两个要求合起来就是值分解方法的 **IGM（individual-global-max）目标**：存在一组个体 Q，使得逐 agent 贪心拼出的联合动作恰好是联合价值的全局最优。整章的构造都在回答同一个问题——$f$ 取什么形式，既能表达团队价值，又让 $\arg\max$ 拆得开。

## 二 · 联合 Q 的维数灾难与分解式

$n$ 个 agent、每个 $|A|$ 个动作，联合动作空间大小是 $|A|^n$。走廊里 $n=2$、$|A|=3$，联合动作只有 9 个，还能列成 3×3 的表逐格填数；把规模推到 10 个 agent、每个 10 个动作，$|A|^n=10^{10}$，联合 Q 表 $|S|\times|A|^n$ 存不下、采不到、更学不动。DQN 只是把表格换成网络，并没有消除「对每个联合动作求一次值」的开销。

分解是标准应对：

$$Q_{tot}(s,a_1,\dots,a_n)=f\big(Q_1(o_1,a_1),\dots,Q_n(o_n,a_n);\,s\big)$$

每个 $Q_i$ 只吃局部观测与自身动作，参数量随 $n$ 线性增长（本项目是 $n$ 个 `obs→64→64→n_actions` 网络），指数维数被搬进了 $f$ 的表达力里。于是全部设计压力集中到 $f$：它要能表达联合动作之间的交互（否则退回玩具级的可加情形），又要让 $\arg\max_{a}Q_{tot}$ 拆成各选各的。VDN 与 QMIX 的分野，就是对这两个目标的取舍不同。

分解式里还藏着一条纪律：**全局状态 $s$ 只允许进 $f$，不允许进任何 $Q_i$**。若个体网络也吃 $s$，训练时学到的映射在部署时根本拿不到，CTDE 的「分散执行」当场断掉；把 $s$ 关在混合网络里，训练用得上集中信息、执行仍只靠局部观测。

## 三 · VDN：加和假设与它的表达力上限

VDN 取最简单的 $f$——直接求和：

$$Q_{tot}=\sum_{i=1}^{n}Q_i(o_i,a_i)$$

训练目标里团队奖励只加一次：

$$y=r+\gamma(1-d)\sum_{i}\max_{a_i'}Q_i(o_i',a_i';\theta_i^-)$$

本实现对应 `td_target` 的 `mode="joint"`，预测侧把 `q_taken.sum(1)` 与 $y$ 做 Huber 损失；截断（`truncated`）时 $d=0$ 照常 bootstrap，真实终止（`terminated`）时 $d=1$ 不外推。它与 IQL 的分野只在**梯度流到谁**：IQL 把 $r$ 广播给每个 agent 各算各的 Huber，VDN 让梯度穿过联合和回到每个 $Q_i$——同一批数据、同一批网络，差别只在损失怎么组合。

加和天然满足单调性（$\partial Q_{tot}/\partial Q_i=1\ge 0$），贪心因此自动可分解：$\arg\max_{a}\sum_i Q_i=(\arg\max_{a_1}Q_1,\dots,\arg\max_{a_n}Q_n)$，不需要任何额外结构。**代价写在表达力上**：$f$ 只会相加，联合价值必须可加。用 2×2 的匹配情形检验——若想让 $Q_{tot}(0,0)=Q_{tot}(1,1)=1$、$Q_{tot}(0,1)=Q_{tot}(1,0)=0$，可加性要求 $Q_1(0)+Q_2(0)=1$ 与 $Q_1(0)+Q_2(1)=0$ 同时成立（推出 $Q_2(0)-Q_2(1)=1$），又要求 $Q_1(1)+Q_2(0)=0$ 与 $Q_1(1)+Q_2(1)=1$ 同时成立（推出 $Q_2(1)-Q_2(0)=1$），两式矛盾，无解。凡是「我的最优动作取决于你选什么」的相关结构——分工、轮流、反协调——VDN 都表示不出来：加和之下，最优联合动作永远是各自独立的最优。走廊并非完全可加（撞车 −0.2 就取决于两人的动作组合），但这类交互项占比小、发生位置在双方观测里可见，+10 的达成条件（门开、两人的位置）同样是双方都能看见的事实，联合价值整体更接近可加族，不靠精细的交互建模也能学个大概——这给「VDN 与 QMIX 能否拉开差距」留了悬念，结论留待实测。

## 四 · QMIX：状态条件超网络与单调性约束

QMIX 把 $f$ 换成由**全局状态 $s$ 驱动的超网络**生成的混合网络，并施加单调性约束：

$$\frac{\partial Q_{tot}}{\partial Q_i}\ \ge\ 0,\qquad \forall i$$

状态 $s$ 只进混合网络：CTDE 的口径是集中信息只进训练目标，不进个体 Q 网络的输入，所以执行时每个 agent 依然只用自己的 $Q_i$。

**为什么单调性才能保证 argmax 可分解。** 设 $a_i^*=\arg\max_{a_i}Q_i(o_i,a_i)$，对任意联合动作 $a$，每个分量都满足 $Q_i(a_i)\le Q_i(a_i^*)$；由单调性逐分量抬升，得到

$$Q_{tot}(a_1,\dots,a_n)\ \le\ Q_{tot}(a_1^*,\dots,a_n^*)$$

于是逐 agent 贪心拼出的 $a^*$ 就是联合 argmax，无须枚举 $|A|^n$。这是**充分条件，不是必要条件**：不单调的 $f$ 也可能恰好可分解，但要在训练中逐点验证代价极高；单调性把保证直接写进网络结构，这才是它被广泛采用的真正原因——它是一份结构性的可解性保证，不是免费的表达力赠品。单调性限制了可精确表示的联合价值表，但不能据此断言 QMIX 无法学会任何协调或反协调策略。表示完整 Q 值与表示某个最优联合动作是不同要求。

**本项目混合网络的前向**（`QMixer`，隐层 32）：

$$W_1(s)=\big|\mathrm{hyper}_{w1}(s)\big|,\quad b_1(s)=\mathrm{hyper}_{b1}(s),\quad W_2(s)=\big|\mathrm{hyper}_{w2}(s)\big|,\quad b_2(s)=\mathrm{hyper}_{b2}(s)$$

$$h=\mathrm{ELU}\big(QW_1+b_1\big),\qquad Q_{tot}=h\,W_2+b_2$$

其中 $Q=(Q_1,\dots,Q_n)$ 为行向量，$W_1\in\mathbb{R}^{n\times H}$、$W_2\in\mathbb{R}^{H\times 1}$，四个超网络都是以 $s$ 为输入的线性层。三处设计各管一件事：

- **权重取绝对值**：超网络可输出任意实数，`abs` 之后非负；链式法则里每层雅可比非负，$Q_i$ 增大只会让 $Q_{tot}$ 不降，单调性由此成立。
- **隐层用 ELU**：它单调不减（$x>0$ 时等于 $x$，$x\le 0$ 时等于 $e^{x}-1$），复合后不破坏单调性，且负半轴保有非零梯度。
- **$b_1,b_2$ 自由**：偏置只依赖 $s$、不依赖任何 $Q_i$，对单调性毫无影响，却决定 $Q_{tot}$ 能落在什么数值范围——这正是下一节修正的着力点。

## 五 · 本项目的修正：最终偏置不能过 ReLU

源实现（系列讲义配套代码）把**最终偏置 $b_2$ 过了 ReLU**。顺着链条推一遍就能看到后果：隐层用 ReLU 则 $h\ge 0$，权重 $W_2\ge 0$，于是 $hW_2\ge 0$；再叠 $b_2=\mathrm{ReLU}(\cdot)\ge 0$，整个混合网络被钉死在 $Q_{tot}\ge 0$。

而走廊的奖励本身就含负值：**每步 −0.1**、撞车 −0.2，一局 40 步没有送达就至少 −4（还没算撞车），失败局的团队价值是货真价实的负数。$Q_{tot}\ge 0$ 的网络只能把负价值压在 0 附近，TD 目标 $r+\gamma(1-d)Q_{tot}'$ 为负、预测非负，Huber 损失永远留着一块拉不平的系统偏差——这不是收敛快慢的问题，是**表示能力缺了整个符号**。

本版的改法是三处配合：隐层改 **ELU**（单调不减，单调性不破）、混合权重保留 **abs**（非负，单调性的来源）、**最终偏置 $b_2$ 不加任何激活**（可以为负）。两个测试把修正钉死在回归层面：

```python
def test_qmix_is_monotone_in_each_agent_q():         # 对每个 Q_i 加 1，输出不降
    ...

def test_qmix_can_represent_negative_team_value():   # 两个 Q_i 置 -50，输出全为负
    ...
```

前者守住单调性：改坏它，argmax 分解就失效，QMIX 退化成不可分解的黑盒；后者守住可负性：防止改回非负的老毛病。**单调与可负是两个正交的性质**——偏置不参与对 $Q_i$ 的求导，放不放激活只影响值域、不影响单调方向，所以这一刀可以只切在 $b_2$ 上。

同一约束也要带到目标侧：`_run` 里 QMIX 的 TD 目标走 `tgt_mixer`（混合网络的 target 副本，随 `target_sync` 同步），与预测侧共用同一套结构，因此目标值同样可以为负；若目标侧与预测侧值域不一致，TD 回归会朝一个网络够不到的区间收敛。

## 六 · IQL / VDN / QMIX 的可比性设计

第 6 章已铺垫这条链：三个方法共用个体 Q 网络结构与联合回放接口，但学习目标不同，QMIX 还增加了混合网络参数与全局状态输入。这里把口径固定成对照表：

| 维度 | IQL | VDN | QMIX |
|---|---|---|---|
| 个体 Q 网络 | `obs→64→64→n_actions` | 同左 | 同左 |
| 回放 | `JointReplay`（整条联合转移一起存） | 同左 | 同左（读取其中的全局 state 字段） |
| 预算与种子 | 100k 联合步、种子 0–4 | 同左 | 同左 |
| 超参 | γ=0.95；ε 0.5→0.05 覆盖前 60%；lr 1e-3；batch 64；Huber；梯度裁剪 10；target_sync 500 | 同左 | 同左 |
| 评估 | 每 10k 联合步验证 20 局（种子 10000+）；最终测试 100 局（种子 20000+），贪心 | 同左 | 同左 |
| 团队价值 | 各自把 $r$ 当自己的 | $\sum_i Q_i$ | $\mathrm{mixer}(Q_i;s)$ |
| TD 目标 | $r$ 广播，逐 agent（`per_agent`） | 联合和，$r$ 只加一次（`joint`） | `tgt_mixer` 组合后逐元素（`element`） |
| 额外参数 | 无 | 无 | 超网络（混合隐层 32） |

损失分支把差异压缩成一处：

```python
if algo == "vdn":
    pred = q_taken.sum(1)                      # Σ_i Q_i
    loss = F.smooth_l1_loss(pred, target)      # target = r + γ(1-d)·Σ_i next_i
elif algo == "iql":
    per = td_target(rew, don, gamma, q_next, mode="per_agent")   # r 广播给每个 agent
    loss = F.smooth_l1_loss(q_taken, per)
else:                                          # qmix
    pred = mixer(q_taken, states)              # f(Q_i; s)
    loss = F.smooth_l1_loss(pred, target)      # target 由 tgt_mixer 组合
```

三点口径先摆出来。第一，QMIX 多出的超网络参数是**方法本身的一部分**（拿容量换结构），不是多拿的预算；它确实让参数量与另外两者不等，引用数字时要注明。第二，误差带是**跨训练种子的样本 SD**，5 个种子的误差带重叠既不能推出「无差异」，也不能推出「有差异」。第三，名义预算都是 100k 联合步，**局数是另一口径**，不与预算混用；三条曲线只能在同一张走廊图上并排。

顺带把 IQL 与 VDN 的差别说到数值层面：IQL 把团队奖励 $r$ 广播给每个 agent，再逐个回归，每个 Huber 各自独立；VDN 的联合目标里 $r$ 只加一次，回归对象是 $\sum_i Q_i$ 整体，求和节点上的误差会同时改动所有 $Q_i$。两者的差别最终落在**梯度怎么流**，而数据、网络与预算完全共用。

## 七 · 实测：走廊上的三个方法

协议已在第六节列全：100k 联合步、5 个训练种子、每 10k 步验证 20 局、最终测试 100 局、贪心策略、误差带为跨种子 SD。走廊上三个方法均已跑完 5 个训练种子，结果如下：

| 指标 | IQL | VDN | QMIX |
|---|---|---|---|
| 测试成功率（100 局 × 5 种子） | 100.0% | 100.0% | 0.8% |
| 测试平均回报 ± 跨种子 SD | 9.547 ± 0.000 | 9.547 ± 0.000 | -3.892 ± 0.241 |
| 验证成功率首次 → 末次 | 100% → 100% | 100% → 100% | 17% → 1% |
| 平均局长 | 4.5 | 4.5 | 39.7 |
| 截断率 | 0.0% | 0.0% | 99.2% |

![走廊上四种方法的验证成功率曲线：VDN／QMIX 与 IQL、COMA 同预算对照（每点 20 局贪心评估，5 种子；阴影为跨种子 SD；IQL 与 VDN 曲线完全重合且全程 100%，IQL 的红色被 VDN 的蓝色覆盖）](/assets/img/rl-practice/06_corridor_curves.png)

**「VDN ≈ QMIX」这类负结果怎么读。** 源材料曾记录本任务规模下两者数值接近，实测并不支持这个读法：同预算下测试回报差为 13.439（VDN 9.547 ± 0.000、QMIX -3.892 ± 0.241），成功率差为 99.2 个百分点（VDN 100.0%、QMIX 0.8%），差距远超两者各自的跨种子 SD——走廊里 QMIX 这一组不是「与 VDN 数值接近」，而是没有跑起来（验证成功率 17% → 1%，99.2% 的局磨满 40 步被截断）。这也不构成给方法排名的依据：单环境、单预算、5 个种子只是这一组设定下的读数。反过来，若差距确实落在种子 SD 以内，可检验的解释至少有三类——走廊的联合价值接近可加，VDN 的表达力已经够用；只有 2 个 agent、观测近乎充分，超网络的增益空间有限；QMIX 参数更多，同一预算下可能尚未收敛到更优。三类解释分别指向**任务结构、信息结构与预算**，要用加宽 VDN、延长预算、换交互更强的环境等对照才能区分。一张重叠的曲线分不出「方法没有优势」与「这个任务不需要优势」，负结果在这里的正确用法是收窄结论边界，不是给方法排名。

把三列放在一起读：走廊里每局要么送达成功（`terminated`）、要么 40 步超时（`truncated`），成功率与截断率互补；截断率高意味着大量局磨到上限仍未送达，负回报来自累计的每步 −0.1，这与中途反复撞车扣分是两种不同的失败形态。平均局长接近 40 说明主要在磨，明显短于 40 则说明局以成功提前结束——三列缺一个都会误判。

## 八 · 易错点

**一、把 QMIX 说成「把 Q 加起来」。** 加和是 VDN；QMIX 是由全局状态生成权重的**单调混合**，输出是 $Q_i$ 的非线性组合。判别方法很直接：VDN 求和没有一个可学参数，QMIX 的 $f$ 是一整套超网络参数。

**二、把单调性当免费午餐。** 单调性保证局部贪心可拼成联合最大值，却限制了联合价值的表示能力。某些动作排序随队友动作改变的价值表无法被精确表示；这不等于所有相关行为或反协调策略都不可表示。满足结构约束也不保证优化成功。

**三、把「权重非负」当成双向约束。** $W\ge 0$ 配合 ELU 单调不减，只给出 $\partial Q_{tot}/\partial Q_i\ge 0$，即 $Q_i$ 涨则 $Q_{tot}$ 不跌；**反向不成立**——$Q_{tot}$ 大不代表每个 $Q_i$ 都大，也不代表 $Q_{tot}=\sum_i Q_i$ 或是它们的上界。偏置又不参与对 $Q_i$ 的求导，所以「能否表示负值」与「是否单调」是两个正交的性质，第五章的修正只动了前者。

**四、跨环境比回报。** 走廊的 +10、谜题的 ±5、Nav2D 的归一化奖励不在同一量纲上，回报只能在同一环境、同一协议、同一批种子内比较；不同表示（表格 vs 网络、个体网络 vs 混合网络）的容量差异也要随数字写明。走廊这类教学小环境给出的是**机制演示**，不称论文复现。
